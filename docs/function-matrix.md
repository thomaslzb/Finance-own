# MoneyHome8 功能矩阵

本文档把目前已经掌握的功能点按“业务域 -> 具体能力 -> 证据来源”归并，用于支撑 Rust 重构时的模块拆分与需求追踪。

证据来源缩写：

- `UI`：运行中界面截图或窗口控件树
- `INI`：`Moneyhome.ini`、`DealOption.ini`、`mwSync.ini`、`Notification.ini`
- `RC`：`MoneyHome8.exe` 的 `RT_RCDATA` 资源窗体
