# 重大资产与家居物品 Rust 开发合同

## 1. 证据边界

本合同覆盖 B14 的重大资产、家居物品、持仓、买卖、追加投资、投资收益、投资费用、价值变更、成本市值构成和物品买入分期。重大资产买入已完成零金额兼容边界、`1.00 CNY` 无支付账户保存、`10.00 CNY` 绑定 `Cash-CNY` 保存、初始市值、工作区投影和冷启动验证；卖出已完成资产绑定、金额校验、`1.00 -> 1.50` 全额成本结转、`10.00` 资产按成本 `4.00`/所得 `6.00` 部分卖出、真实收入账户流入、同日市值调整、持有范围和冷启动验证；追加投资已完成零金额事件、`2.00` 成本/市值联动、`3.00` 仅成本追加、`5.00` 绑定 `Cash-CNY` 内部资产转换、新增贷款融资 `2.00` 的资产/负债同额增加、未关联既有贷款 `1.00` 成功复用且本金不重复，以及 `3.00=现金2.00+贷款1.00` 组合融资、关系投影和冷启动验证；投资收益已完成入口上下文差异、零金额阻断、`0.50` 外部取得、`0.25` 绑定 `Cash-CNY`、资产绩效与资金投影及冷启动页面复核；投资费用已完成零金额阻断、`0.50` 外部支付、`0.25` 绑定 `Cash-CNY`、资产绩效与资金投影验证；市值管理已完成零值、跨日期新增、同日 upsert、修改、无确认删除、上一日期回退、成本/收益/现金隔离、账户中心与净资产联动和冷启动验证。多贷款分摊、已关联贷款候选和额度规则、非人民币、成本与市值不相等时的部分卖出比例和舍入、并发与失败回滚仍待校准。家居物品账户的单页默认值、名称校验、取消、零余额创建、投资/自用修改、工作区空投影、冷启动、归档回放和零余额删除已有动态证据；真实物品买卖、跨币种、精确估值与分期公式仍属于待校准项。

MoneyHome8 8.50.0.0 的普通物品买入编辑器中，`TPracBuyEditFrame.btnInstallment` 存在且绑定事件，但运行时不可见并与资金账户控件重叠。Rust 必须提供明确、可见、受校验保护的分期入口，不复制这一隐藏状态。

## 2. 领域对象

- `MajorAssetAccount`：重大资产的稳定 ID、账簿、名称、币种、所有者、资产性质、账户组、状态和审计版本。
- `MajorAssetPurchase`：重大资产、取得日、原币总额、可选支付账户、外部资金来源标志、可选贷款、标签、备注、幂等键和审计版本。
- `MajorAssetInvestment`：重大资产、追加日、原币金额、可选支付账户、外部资金来源标志、是否同步增加市值、可选贷款、标签、备注、幂等键和审计版本。
- `MajorAssetDisposal`：重大资产、处置日、卖出所得、结转成本、已实现收益、可选收入账户、外部所得标志、市值处理、可选欠款结算、标签、备注、幂等键和审计版本。
- `MajorAssetIncome`：重大资产、收益日、正金额、收入项目、可选资金账户、外部取得标志、标签、备注、幂等键和审计版本；不修改取得成本或市值。
- `MajorAssetExpense`：重大资产、费用日、正金额、支出项目、可选资金账户、外部支付标志、标签、备注、幂等键和审计版本；不拥有资本化标志，不直接修改成本或市值。
- `MajorAssetValuation`：重大资产、估值日、币种定点市值、来源、旧值、新值、upsert 审计、删除审计和并发版本；资产与估值日构成业务唯一键。
- `HouseholdItemAccount`：家居物品账户身份、币种、所有者、账户组、创建日期、可选资金账户、投资/自用性质、状态和审计版本；不拥有可直接调整的独立余额。
- `AssetCatalogItem`：分类、名称、规格、计量单位、默认标签和停用状态；历史交易引用后不得物理删除。
- `AssetLot`：买入事件、数量、原币单价、原币成本、基础币成本、资金来源和剩余数量。
- `AssetTransaction`：买入、卖出、转入、转出、处置、迁移导入和更正；类型不能由金额方向推断。
- `AssetValuationEvent`：资产或物品、估值日、变更前价值、变更后价值、币种、来源、备注和审计版本。
- `AssetInstallmentAgreement`：关联买入草稿、本金、期数、手续费、利息、首次记账日、资金或负债账户、状态和幂等键。

`HouseholdItemAccount` 创建只写账户和可选关系。账户中心余额、工作区市值和净资产贡献统一从 `AssetLot`、`AssetTransaction` 与 `AssetValuationEvent` 计算；空账户必须投影为零，不得在开户时预造物品主档、持仓、价格、交易或期初资金事件。投资/自用性质可修改，但只影响明确的筛选、报表或展示口径，不得追溯重写历史交易和估值。

`MajorAssetPurchase` 保存时原子创建资产身份、买入事件、取得成本和同日初始市值。支付账户为空时保存显式外部资金来源，校准样例要求资产和净资产各增加 `1.00`、负债和既有资金账户不变。支付账户绑定 `Cash-CNY` 的 `10.00` 样例则使现金减少 `10.00`、重大资产成本和市值各增加 `10.00`，全账簿资产、负债和净资产不变，证明该路径是受跟踪资产之间的内部转换。旧版零金额买入会留下账户中心对象但不进入当前持有资产范围；迁移必须保留其审计状态，新建策略必须明确允许、警告或拒绝。

`MajorAssetDisposal` 保存时原子创建卖出事件、成本结转、已实现收益和市值调整。全额样例把成本 `1.00` 的资产按 `1.50` 卖出，当前成本和市值归零，累计收益变为 `0.50`。部分卖出样例从成本/市值 `10.00/10.00` 的资产结转成本 `4.00`、取得 `6.00` 并绑定 `Cash-CNY`：剩余成本/市值为 `6.00/6.00`，现金增加 `6.00`，全账簿资产和净资产各增加已实现利润 `2.00`。收入账户未绑定稳定 ID 时旧程序不产生资金账户流入；目标模型必须保存显式外部所得标志，不能根据显示文字伪造账户引用，也不能丢失卖出所得。

`MajorAssetInvestment` 保存时原子创建追加投资业务头和成本增量，并按显式选项决定是否创建同额市值增量。校准样例先以 `2.00` 联动追加，把成本和市值从 `1.00` 同时增至 `3.00`；再以 `3.00` 关闭联动，只把成本增至 `6.00`，市值、账户中心余额和净资产继续保持 `3.00` 口径。支付账户为空时保存显式外部资金来源；绑定 `Cash-CNY` 的 `5.00` 样例使现金 `604.00 -> 599.00`、资产成本和市值 `6.00 -> 11.00`，全账簿资产、负债和净资产不变。新增贷款融资 `2.00` 的样例使成本和市值 `11.00 -> 13.00`、资产和负债各增加 `2.00`，现金与净资产不变。组合融资样例把 `3.00` 业务总额拆为 `Cash-CNY 2.00 + 新贷款1.00`，现金承担额按总额减贷款本金计算；全局记录展示 `3.00`，现金与负债工作区分别展示 `2.00/1.00`，三者引用同一业务事实。贷款款项留空时旧版按债权人自动生成“债权人的普通应付款”；目标产品必须显式展示生成结果并处理重名。旧版 `0.00` 追加仍会创建交易事件，迁移必须保留其审计事实。选择已关联其它资产的既有贷款后，旧版会无提示返回且不写入；Rust 必须过滤不可用候选或返回明确领域错误。两笔及以上贷款的分摊仍待校准。

`MajorAssetIncome` 保存独立收益事件并增加资产累计收益，不增加取得成本，也不创建或覆盖估值。校准样例中，`0.50` 外部收益把累计收益从 `0.00` 增至 `0.50`，但不改变账户中心和资产负债表；再绑定 `Cash-CNY` 收入 `0.25` 后，累计收益变为 `0.75`，现金、全账簿资产和净资产各增加 `0.25`。收入项目默认 `投资收益`，但候选为完整收入类别列表，必须保存稳定类别 ID。顶部全局入口不会继承账户中心选择态，资产上下文必须由命令参数或稳定选择器显式建立。

`MajorAssetExpense` 保存独立费用事件并减少资产累计收益，不增加取得成本，也不创建或覆盖估值。校准样例中，`0.50` 外部支付把累计收益从 `0.00` 降至 `-0.50`，但不改变账户中心和资产负债表；再绑定 `Cash-CNY` 支付 `0.25` 后，累计收益变为 `-0.75`，现金、全账簿资产和净资产各减少 `0.25`。支出项目默认 `资产费用`，但候选为完整支出类别树，必须保存稳定类别 ID。

## 3. 买入、持仓与处置

1. 重大资产买入至少需要名称、币种和交易日；名称为空时返回字段级错误。取得总额、支付账户和贷款按明确产品规则校验，不得依赖控件默认值隐式决定资金来源。
2. 无支付账户使用外部资金来源语义；有支付账户时资产取得和资金流出必须原子提交，资金流出逐分等于取得成本和初始市值增加额，总资产和净资产保持不变；有贷款时资产、首付、负债本金和可选计划必须共享业务版本。
3. 正金额买入创建取得成本和同日初始市值。后续市值变化只写估值事件，不得反向覆盖取得成本。
4. 兼容读取必须识别零金额重大资产并保持零汇总；当前持有、所有记录过和账户中心三个范围的包含规则必须稳定、可解释和可测试。
5. 物品买入至少需要物品账户、分类、名称、数量、单价或金额和交易日；数量必须大于零，金额使用币种定点精度。
6. 单价、数量和金额的联动必须有明确主输入字段，舍入差额不得通过二进制浮点累计。
7. 买入保存原子创建交易和持仓批次；存在资金账户时同时创建资金分录，不得先生成孤立持仓。
8. 重大资产卖出必须绑定稳定资产 ID，卖出所得必须大于零；有收入账户时必须绑定稳定账户 ID，显示文字不构成领域引用。
9. 全额或部分卖出原子结转成本、确认已实现收益并按所选规则调整市值。全额校准公式为 `1.50 - 1.00 = 0.50`；绑定收入账户的部分卖出校准公式为所得 `6.00 -` 结转成本 `4.00 = 2.00`，资金账户流入 `6.00`。无收入账户时保存为外部所得，不生成资金账户分录。
10. 追加投资必须绑定工作区当前选中资产的稳定 ID。勾选同步市值时成本与市值按同一金额增加；关闭时只增加成本，不得改写估值历史、账户中心余额或净资产。
11. 无支付账户的正金额追加保存为外部资金来源，不生成资金账户流出；零金额历史事件必须可迁移和查询，新建是否允许零金额由显式产品规则决定。
12. 工作区命令按稳定资产 ID 和“追加投资”语义寻址；旧版数字命令 ID 在不同会话观察到 `1223` 与 `574`，不得硬编码为领域、路由或自动化合同。
13. 新增贷款融资必须原子创建负债身份、本金增加、资产追加事件、成本增量、可选市值增量和资产债务关系。复用未关联既有贷款时只创建资产追加、可选市值和关系事件，不得重复增加本金；同一资产允许关联多笔贷款。支付账户和贷款并存时必须保存资金来源分配，来源金额合计等于投资总额，现金承担额为总额减贷款分配额。不可复用的既有贷款必须在候选阶段过滤或返回明确错误，不得静默关闭且无写入。
14. 投资收益金额必须大于零并绑定稳定资产和收入项目 ID。旧程序对 `0.00` 静默停留在编辑器，Rust 版必须给出明确字段级错误。
15. 外部取得收益不生成资金账户分录；绑定资金账户时，收益事件、现金流入、资产绩效和全局财务记录索引必须原子提交。
16. 投资费用金额必须大于零并绑定稳定资产和支出项目 ID。旧程序对 `0.00` 静默停留在编辑器，Rust 版必须给出明确字段级错误。
17. 外部支付费用不生成资金账户分录；绑定资金账户时，费用事件、现金流出、资产绩效和全局财务记录索引必须原子提交。
18. 卖出或处置必须指定数量、收入、费用和成本结转策略；可用数量或可结转成本不足时禁止提交。
19. 修改或撤销历史交易必须通过可审计更正，不得破坏后续卖出、估值或报表引用。

## 4. 价值与成本规则

1. 购买成本来自有效买入批次和成本结转，不被后续估值覆盖。
2. 当前市值取不晚于查询时点的最新有效估值；没有估值时采用何种回退值必须经真实样例校准后固定。
3. 重大资产市值保存独立 `MajorAssetValuation`。当前版本实际使用 `TEditSecurityPriceFm` 按日期维护快照；旧 `TAssetIncrementDlgFM` 无当前用户入口，不作为独立产品功能复刻。
4. 估值变化默认是未实现损益，不生成资金流水、收入或支出；处置时才按成本结转规则计算已实现损益。
5. 同资产同日只有一个当前有效估值版本。校准样例中，已有 `2026-08-03 / 2.50` 时再次添加同日 `3.00`，历史行数不变且原行更新为 `3.00`。目标实现采用显式 upsert 并保存旧值、新值和操作者审计。
6. 跨日期新增形成独立历史点；当前市值取不晚于查询时点的最新有效快照。删除最新快照后回退到最近较早日期；旧版删除无二次确认，Rust 版必须提供确认或可撤销机制并保留删除审计。
7. 市值允许显式保存 `0.00`。校准样例从 `2026-08-02 / 1.00` 新增 `2026-08-03 / 0.00` 后，成本仍为 `1.00`、累计收益仍为 `0.00`，当前市值按零值投影。
8. 修改锁定资产和估值日，只更新金额。若需要改变日期，使用删除旧快照并新增新快照的显式工作流，不能无痕移动历史事实。
9. 联动追加属于显式估值写入：同日 `1.00 + 2.00` 投影为当前有效 `3.00`；仅成本追加不得生成或修改估值版本。
10. 投资收益属于已实现损益事件：增加累计收益但不修改取得成本和当前市值；只有绑定受跟踪资金账户时才增加资产负债表和净资产。
11. 投资费用属于已实现损益事件：减少累计收益但不修改取得成本和当前市值；只有绑定受跟踪资金账户时才减少资产负债表和净资产。
12. 勾选按比例减少市值时，市值减少额由处置前成本、市值和结转成本确定。已验证成本等于市值的样例按 `4.00 / 10.00` 结转后市值同步减少 `4.00`；成本与市值不相等时的比例精度、货币舍入和尾差归属不得臆测。

## 5. 分期买入规则

1. 分期向导先校验完整物品买入信息，再创建分期草稿；缺少分类或名称时不得进入计算阶段。
2. 本金、期数、手续费和利息均使用定点小数；每期分配、尾差和日期顺延规则在真实样例校准前保持可替换策略。
3. 完成操作原子创建买入交易、持仓批次、分期协议、负债或资金分录和计划交易。
4. 取消、校验失败或保存失败不得留下协议、占位持仓、提醒或计划分录。
5. 提前还款、逾期、修改计划和撤销买入必须有显式状态迁移，不能直接覆盖历史期次。

## 6. 查询投影

- 重大资产与物品的交易明细、当前持有范围、购买成本、市值和成本市值构成绑定同一账户、范围和查询时点。
- 成本列表、市值列表、合计和图形从同一不可变查询快照生成，避免刷新过程中相互不一致。
- 当前持有范围排除清仓和兼容零金额资产；所有记录范围继续保留其交易、收益、估值和主数据。
- 重大资产收益在资产交易明细、资产累计收益、可选资金账户工作区和全局财务记录中投影同一业务事件，不能复制成互不关联的多笔交易。
- 重大资产费用在资产交易明细、资产累计收益、可选资金账户工作区和全局财务记录中投影同一业务事件，不能复制成互不关联的多笔交易。
- 旧程序构成图例会保留零金额和清仓资产并显示 `0.00`，环图扇区只绘制非零值。目标产品若优化空状态，必须保证列表、图例、合计和导出口径一致并记录兼容差异。
- 跨币种投影保存原币金额、汇率方向、汇率来源和快照时间；原币与基础币合计不得混加。
- 导出与打印复用当前查询快照，不在导出过程中重新读取并混入后续写入。

## 7. 验收缺口

- 重大资产追加投资的多贷款分摊、非人民币、标签、修改、删除、重复提交、并发冲突和失败回滚；新增贷款融资、未关联既有贷款成功复用、现金加贷款部分融资、追加投资支付账户、买入支付账户与卖出收入账户稳定绑定已验证。已关联其它资产的既有贷款提交会静默无写入，仍需校准完整筛选和额度规则。
- 支付账户买入、收入账户部分卖出和成本/市值分摊的已完成受控样本及核对结果见 `artifacts/runtime-validation/RT14-major-asset-cash-partial-notes.md`；仍需成本不等于市值的比例、舍入和尾差样例。
- 投资收益的非默认收入项目报表口径、非人民币、标签、保存并继续、修改删除和失败回滚；外部取得、绑定 `Cash-CNY` 和冷启动页面金额已验证。
- 投资费用的非默认支出项目报表口径、非人民币、标签、保存并继续、修改删除、失败回滚和冷启动页面金额复核；外部支付和绑定 `Cash-CNY` 的正金额保存已验证。
- 零金额及清仓重大资产的导出投影；其“所有记录过的资产”、零值图例和冷启动已验证。
- 市值删除唯一剩余快照、历史/未来日期、负数、大额、其它币种精度、汇率快照、并发、撤销、审计导出和失败回滚；跨日新增、同日 upsert、修改、删除最新值回退和未实现价差投影已验证。
- 卖出费用、取消按比例减少市值、成本不等于市值时的比例分摊、超额成本和其它金额边界；全额卖出 `1.50 - 1.00 = 0.50` 与绑定账户的部分卖出 `6.00 - 4.00 = 2.00` 已验证。追加投资的零金额、联动、不联动、绑定支付账户、新增贷款融资、未关联既有贷款复用和现金加贷款组合已验证；两笔及以上贷款分摊仍待验证。
- 分期信息、确认页、每期尾差、日期顺延和完成后的真实分录。
- 成本市值构成的分组、颜色、百分比、缺失估值和负值策略。
- 跨币种、并发编辑、幂等、失败回滚及导出打印。
