## 3. 当前可确认结论

- 原软件的 `财务报表` 页面不是单一报表，而是一个左侧树状报表导航中心。
- 至少已经实测确认两个大分组：
  - 日常收支类
  - 资产负债类
- 还可见第三个分组：
  - 投资类

## 4. 对 Rust 重构的意义

- `财务报表` 需要设计为“报表导航容器 + 具体报表页”的结构。
- 左侧分组树和右侧报表内容区应解耦。
- `筛选` / `操作` / `日期范围` 是报表通用交互层，应抽为公共能力。

## 5. 尚待继续实测

- 报表精确 SQL、投资收益率与年化收益率公式
- 筛选页签的边界值、无效组合和恢复默认语义
- 排序、钻取、图表序列开关、导出格式和打印预览
- 概况页 `TUsableMoneyChartFrame` 的独立空态、有数据态和交互
