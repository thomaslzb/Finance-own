# MoneyHome8 覆盖度状态

本文档用于回答三个问题：

1. 哪些功能域已经有较强证据支持
2. 哪些功能域已经能说明数据流
3. 哪些地方仍然缺乏正式结构或 UI 实测

状态说明：

- `高`
  - 已有多源证据（UI / INI / RC / 数据源）支撑
- `中`
  - 已有部分证据，但缺正式表结构或页面细节
- `低`
  - 只有间接线索或仍依赖推断
