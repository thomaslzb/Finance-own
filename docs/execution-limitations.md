# 当前会话执行限制

本文档只记录当前这次 Codex 会话里已经反复出现、并且会影响继续取证的执行限制。

## 1. GUI 相关限制

### 1.1 `MoneyHome8.exe` 启动不稳定

已出现的现象：

- `Start-Process` 有时会超时
- 超时后不一定能稳定留下可见进程
- 有时能看到窗口标题 `test - 财智8`
- 有时进程直接不存在

当前影响：

- 难以保证每一轮都能稳定继续 UI 页面取证

### 1.2 窗口可能最小化到离屏坐标

已出现的现象：

- UIA 读取到窗口在 `-32000,-32000`

当前影响：

- 桌面截图可能只截到桌面而不是程序窗口
- 快捷键触发后页面状态容易丢失

### 1.3 快捷键切换会话不稳定

已出现的现象：

- 针对 `财务分析` 子页的点击后，多张截图重新掉回桌面
- 无法稳定证明每一次点击都切到目标页

当前影响：

- `财务诊断 / 财务规划 / 财务目标`
- `记账`
- `财务报表` 投资类子页

这些页面仍缺少高质量的真实页面证据。

### 1.4 `pywinauto` / `pywin32` 依赖可部分使用，但不稳定

已确认：

- 通过补充 `PYTHONPATH` 和 DLL 目录，`win32api`、`win32ui`、`pywinauto` 曾成功导入

当前问题：

- 再次尝试时，`win32gui` 出现：
  - `ImportError: DLL load failed while importing win32gui: 找不到指定的模块`

当前影响：

- 无法在本轮稳定用 `pywinauto`/Win32 API 接管窗口恢复与点击

## 2. 数据层相关限制

### 2.1 主账本正式认证未打通

已确认：

- `test.mh8` 为 `Standard Jet DB`
- `SystemDB=mh.mdw` 后错误收敛到账号或口令无效

当前影响：

- 无法直接枚举主账本正式表结构
- 无法抽取主账本真实样例数据

### 2.2 内置库正式认证未打通

已确认：

- `MoneyHome8.data` 可解压为 Jet 内置库
- 同样受工作组认证控制

当前影响：

- 无法正式读取内置库表结构
