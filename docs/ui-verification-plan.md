# UI 补证计划

本文档面向当前仍未完成页面级实测的功能区，明确下一轮 UI 验证应该优先补哪些页面，以及每页要验证什么。

## 1. 当前已拿到真实页面证据

- 财务数据
  - 账户中心
- 财务报表
  - 日常收支类
  - 资产负债类
- 财务分析
  - 财务预算空状态

## 2. 当前 UI 补证优先级

### Priority A：记账工作区

目标：

- 证明 `记账` 是独立工作区，而不是 `财务数据` 下的别名

希望拿到的证据：

- 顶部显示为 `记账`
- 左侧或局部导航结构
- 至少一个可见录入页或流水页

### Priority B：财务报表的投资类

目标：

- 拿到投资类子报表的至少一页真实截图

希望拿到的证据：

- 左侧投资类具体子项
- 右侧空状态或查询面板
- 标题是否与 `TRptInvest* / TRptStockTrend* / TRptFundTrend*` 对应

### Priority C：财务分析的三张子页

目标：

- 拿到 `财务诊断` / `财务规划` / `财务目标` 的真实页面

希望拿到的证据：

- 标题
- 空状态或输入入口
- 操作按钮
- 是否出现专题输入向导

### Priority D：财务数据剩余子页

目标：

- 补齐 `概况` / `财务记录` / `投资一览` / `标签`

希望拿到的证据：

- 每页主标题
- 主要操作按钮
- 是否为空状态、列表页或统计页

## 3. 当前最现实的 UI 风险

- 主程序窗口可能最小化到 `-32000,-32000`
- 快捷键切换不稳定，部分截图会掉回桌面
- UAC / 管理员权限可能影响自动化焦点

## 4. 建议的补证方式

### 方式 A：最小化风险点击

- 只点击左侧或顶部一级入口
- 每次点击后立刻截图
- 不在同一轮里连续触发太多快捷键

### 方式 B：页面即刻固化

- 只要看到新页面，就立即写观察文档
- 不等待 UIAutomation 完全一致再记录

### 方式 C：优先空状态页

- 空状态页最稳定，也最容易识别工作区边界
- 可优先寻找：
  - 无预算
  - 无报表
  - 无目标
  - 无数据提示

## 5. 成功标准

- `记账` 至少有一张真实工作区截图
- `财务报表` 投资类至少有一张真实子页截图
- `财务分析` 诊断/规划/目标至少各有一张真实子页截图
