# 代码与类型映射推断

本文档基于 `mhlink.mdb` 的 `TBSecuPrice` 样本，以及 `MoneyHome8.cache` / `Investment.cache` 中的代码与名称对照，对当前可见的类型编码做技术推断。

说明：

- 下述结论分为“已确认事实”和“当前高可信推断”。
- 其中“推断”仍需未来用正式表结构或 UI 行为验证。

## 1. `TBSecuPrice.ObjType`

### ObjType = 4

已确认事实：

- 样例代码：
  - `002560`
  - `004666`
  - `320007`
  - `519674`
  - `200010`
  - `952009`
- 在缓存中对应名称：
  - `诺安和鑫混合A`
  - `长城久嘉创新成长混合A`
  - `诺安成长混合A`
  - `银河创新成长混合A`
  - `长城双动力混合A`
  - `国泰海通君得鑫两年持有混合A`

当前结论：

- `ObjType = 4` 高可信对应“场外基金/公募基金/混合债券股票基金类对象”。

### ObjType = 3

已确认事实：

- 中国市场样例代码：
  - `71A0001` -> `上证指数`
  - `7603248` -> `锡华科技`
  - `7688790` -> `昂瑞微-UW`
  - `8180503` -> `中航北京昌保租赁住房REIT`
  - `8900074` -> `深证100E`
  - `B920125` -> `鸿仕达`
  - `B920156` -> `海昌智能`
  - `B920186` -> `N中科仪`
- 海外市场样例代码：
  - `TESLA`
  - `FLY`
  - `ZIMVV`
  - `ZTOP`

当前结论：

- `ObjType = 3` 高可信对应“市场交易型标的”，包括：
  - A 股/北交所/新股
  - ETF / LOF / REIT / 指数产品
  - 美股或海外证券

换句话说，`ObjType = 3` 更像“证券化交易对象大类”，而不是单一某一个细品种。

### ObjType = 10

已确认事实：

- 样例代码：
  - `Au99.95`
  - `Au99.99`
  - `Au100g`
  - `AuT+D`
  - `Pt99.95`
  - `Ag(T+D)`

当前结论：

- `ObjType = 10` 高可信对应“贵金属/黄金白银现货及延期品种”。

### ObjType = 100000

已确认事实：

- 唯一样例：
  - `SecuCode = MHLINKID`
  - `CurrType = 0`
  - `PriceDate = 2025-12-01`

当前结论：

- `ObjType = 100000` 很可能不是普通投资标的，而是 `mhlink.mdb` 自身的内部标识或版本/基准记录。

## 2. `TBSecuPrice.CurrType`

### CurrType = 1

已确认事实：

- 对应样本大量为中国市场基金、ETF、A 股、黄金品种

当前结论：

- `CurrType = 1` 高可信对应人民币计价。

### CurrType = 2

已确认事实：

- 对应样本包含大量美股代码：
  - `TESLA`
  - `FLY`
  - `ZTOP`
  - `ZIONZ`

当前结论：

- `CurrType = 2` 高可信对应美元计价。

### CurrType = 8

已确认事实：

- 当前样本仅见：
  - `TESLA`

当前结论：

- `CurrType = 8` 可能是某个特殊海外市场口径、单独证券类别或历史兼容值。
- 证据仍弱，暂不做强绑定。

### CurrType = 0

已确认事实：

- 当前仅见：
  - `MHLINKID`

当前结论：

- 更像保留值或系统内部值，而不是正常货币。

## 3. `Investment.cache` 后缀类别码

### `_4`

样本：

- `952009_4` -> `国泰海通君得鑫两年持有混合A`
- `200010_4` -> `长城双动力混合A`
- `004666_4` -> `长城久嘉创新成长混合A`
- `320007_4` -> `诺安成长混合A`

当前结论：

- `_4` 高可信对应“场外基金/公募基金产品”。

当前样本规模：

- `Investment.cache` 中约 `24314` 条 `_4` 类记录

### `_3`

样本：

- `71A0001_3` -> `上证指数`
- `8900074_3` -> `深证100E`
- `8180503_3` -> `中航北京昌保租赁住房REIT`
- `B920186_3` -> `N中科仪`
- `7688805_3` -> `健信超导`

当前结论：

- `_3` 高可信对应“交易型市场标的”，包括：
  - 股票
  - 指数
  - ETF/LOF/REIT
  - 新股
  - 部分海外证券

当前样本规模：

- `Investment.cache` 中约 `78763` 条 `_3` 类记录

### `_9`

样本：

- `400005_9` -> `东方金账簿货币A`
- `000494_9` -> `南方现金通货币B`
- `180009_9` -> `银华货币市场B`

当前结论：

- `_9` 高可信对应“货币基金/现金管理类产品”。

当前样本规模：

- `Investment.cache` 中约 `286` 条 `_9` 类记录

## 4. 对 Rust 重构的直接影响

### 4.1 枚举设计

建议引入：

- `InvestmentObjectType`
  - `FundLikeOffMarket`
  - `TradableMarketObject`
  - `PreciousMetal`
  - `SystemMarker`
  - `Unknown(i32)`

- `CurrencyType`
  - `Cny`
  - `Usd`
  - `Special(i32)`

- `CatalogTypeCode`
  - `MarketTradable`
  - `Fund`
  - `MoneyFund`
  - `Unknown(i32)`

### 4.2 检索与展示

- `mhlink.mdb.TBSecuPrice`
  - 提供价格与数值分类
- `Investment.cache`
  - 提供名称与类别索引
- `MoneyHome8.cache`
  - 提供拼音/缩写检索键

这三者应组合使用，而不是由任一单源独立承担全部职责。

## 5. 待验证问题

- `ObjType = 3` 是否还覆盖港股、债券 ETF、期权等更多交易型对象
- `CurrType = 8` 的真实币种/市场含义
- `_3 / _4 / _9` 是否在所有缓存条目中稳定成立
- `TBObjectType` / `TBSecuType` 表是否能给出这些码值的官方定义
