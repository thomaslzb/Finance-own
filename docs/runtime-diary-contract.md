# 日记运行合同

本文档记录 MoneyHome8 日记功能在指定测试账簿中的动态行为，并把已验证行为转换为 Rust 重构约束。尚未完成真实操作验证的导出格式、跨年月搜索范围和财务日历“查看”下钻不视为兼容结论。

## 1. 验证边界

- 目标程序：`C:\Program Files (x86)\MoneyWise\MoneyHome8\Program\MoneyHome8.exe`
- 唯一可写账簿：`C:\DCG-SZ\IT Manage\Private\Personal-Docs\test.mh8`
- 受控日记日期：`2026-08-03`
- 日记创建、修改、放弃未保存更改、搜索、查看全部、冷启动、财务日历投影和删除均使用该受控记录。
- 最终账簿已恢复到长度 `18,669,568`、SHA-256 `D8E4AE302231A7A9B99B06D28C4D83500F8CD32D95F003814039E91EB0E165AC`；MoneyHome8 进程、`~$test*` 和 `test001*` 均为 `0`。

## 2. 已验证交互

### 2.1 编辑与持久化

- 编辑器包含日期、字体、字号、粗体、斜体、下划线、左中右对齐、项目符号、文字颜色、富文本正文和保存。
- 空正文保存被阻止并提示 `请输入日记内容`。
- 粗体正文保存后，重新进入修改页仍显示粗体按钮激活，证明正文与至少粗体格式一起持久化。
- 修改已有日记时，日期和原正文会加载到同一编辑器。
- 修改后直接关闭会提示 `你已修改2026-08-03的日记内容，是否保存更改？`；选择“否”后重新打开仍保留关闭前的已保存版本。
- 正式保存修改后，月度篇数保持 `1`；关闭并重新启动 MoneyHome8 后，日期、正文和篇数仍存在。

本轮自动化对富文本控件执行“全选后替换”时未可靠清空原正文，最终列表出现新旧文本拼接。该现象属于输入工具与旧富文本控件的交互限制，不能据此推断 MoneyHome8 的正常人工修改规则。

### 2.2 列表、搜索与查看全部

- 默认列表按年和十二个月导航，标题显示 `YYYY年M月 共N篇`。
- 搜索对话框只有一个搜索内容字段和确认命令。
- 命中搜索显示 `搜索：updated 共1篇`；无匹配时不弹错误，显示 `搜索：NoSuchDiary-20260803 共0篇`。
- “查看全部”清除搜索结果模式并切换为 `全部日记 共1篇`。
- 只有一个受控月份存在数据，因此搜索是否跨全部年月、大小写规则、分词规则和排序仍待验证。

### 2.3 导出

- “导出列表”打开标准“浏览文件夹”对话框，提示 `请选择一个文件夹来保存导出的日记`。
- 未选择目录时“确定”禁用。
- 本轮没有成功完成导出，文件命名、扩展名、编码、富文本保留方式、当前月/搜索/全部列表的导出范围和覆盖策略仍待真实验证。
- 自动化向旧标准对话框发送目录选择消息时 MoneyHome8 意外退出；主账簿和恢复文件已先行归档，冷启动确认日记仍存在。该退出只记录为自动化限制，不标记为软件导出失败。

### 2.4 删除与财务日历

- 删除前提示 `您确定删除该日记吗？`，提供“是/否”。
- 确认后月度列表立即变为 `共0篇`。
- 日记存在时，财务日历 `2026-08-03` 的右侧摘要显示“日记：正文摘要”和“查看”，同时保留同日“有账务记录”。
- 删除日记后重新打开财务日历，“日记”摘要立即消失，“有账务记录”保持不变，证明日历按日期读取日记事实而不是保存第二份日记。
- 当前自动化没有成功触发“查看”下钻，因此目标页面、只读/编辑权限和关闭返回行为仍待验证。

## 3. Rust 领域合同

`DiaryEntry` 至少应包含：

- 稳定 `diary_id` 和所属 `ledger_id`。
- 账簿本地自然日 `diary_date`；不能由系统 UTC 日期静默换日。
- 带显式格式版本的安全富文本正文，以及由正文派生的规范化纯文本搜索投影。
- `created_at`、`updated_at`、`row_version` 和可审计删除状态。

富文本格式应使用受限、可迁移的结构化表示，覆盖已观察的字体、字号、粗体、斜体、下划线、对齐、项目符号和文字颜色。不得把任意可执行 HTML、脚本或不受控外部对象作为账簿内容加载。

保存命令必须在一个事务中完成正文、格式版本、纯文本投影和更新时间更新。修改沿用稳定 `diary_id` 并核对 `row_version`；冲突不得静默覆盖。脏草稿选择“否”只丢弃页面草稿，选择“是”必须走与保存按钮相同的校验和提交路径。

## 4. 查询与投影合同

建议真相表和查询边界：

```text
diary_entries
  -> 按 ledger_id + diary_date 范围读取月度列表与计数
  -> 按规范化纯文本执行显式范围搜索
  -> 按当前列表查询快照导出
  -> 按 ledger_id + diary_date 投影到财务日历
```

- 月度计数、搜索结果、查看全部和财务日历必须读取同一日记真相与删除状态。
- 搜索不得匹配富文本控制标记，结果应返回稳定 ID、日期和安全摘要。
- 导出开始时冻结查询范围和排序，所有文件只能写入用户明确选择的目录；文件名必须清理路径分隔符和保留名。
- 财务日历只保存页面年月与选中日期状态，不复制日记正文。日历详情命令按稳定来源 ID 打开日记页面。
- 删除应在同一事务中更新日记可见状态和搜索投影；提交后列表计数与日历查询必须同时反映删除结果。
