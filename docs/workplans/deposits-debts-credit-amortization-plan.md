# 存款、债务、信用卡与摊还需求计划

本文档承接 `three-client-requirements-analysis.md`、`amount-currency-exchange-rate-plan.md`、`schedule-reminder-occurrence-plan.md`、`limit-alert-budget-rule-evaluation-plan.md`、`runtime-deposits-and-bank-wealth-contract.md` 和 `runtime-debts-credit-and-amortization-contract.md`，定义 Finance Own 第一版定期存款、银行理财、债权债务、信用卡账单、分期和摊还的需求边界。本文只定义需求口径，不把未通过真实样例校准的旧版利息、收益、摊还或最低还款公式标记为已兼容。

## 1. 目标

1. 支持定期存款、银行理财、借入、借出、应收、应付、预收、预付、垫付、待摊、信用卡账单和分期的基础对象。
2. 区分合同、计划、实际交易、派生投影和审计，避免把计划值当作事实流水。
3. 所有资金流必须生成可平衡分录，失败时整体回滚。
4. 支持 PC/Web 完整维护，手机端摘要查看和提醒状态。
5. 支持自动续存、到期、还款、收款和分期入账的幂等任务边界，但第一版不承诺完整后台自动执行闭环。
6. 支持敏感卡号、联系方式和旧迁移证据的隐私边界。

## 2. 非目标

1. 第一版不承诺旧版全部利息、闰年、尾差、提前支取、最低还款、逾期费和摊还公式完全兼容。
2. 第一版不承诺自动银行接口、自动账单抓取、自动券商或网贷平台接口。
3. 第一版不把信用卡或网贷自动计划当成无审计的后台静默入账。
4. 第一版不在手机端提供复杂合同编辑、账单规则配置或冲突解决。
5. 第一版不上传旧 MoneyHome8 原始合同、旧账单、旧路径、旧原始行、迁移审计、迁移报告或脱敏摘要。

| `ledger_id` | 所属账本 |
| `account_id` | 所属存款账户 |
| `currency_code` | 币种 |

| `start_date` | 起息业务日期 |
| `term_value` | 期限数值 |
| `term_unit` | `day`、`month`、`year` |
| `maturity_date` | 到期业务日期 |
| `annual_rate` | 年利率定点值 |
| `rate_rule_version` | 利率规则版本 |
| `rounding_mode` | 舍入口径 |
| `auto_renewal_policy` | 自动续存策略 |
| `status` | `active`、`matured`、`withdrawn`、`renewed`、`archived` |
| `version` | 对象版本 |

`BankWealthPositionDto` 字段：

| 字段 | 说明 |
| --- | --- |
| `position_id` | 持仓 ID |
| `ledger_id` | 所属账本 |
| `wealth_account_id` | 银行理财账户 |
| `product_id` | 产品 ID |
| `principal_minor` | 持仓本金 |
| `purchase_date` | 申购业务日期 |
| `maturity_date` | 到期业务日期 |
| `terms_snapshot_id` | 产品条款快照 |
| `calculation_status` | `input_only`、`pending_calibration`、`calibrated`、`manual_override` |
| `status` | `active`、`redeemed`、`matured`、`archived` |

`BankWealthProductDto` 字段：

| 字段 | 说明 |
| --- | --- |
| `product_id` | 银行理财产品稳定 ID |
| `ledger_id` | 所属账本 |
| `product_name` | 产品名称 |
| `product_code` | 产品代码，可为空 |
| `issuer_party_id` | 发行机构或管理人 |
| `risk_level` | 风险等级或结构化未知 |
| `currency_code` | 产品币种 |
| `terms_snapshot_id` | 当前条款快照 |
| `status` | `active`、`closed`、`archived` |
| `version` | 对象版本 |

规则：

1. 存款账户身份与单笔定期存单分离，修改账户资料不能覆盖历史存单条款。
2. 到期本息、预期收益和累计回报是派生结果，不能成为唯一业务事实。
3. 续存不能原地覆盖旧存单；旧存单结算和新存单生成必须在同一命令中保持一致。
4. 银行理财产品有历史持仓或交易时不能物理删除，只能注销、归档或保留历史引用。
5. 产品条款修改只影响新申购或明确生效日后的事件，已有持仓引用申购时快照。
6. 银行理财申购、赎回、分红、其它费用、利息收入和到期结算必须作为独立事件保存，不能只改写持仓本金或收益字段。
7. 持仓本金、实际现金流、预期收益、实际收益和年化收益率必须在列表、详情和报表中使用同一估值日期、产品条款快照和公式状态。
8. 银行理财产品核销或关闭必须保留历史持仓和交易引用；被引用产品删除必须进入影响预览或阻断。

## 4. 债权债务与摊还对象

`DebtAgreementDto` 字段：

| 字段 | 说明 |
| --- | --- |
| `agreement_id` | 稳定合同 ID |
| `ledger_id` | 所属账本 |
| `direction` | `borrowed`、`lent`、`receivable`、`payable`、`prepaid`、`deferred` 等显式方向 |
| `party_id` | 对手方 |
| `currency_code` | 币种 |
| `initial_principal_minor` | 初始本金 |
| `remaining_principal_minor` | 剩余本金投影 |
| `business_date` | 合同业务日期 |
| `schedule_rule_version` | 计划规则版本 |
| `interest_rule_version` | 利率规则版本 |
| `status` | `active`、`settled`、`bad_debt`、`archived` |
| `version` | 对象版本 |

`RepaymentScheduleItemDto` 字段：

| 字段 | 说明 |
| --- | --- |
| `schedule_item_id` | 计划项 ID |
| `agreement_id` | 所属合同 |
| `schedule_version` | 计划版本 |
| `period_no` | 期次 |
| `planned_date` | 计划还款或收款日期 |
| `principal_minor` | 计划本金 |
| `interest_minor` | 计划利息 |
| `fee_minor` | 计划手续费 |
| `status` | `planned`、`posted`、`skipped`、`superseded` |
| `posted_transaction_id` | 已入账交易 ID |

规则：

1. 借入、借出、应收、应付、预收、预付、垫付和待摊必须由显式方向表达，不能只靠金额正负号推断。
2. 计划值和实际交易不能混写到同一字段。
3. 计划重算必须保存旧版本、变更原因、生效日期和已执行期次保护。
4. 已入账期次不能被无痕覆盖；未来未执行期次可在影响预览后由新版本替代。
5. 坏账是显式终止或减值命令，不能通过删除合同或把余额改为零实现。
6. 借入、借出、预收、预付、收回、返还、提前结清、坏账、垫付和报销是不同命令，必须保存方向、对手方、合同版本和资金分录。
7. 本金、利息、手续费、罚息、奖励和坏账损失必须逐分分配到明确组成项；净额不能替代分项事实。
8. 网贷借出、收款计划、奖励、转让、坏账和收回必须共享稳定合同或平台流水身份，状态流转和幂等重试不能生成孤立交易。

## 5. 信用卡账单与分期

`CreditCardAccountDto` 字段：

| 字段 | 说明 |
| --- | --- |
| `account_id` | 信用卡账户 ID |
| `ledger_id` | 所属账本 |
| `currency_codes` | 支持币种 |
| `statement_day_rule` | 账单日规则版本 |
| `payment_due_rule` | 还款日规则版本 |
| `credit_limit_minor` | 授信额度 |
| `minimum_payment_rule_version` | 最低还款规则版本 |
| `sensitive_card_ref` | 受保护卡号引用，不进入普通日志 |
| `status` | `active`、`closed`、`archived` |
| `version` | 对象版本 |

`BillingDayRuleDto` 字段：

| 字段 | 说明 |
| --- | --- |
| `rule_id` | 账单日或还款日规则 ID |
| `rule_kind` | fixed_day、last_day_of_month、days_after_statement、custom |
| `day_of_month` | 固定日，`rule_kind=fixed_day` 时必填 |
| `offset_days` | 相对账单日偏移天数，`days_after_statement` 时必填 |
| `short_month_policy` | clamp_to_month_end、reject_missing_day、next_month_first |
| `effective_from` | 规则生效业务日期 |
| `effective_to_exclusive` | 规则失效业务日期，可为空 |
| `rule_version` | 规则版本 |

`CreditStatementDto` 字段：

| 字段 | 说明 |
| --- | --- |
| `statement_id` | 账单 ID |
| `account_id` | 信用卡账户 |
| `currency_code` | 币种 |
| `period_start` | 账期开始业务日期 |
| `period_end` | 账期结束业务日期 |
| `statement_date` | 账单业务日期 |
| `due_date` | 还款业务日期 |
| `billed_amount_minor` | 账单金额 |
| `minimum_payment_minor` | 最低还款金额 |
| `statement_rule_snapshot_id` | 生成账单时采用的账单日规则快照 |
| `payment_rule_snapshot_id` | 生成账单时采用的还款日规则快照 |
| `generated_by_command_id` | 账单生成命令 ID，用于幂等 |
| `source_transaction_version_set` | 账单覆盖交易版本集合摘要 |
| `status` | `open`、`billed`、`paid`、`overdue`、`archived` |
| `version` | 对象版本 |

规则：

1. 信用卡交易先进入未出账集合，再按账单规则归属账单。
2. 账单生成后必须保存与交易的稳定关联，不能只按日期范围即时猜测。
3. 双币信用卡共享账户身份和账单规则，但每个币种分别维护额度、账单和还款投影。
4. 卡号、联系方式和敏感备注必须使用安全存储或受保护字段，不进入普通日志、截图、导出或搜索索引。
5. 分期协议必须保存本金、期数、手续费规则、每期金额、自动扣减规则和状态；提前结清或取消只影响未入账期次。
6. 账单日和还款日规则必须版本化保存；固定日、每月最后一天和短月份不存在日期必须由领域层返回标准化结果或结构化错误。
7. 账单生成必须冻结账单日规则、还款日规则、最低还款规则、交易版本集合和账本时区；后续规则调整只影响未来账单。
8. 短月份处理必须由 `short_month_policy` 明确表达：顺延到月末、拒绝不存在日期或顺延到次月一日，不能由 Flutter UI 自行猜测。
9. 同一账户、币种、账期和生成命令幂等键重复提交必须返回原账单，不得重复关联交易或重复生成还款提醒。
10. 账期重叠、交易版本变化、账单已还款、账单已归档或还款已入账时，重新生成必须进入影响预览。
11. 还款分配必须按账单、币种、本金、利息、手续费、罚息和最低还款状态逐分拆分；净额不能替代分项事实。
12. 信用卡账单导入来源只作为 PC 本地导入预览；确认后写入新系统账单和交易对象，旧账单文件、旧路径、旧原始行和导入诊断不上传云端。

## 6. 命令与分录平衡

第一版命令至少包括：

| 命令 | 分录要求 |
| --- | --- |
| 创建定期存单 | 写入存单、资金分录和审计 |
| 到期支取 | 拆分本金、利息、税费或调整 |
| 续存 | 结清旧周期并生成新条款快照 |
| 银行理财申购 | 保存申购本金、资金账户和产品条款快照 |
| 银行理财赎回 | 区分赎回本金、实际收回金额、费用和收益 |
| 银行理财分红 | 区分现金分红、再投资和税费 |
| 银行理财其它费用 | 记录费用类别、资金账户和持仓影响 |
| 银行理财到期结算 | 结清持仓本金、实际收益、费用和现金到账 |
| 创建债务合同 | 保存合同、初始本金和计划版本 |
| 还款或收款 | 引用合同或计划项，拆分本金、利息和手续费 |
| 提前结清 | 展示剩余本金、利息、手续费、罚息、奖励和坏账影响 |
| 坏账 | 记录损失金额、原因和剩余本金处理 |
| 网贷转让 | 保存合同关系、转让价格、损益和新状态 |
| 信用卡还款 | 指定资金来源、币种、本金、利息、手续费和幂等键 |
| 分期入账 | 引用分期协议和期次 |

规则：

1. 所有写命令携带账本 ID、期望版本和幂等键。
2. 资金账户流出、负债减少、利息费用、手续费费用、收益到账和审计必须在同一事务提交。
3. 失败时整体回滚，重试不得重复扣款、到账、续存或生成分期。
4. 页面不得直接写合同余额、账单金额、期次状态或持仓余额。
5. 自动任务必须保存计划项、预期执行时间、幂等键、执行结果和重试状态。

## 8. 同步、冲突与删除

同步规则：

1. 合同、计划、账单、分期、存单、理财产品、持仓和事件作为新系统对象同步。
2. 云端不保存旧 MoneyHome8 原始合同、旧账单、旧路径、旧原始行、迁移审计、迁移报告或脱敏摘要。
3. 并发修改合同条款、账单规则、计划规则、产品条款或分期规则时进入冲突解决。
4. 云端成员权限变化不得删除 PC 本地合同、账单或存单文件数据。
5. 手机离线只保留摘要缓存或本机草稿；上传失败不得丢弃用户输入。

删除和关闭规则：

1. 存在历史交易、账单、计划、附件或审计引用时，优先关闭、注销、归档或替代版本，不做物理删除。
2. 删除前必须返回交易、账单、计划、附件、提醒、预算和目标引用影响预览。
3. 删除与其它端修改并发时进入冲突解决。
4. 关闭信用卡、债务合同、存单或理财产品不删除历史分录。

## 9. 查询与报表

查询上下文必须包含账本、对象范围、状态、日期、币种、排序、数据版本和估值日期。

报表规则：

1. 剩余本金、账单金额、存款到期本息、银行理财收益、待摊余额和图表结果可以使用可重建投影或缓存，但不能成为唯一事实。
2. 切换“仅债权”“仅债务”“忽略已完成”“当前持仓产品”或“所有交易过的产品”只改变查询参数，不写业务事实。
3. 未校准公式结果显示为 `pending_calibration`、`input_only` 或 `unsupported`。
4. 导出必须包含公式状态和查询口径，不导出敏感卡号和旧迁移证据。
5. 银行理财持仓本金、实际现金流、预期/实际收益和年化收益率必须来自同一查询快照；公式未校准时不得作为正式收益结论。
6. 债权债务构成、还款表和概况必须能追溯本金、利息、手续费、罚息、奖励和坏账损失组成。

## 10. 审计与隐私

审计必须覆盖：

1. 创建、修改、关闭、注销、归档和删除对象。
2. 到期、续存、申购、赎回、还款、收款、坏账、计划重算和分期入账。
3. 账单日调整、还款日调整、最低还款规则变化和额度变化。
4. 自动任务执行、重试、失败和回滚。
5. 冲突解决、权限阻止和引用影响预览。

隐私规则：

1. 卡号、联系方式、平台账号和敏感备注不得进入普通日志、截图、导出、错误响应或搜索索引。
2. 旧 MoneyHome8 迁移证据只保存在 PC 本地。
3. 云端不得保存旧原始文件、旧路径、旧原始行、旧字段值、迁移审计、迁移报告、脱敏摘要或 PC 机器环境诊断。
4. 错误响应和审计不得包含密码、令牌、PC 完整本地路径或旧迁移证据。

## 11. 错误码

| 错误码 | 含义 | 行为 |
| --- | --- | --- |
| `contract_direction_invalid` | 合同方向不合法 | 阻止保存 |
| `schedule_recalculation_blocked` | 已执行期次阻止无痕重算 | 返回影响预览 |
| `installment_total_mismatch` | 分期本金合计不等于协议本金 | 阻止保存 |
| `statement_period_conflict` | 账期与既有账单冲突 | 返回冲突或字段错误 |
| `billing_day_missing_in_month` | 固定账单日在目标月份不存在 | 按规则标准化或返回字段错误 |
| `billing_rule_version_stale` | 提交使用陈旧账单日或还款日规则 | 保留草稿并要求刷新 |
| `statement_generation_replay` | 账单生成命令幂等重放 | 返回原账单 |
| `statement_regeneration_preview_required` | 已有关联、已还款或版本变化时尝试重算账单 | 要求影响预览和确认 |
| `deposit_renewal_replay` | 续存幂等重放 | 返回原结果 |
| `wealth_product_reference_blocking` | 产品存在历史引用 | 返回影响预览 |
| `credit_sensitive_field_forbidden` | 敏感字段进入禁止范围 | 阻止输出 |
| `financial_formula_pending_calibration` | 公式未校准 | 标记结果状态 |
| `contract_version_conflict` | 对象版本冲突 | 进入冲突解决 |
| `wealth_position_snapshot_mismatch` | 理财列表、详情和报表快照不一致 | 阻止导出或提示刷新 |
| `repayment_allocation_invalid` | 本息费罚奖励或坏账组成不平衡 | 阻止提交 |
| `p2p_flow_orphaned` | 网贷事件缺少稳定合同或平台流水身份 | 阻止提交 |

错误响应不得包含 PC 完整本地路径、旧 MoneyHome8 原始路径、旧原始行、旧字段值、迁移审计、迁移报告、脱敏摘要、卡号、联系方式、令牌或密码。

## 12. 验收场景

1. PC 创建定期存单后生成资金分录和审计，失败时不留下半存单。
2. 自动续存重试不会重复生成新存单。
3. 银行理财申购保存产品条款快照，产品后续修改不覆盖历史持仓。
4. 债务合同计划重算保留已执行期次并返回未来影响预览。
5. 信用卡账单生成后保存交易关联，调整账单日不改写历史账单。
6. 分期协议每期本金合计等于协议本金，提前结清只影响未入账期次。
7. Web 与 PC 并发修改同一合同条款时进入冲突解决。
8. 手机只展示到期、还款、账单和同步摘要，不显示复杂规则编辑入口。
9. 导出不包含敏感卡号、联系方式、旧迁移证据或 PC 本地完整路径。
10. 旧迁移相关合同、账单、规则验证证据、迁移审计、迁移报告、脱敏摘要、旧路径和旧原始行只保存在 PC 本地。
11. 账单日管理支持固定日、每月最后一天和相对账单日偏移模式；短月份不存在日期必须按 `short_month_policy` 标准化或返回结构化错误。
12. 账单生成冻结规则快照、交易版本集合和账本时区；重复生成幂等，已还款或已归档账单重算必须先影响预览。
13. 信用卡账单导入只进入 PC 本地预览；旧账单文件、旧路径、旧原始行和导入诊断不上传云端。
14. 银行理财申购、赎回、分红、其它费用、利息收入和到期结算都生成独立事件；产品被引用时不能物理删除。
15. 理财持仓本金、实际现金流、预期/实际收益和年化收益率在列表、详情和报表中使用同一查询快照和公式状态。
16. 债权债务还款、提前结清、坏账、垫付、报销和网贷流转必须逐分拆分本金、利息、手续费、罚息、奖励和坏账损失，失败整体回滚。

## 13. 当前无需人工确认

本计划没有引入新的产品取舍；它细化的是已确认的存款、银行理财、债权债务、信用卡、分期摊还、幂等任务、分录平衡、敏感信息保护、三端职责和旧迁移证据 PC 本地保存边界。
