# 投资与高级资产校准边界需求计划

本文档承接 `three-client-requirements-analysis.md`、`amount-currency-exchange-rate-plan.md`、`reporting-planning-plan.md`、`backup-import-export-plan.md` 和当前 `implementation-backlog.md` 中的投资相关任务，定义 Finance Own 第一版对投资、证券、基金、债券、外汇、期货、贵金属、保险和重大资产的需求边界。本文只定义三端产品口径、数据状态和校准要求，不固化尚未通过真实样例验证的旧程序公式。

## 1. 核心原则

1. 第一版不得把未校准的投资成本、收益率、复杂费用、分红、拆合股、配股、债券摊余成本或保险现金价值公式标记为已兼容。
2. 第一版可以保存和展示用户可确认的投资输入、持仓输入、交易流水输入、报价输入和基础附件。
3. 已校准字段和未校准字段必须在 UI、API、报表和迁移报告中区分。
4. 旧 MoneyHome8 投资相关迁移只在 PC 本地执行，旧原始数据、旧字段值、旧路径、迁移审计、迁移报告和脱敏摘要不上传云端。
5. 三端同步只传输新系统对象和明确校准状态，不传输旧迁移证据。

## 2. 第一版范围

第一版可进入主线的能力：

| 能力 | PC | Web | 手机 |
| --- | --- | --- | --- |
| 投资账户基础展示 | 支持 | 支持 | 摘要 |
| 投资品目录选择 | 支持 | 支持 | 读取 |
| 投资输入流水列表 | 支持 | 支持 | 摘要 |
| 持仓输入展示 | 支持 | 支持 | 摘要 |
| 报价输入或手工更新 | 支持 | 支持 | 后置 |
| 附件和交割单导入 | 支持 | Web 附件上传，复杂导入后置 | 后置 |
| 复杂公式结果 | 仅已校准字段 | 仅已校准字段 | 摘要或隐藏 |
| 旧数据迁移预览 | 仅 PC 本地 | 不支持 | 不支持 |

第一版不承诺完成：

1. 自动券商接口。
2. 全部投资品类收益率与成本法兼容。
3. 公司行动自动推导。
4. 复杂税费和摊销公式。
5. 移动端复杂投资录入。
6. Web 或手机端旧 MoneyHome8 投资数据迁移。

## 3. 投资对象族

云端和 PC 本地可以表达的新系统对象族包括：

| 对象族 | 用途 | 第一版状态 |
| --- | --- | --- |
| `InvestmentCatalog` | 投资品目录、代码、名称、类型 | 可同步 |
| `InvestmentAccount` | 投资账户或资产账户扩展 | 可同步 |
| `InvestmentTransactionInput` | 用户录入或迁移后的成交输入 | 可同步 |
| `InvestmentPositionInput` | 持仓输入或迁移持仓快照 | 可同步 |
| `QuoteInput` | 用户输入或导入的报价 | 可同步 |
| `CostLotInput` | 成本批次输入或分配结果 | 仅已校准后可作为正式结果 |
| `InvestmentCalculationResult` | 成本、收益率、盈亏等计算结果 | 未校准前只能是草稿或 `pending_calibration` |
| `LegacyInvestmentMap` | 旧 ID、旧类别码和迁移诊断映射 | 仅 PC 本地 |

对象必须携带 `ledger_id`、对象 ID、版本、来源端、更新时间和校准状态。

## 4. 校准状态

投资相关字段、对象和报表必须支持校准状态：

| 状态 | 含义 | 可展示方式 |
| --- | --- | --- |
| `input_only` | 只有用户输入或迁移输入，不产生正式公式结论 | 显示输入列表和待校准提示 |
| `pending_calibration` | 已有候选计算，但未通过真实样例验证 | 不作为正式资产收益结论 |
| `calibrated` | 已通过最小样例和旧程序对照校准 | 可作为正式结果展示 |
| `manual_override` | 用户手工确认覆盖结果 | 显示手工确认来源和时间 |
| `unsupported` | 第一版不支持该公式或品类 | 展示不支持原因 |

规则：

1. 未校准公式不得进入资产总览的正式收益率结论。
2. `pending_calibration` 可以用于研发验证和 PC 本地迁移预览，但不能上传旧诊断证据。
3. 用户手工确认的结果必须记录确认人、确认时间、字段和版本。
4. 报表导出必须带校准状态，避免把未验证结果当作正式财务结论。

| `instrument_id` | 是 | 投资品 |
| `trade_date` | 是 | 成交业务日期 |
| `direction` | 是 | buy、sell、dividend、fee、transfer、adjustment 或已支持类型 |
| `quantity` | 否 | 数量，使用定点数或整数比例表示 |
| `price_minor` | 否 | 单价或报价的最小单位表达 |
| `amount_minor` | 是 | 发生金额 |
| `currency_code` | 是 | 币种 |
| `fee_minor` | 否 | 费用金额 |
| `tax_minor` | 否 | 税费金额 |

| `instrument_id` | 是 | 投资品 |

## 6. PC 端需求

PC 端支持：

1. 投资账户、投资品目录、成交输入、持仓输入和报价输入的完整查看。
2. 从旧 MoneyHome8、缓存、交割单或用户文件中做本地只读预览。
3. 将确认后的新系统投资输入写入 PC 本地 SQLite。
4. 已校准字段可进入本地报表；未校准字段必须标记状态。
5. 用户确认同步后，只上传新系统投资对象和校准状态。

PC 端禁止：

1. 把旧投资原始行、旧字段值、旧类别码诊断、迁移审计、迁移报告或脱敏摘要上传云端。
2. 在未完成样例校准前，把复杂投资收益率标为正式兼容。
3. Flutter 直接读取旧账本文件或直接写 SQLite。

## 7. Web 端需求

Web 端支持：

1. 登录后读取云端投资对象和已校准结果。
2. 管理投资品目录、投资账户和基础输入。
3. 查看 `input_only`、`pending_calibration`、`calibrated`、`manual_override` 和 `unsupported` 状态。
4. 在线上传投资相关附件，但复杂交割单解析可后置。
5. 参与 PC/Web 投资对象冲突解决。

Web 端禁止：

1. 读取 PC 本地 SQLite。
2. 读取旧 MoneyHome8 原始文件。
3. 展示旧迁移审计、迁移报告、脱敏摘要、旧路径、旧原始行或 PC 机器环境诊断。

## 8. 手机端需求

手机端第一版支持：

1. 查看投资账户和持仓摘要。
2. 查看已同步的基础投资输入列表。
3. 查看校准状态和不支持提示。
4. 接收同步失败或冲突摘要。

手机端第一版不支持：

1. 复杂投资成交录入。
2. 旧投资数据迁移。
3. 交割单解析。
4. 完整投资冲突解决。
5. 未校准公式的正式收益结论展示。

## 9. 同步和冲突

投资对象进入对象级同步，但计算结果必须受校准状态约束。

规则：

1. 投资输入创建必须带幂等键。
2. 修改投资输入、报价或持仓必须带预期版本。
3. 同一投资输入并发修改进入显式冲突。
4. PC/Web 可解决投资对象冲突；手机只展示摘要和保留本地草稿。
5. 已校准结果的输入字段发生变化时，结果必须失效或重新进入 `pending_calibration`。
6. 云端不能用未校准结果覆盖 PC 本地正式结果，反向也不能静默覆盖。

## 10. 报表和总览

报表规则：

1. 投资输入列表可以展示所有状态。
2. 资产总览可以展示已确认本金、市值或输入值，但必须标明来源。
3. 收益率、盈亏、年化、成本批次等复杂结果只有 `calibrated` 或 `manual_override` 才能作为正式结论。
4. `pending_calibration` 结果可在 PC 研发或迁移预览中展示，但不能混入正式报表汇总。
5. 导出报表必须包含校准状态字段。

## 11. 权限

| 操作 | Owner | Editor | Viewer |
| --- | --- | --- | --- |
| 查看投资输入 | 允许 | 允许 | 允许 |
| 创建投资输入 | 允许 | 允许 | 禁止 |
| 修改投资输入 | 允许 | 允许 | 禁止 |
| 手工确认计算结果 | 允许 | 允许 | 禁止 |
| 管理投资品目录 | 允许 | 允许 | 禁止 |
| 查看旧迁移诊断 | PC 本机本地权限 | PC 本机本地权限 | PC 本机本地权限 |

云端账本 Viewer 不得上传投资对象变更。PC 本地未开启同步账本没有云端成员概念。

## 12. 错误模型

投资相关错误码至少包括：

| 错误码 | 含义 | 三端处理 |
| --- | --- | --- |
| `investment_not_supported` | 当前品类或公式第一版不支持 | 展示不支持原因 |
| `investment_pending_calibration` | 公式未完成校准 | 标记结果不可作为正式结论 |
| `investment_input_invalid` | 投资输入字段缺失或非法 | 字段级提示 |
| `investment_version_conflict` | 投资对象版本冲突 | PC/Web 冲突解决，手机摘要 |
| `investment_permission_denied` | 当前角色无权写入 | 阻止上传或保留草稿 |
| `investment_legacy_local_only` | 旧迁移证据只能 PC 本地查看 | 禁止云端请求 |

错误响应不得包含旧 MoneyHome8 原始路径、旧投资原始行、旧字段值、迁移审计、迁移报告、脱敏摘要或 PC 机器环境诊断。

## 13. 校准验收门槛

某个投资公式或品类从 `pending_calibration` 变为 `calibrated` 前，至少需要满足：

1. 有真实或最小可复现样例。
2. 样例来源文件路径、旧原始行和诊断只保存在 PC 本地。
3. 已记录输入字段、预期输出、旧程序对照结果和差异说明。
4. 已验证买入、卖出、费用、税费、分红或对应品类的关键路径。
5. 已明确舍入规则、币种规则、日期口径和异常口径。
6. 已有自动化或可重复手工验证步骤。

如果以上证据不足，只能保持 `pending_calibration`、`input_only` 或 `unsupported`。

## 14. 验收要点

1. PC 可以查看和保存投资输入，但未校准收益率不会显示为正式结论。
2. Web 可以查看同步后的新系统投资对象和校准状态。
3. 手机只显示投资摘要和校准状态，不承担复杂录入。
4. 投资报表导出包含校准状态。
5. 旧投资迁移证据只保存在 PC 本地，不上传云端。
6. 投资对象并发修改进入 PC/Web 显式冲突解决。
7. Viewer 不能上传投资对象变更。
8. 已校准结果的输入变化会使计算结果失效或回到待校准。
9. 云端错误和审计不包含旧迁移证据或 PC 本地路径。

## 15. 当前无需人工确认

本计划没有引入新的产品取舍；它细化的是已确认的复杂投资公式后置、PC 本地迁移隐私、三端同步新系统对象、手机轻量能力、PC/Web 完整管理和校准前不得标记兼容的边界。
