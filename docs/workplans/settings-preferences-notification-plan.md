# 设置、偏好与通知状态需求计划

本文档承接 `three-client-requirements-analysis.md`、`account-device-ledger-membership-plan.md`、`reporting-planning-plan.md`、`security-audit-error-handling-plan.md` 和 `runtime-ledger-lifecycle-and-settings-contract.md`，定义 Finance Own 第一版设置、偏好、快捷入口、提醒通知、设备状态和生效范围的三端需求边界。本文只定义需求口径，不进入具体系统通知 SDK、秘密存储实现或 Flutter 组件实现。

## 1. 目标

第一版必须支持：

1. 区分设备级、账号级、账本级和授权级设置。
2. PC 本地未登录时仍可保存本机应用设置和本地账本设置。
3. Web 和手机登录后读取账号级偏好和当前账本级设置。
4. 提醒、计划和同步状态可以产生应用内通知。
5. 通知和设置变更遵守账本权限、设备撤销和隐私边界。
6. 设置保存失败、取消和部分失败有可解释状态，不污染其它设置分区。
7. 手机快查、远程通知、检查更新、关于页、软件许可和验证码刷新作为外围入口处理，不进入财务真相。

第一版不要求：

1. 完整系统级推送服务闭环。
2. 短信、邮件和第三方 IM 通知。
3. 复杂主题皮肤市场或插件设置。
4. 授权/许可服务完整兼容旧版本。
5. 手机端完整快捷键或桌面窗口偏好。

## 2. 设置作用域

| 作用域 | 示例 | 第一版存储口径 |
| --- | --- | --- |
| 设备级 | 窗口状态、最近打开账本、本机缓存、声音、快捷键 | 只保存在当前设备，不随账本或云同步迁移 |
| 账号级 | 昵称、默认展示偏好、通知总开关、设备显示名 | 云端账号配置，三端登录后可读取 |
| 账本级 | 账本名称、本位币、同步开启状态、备份策略、提醒规则 | 随账本对象或本地账本保存，必须限定 `ledger_id` |
| 授权级 | 许可状态、购买凭据、授权设备证明 | 独立秘密/授权存储，不进入财务对象同步 |
| 安全级 | 令牌、刷新凭据、账本密码材料 | 系统安全存储或本地加密边界，不进入普通设置表 |
| 外围入口 | 关于页、检查更新、验证码刷新、软件许可入口 | 受控配置和安全适配器，不读取账本明细 |

规则：

1. 最近账本、窗口位置和 UI 展开状态不得写入交易、余额或财务对象真相表。
2. 账本级设置必须明确是否同步；PC 本地未开启同步的账本只保存在本机。
3. 账号级设置不得包含旧 MoneyHome8 迁移审计、旧路径、旧原始行或 PC 机器环境诊断。
4. 授权级设置不得读取或上传账本内容。
5. 安全级设置不得进入普通日志、错误响应、导出文件或截图。
6. 旧程序配置、窗口状态、快捷键、最近账簿和授权协议校准证据只保存在 PC 本地；迁移到新系统时只能写入新系统设置项，不上传旧配置原文、旧路径或旧注册表/INI 片段。

## 3. 设置生效状态

设置项必须声明生效时机：

| 生效时机 | 示例 | 页面要求 |
| --- | --- | --- |
| `immediate` | 显示偏好、声音开关、列表密度 | 保存成功后立即刷新相关界面 |
| `next_open` | 账本级部分显示策略、默认页面 | 下次打开账本生效 |
| `next_start` | 启动行为、窗口级偏好 | 下次启动应用生效 |
| `requires_reauth` | 安全凭据、设备名等敏感设置 | 需要重新登录或重新授权 |
| `requires_ledger_reopen` | 账本密码、加密状态等 | 需要关闭并重开账本 |

保存规则：

1. 设置页进入时固定当前值快照。
2. 用户取消时恢复打开前草稿，不写入。
3. 单项保存失败不得污染其它设置分区。
4. 批量保存必须返回逐项结果。
5. 权限不足时返回 `ledger_readonly`、`ledger_forbidden` 或等价错误。

`SettingsSaveRequestDto` 字段：

| 字段 | 说明 |
| --- | --- |
| `scope` | device、account、ledger、license、security 或 peripheral |
| `ledger_id` | 账本级设置必填；设备级、账号级和授权级可为空 |
| `settings_snapshot_version` | 打开设置页时读取的快照版本 |
| `changes` | 待保存设置项列表，每项包含稳定设置键、目标值、预期版本和生效时机 |
| `migration_preview_id` | 从旧设置迁移时的 PC 本地预览 ID，不上传旧配置原文 |
| `idempotency_key` | 防止重复点击保存造成重复写入或重复通知 |

`SettingsSaveResultDto` 字段：

| 字段 | 说明 |
| --- | --- |
| `saved_items` | 已成功保存的设置项、版本和生效时机 |
| `failed_items` | 逐项失败原因，例如权限不足、快捷键冲突、版本冲突或安全存储不可用 |
| `effective_now_items` | 已立即生效并需要刷新页面的设置项 |
| `pending_restart_items` | 需要重启、重开账本或重新认证后生效的设置项 |
| `suppressed_items` | 因设备撤销、账本关闭、Viewer 权限或命令不可用被抑制的设置项 |
| `audit_ref` | 脱敏审计引用，不包含旧配置原文、完整路径、令牌或密码 |

设置错误码至少包括：

| 错误码 | 含义 |
| --- | --- |
| `settings_scope_invalid` | 设置项写入了错误作用域 |
| `settings_snapshot_stale` | 保存基于过期设置快照 |
| `settings_item_failed` | 单项保存失败，查看逐项结果 |
| `settings_shortcut_conflict` | 快捷键与已有命令或系统保留组合冲突 |
| `settings_window_bounds_invalid` | 窗口坐标不可见或跨屏无效 |
| `settings_license_storage_failed` | 授权级设置保存失败 |
| `settings_secret_storage_unavailable` | 安全存储不可用 |

## 4. 三端设置边界

### 4.1 PC

PC 必须支持：

1. 本机窗口、最近账本、快捷键和缓存设置。
2. 本地账本名称、备份策略、账本密码状态和同步入口设置。
3. 未登录时保存本地设置。
4. 登录后读取账号摘要和设备状态。
5. 开启同步前，账本级本地设置不自动上传。
6. 从旧程序配置迁移窗口状态、最近账簿、快捷键和显示偏好时，先进入 PC 本地预览，用户确认后只保存新系统设置值。

PC 不得：

1. 把令牌、密码或授权秘密写入 Rust 核心领域表。
2. 因云端设置变化自动删除 PC 本地账本文件。
3. 上传旧迁移审计、迁移报告、脱敏摘要、旧路径或旧原始行。
4. 上传旧配置原文、旧授权协议抓取证据、旧快捷键冲突样例、旧窗口坐标或最近账簿完整路径。

### 4.2 Web

Web 必须支持：

1. 登录后读取账号级偏好和云端账本级设置。
2. 修改当前用户可编辑的展示偏好。
3. Owner/Editor 根据权限修改账本基础设置；Viewer 只读。
4. 设备撤销后停止使用刷新令牌并返回登录页。

Web 不得：

1. 保存 PC 本地路径。
2. 展示旧迁移审计或旧原始行。
3. 把浏览器缓存设置作为权威财务真相。

### 4.3 手机

手机必须支持：

1. 当前账号、当前设备和当前账本摘要。
2. 最近数据缓存开关或清理入口。
3. 应用内提醒和同步状态提示。
4. 通知总开关和账本级提醒开关。
5. 设备撤销、成员移除或角色降级后的可解释状态。

手机不要求：

1. 完整快捷键设置。
2. 账本密码或本地加密管理。
3. 完整成员管理台。

## 5. 通知和提醒状态

第一版通知以应用内通知为主，系统推送可作为后续增强。

通知来源：

| 来源 | 第一版状态 |
| --- | --- |
| 今日提醒 | PC/Web 完整查看；手机摘要提示 |
| 计划到期 | PC/Web 列表和操作；手机提示 |
| 预算或限额提醒 | 三端可提示，复杂配置优先 PC/Web |
| 同步失败 | 三端提示 |
| 冲突待处理 | PC/Web 处理入口，手机摘要 |
| 设备撤销或权限变化 | 三端提示，停止相关同步 |
| 手机快查 | 第一版按账号和账本权限读取摘要，不保存完整本地账本 |

通知状态字段：

| 字段 | 说明 |
| --- | --- |
| `notification_id` | 通知稳定标识 |
| `ledger_id` | 所属账本；账号级通知可为空 |
| `source_type` | reminder、schedule、budget、sync、conflict、security |
| `severity` | info、warning、critical |
| `delivery_mode` | in_app、system_notification、none |
| `read_at` | 已读时间 |
| `dismissed_at` | 忽略时间 |
| `action_target` | 可跳转目标，不包含敏感路径 |
| `delivery_state` | pending、delivered、failed、suppressed |
| `failure_code` | 失败原因，例如 revoked、forbidden、network_failed |
| `idempotency_key` | 通知去重键 |

通知规则：

1. Viewer 只能收到可查看范围内的提醒，不显示写入动作。
2. 手机冲突通知只展示摘要，不展示字段级差异。
3. 同步失败通知不得包含令牌、旧路径、旧原始行或迁移诊断。
4. 设备撤销后本机可以展示本地状态，但不能继续上传同步。
5. 通知已读状态可以按账号同步；PC 本地未登录通知只保存在本机。
6. 远程通知投递失败必须保存脱敏失败状态和下一次重试时间，不得重复发送同一幂等通知。
7. 权限变化、设备撤销或账本关闭后，未投递通知进入 `suppressed`，不能继续使用旧权限。

### 5.1 手机快查和远程通知

手机快查和远程通知复用账号、设备和账本权限，不复用旧同步账号密码页面。

规则：

1. 手机快查只读取账户摘要、最近流水摘要、提醒摘要和同步状态，不下载完整 PC 本地账本。
2. 手机快查开关必须限定账号、设备和账本；PC 本地未开启同步的账本不可被手机快查读取。
3. 远程通知默认只发送标题、严重级别、来源类型和脱敏对象摘要，不发送完整交易备注、附件内容、旧迁移证据或 PC 本地路径。
4. 设备撤销、成员移除或角色降级后，手机快查和远程通知必须停止使用旧权限。
5. 旧手机快查和远程通知页面证据、旧路径、旧原始行、迁移审计、迁移报告和脱敏摘要只保存在 PC 本地。
6. 手机快查响应必须只包含 `account_summary`、`recent_entry_summary`、`reminder_summary`、`sync_summary` 和缓存状态，不包含完整流水正文、附件内容或本地文件路径。
7. 手机快查失败必须区分网络失败、设备撤销、成员移除、角色降级、账本未同步和缓存过期。
8. 远程通知重试必须按 `notification_id + idempotency_key` 去重；重复投递只能更新送达状态，不创建多条通知。

## 6. 快捷入口和默认页面

第一版允许保存常用入口偏好，但不得影响财务真相。

规则：

1. 默认页面、最近页面、左侧导航展开状态属于设备级或账号级显示偏好。
2. 快捷键使用稳定命令 ID，不用中文菜单文本作为持久化键。
3. 隐藏、无权限或当前状态不可用的命令不得通过快捷键绕过执行。
4. 快捷键冲突必须在保存前提示。
5. 手机端不要求快捷键，只保留常用入口和最近账本。
6. 窗口状态必须带屏幕边界校验，显示器变化或坐标不可见时回退到默认布局。
7. 最近账本只保存当前设备可打开的本地标识和脱敏显示名；完整路径只保存在 PC 本地安全边界，不进入云端账号偏好。
8. 旧快捷键迁移发生冲突时必须进入预览和逐项选择，不能静默覆盖新系统默认快捷键。

### 6.1 关于、许可、更新和验证码

关于页、软件许可、检查更新和验证码刷新属于外围入口，不能影响财务对象。

规则：

1. 关于页可以展示应用版本、构建信息、版权和支持入口，不展示账本路径、旧迁移证据或财务明细。
2. 检查更新必须通过安全适配器访问受控更新源，不复用旧明文 HTTP 或客户端硬编码秘密。
3. 软件许可和高级功能状态保存到授权级存储，不进入账本同步对象、交易、报表或导出。
4. 验证码刷新只用于注册、登录或授权流程的安全挑战，不进入账本数据模型。
5. 验证码图片、挑战 ID、许可凭据和更新响应不得进入普通日志、导出或支持包。

## 7. 安全和隐私

不得进入普通设置、日志、导出或云端响应：

1. 密码、访问令牌、刷新令牌。
2. 账本密码材料、密钥派生参数明文。
3. PC 本地账本完整路径。
4. 旧 MoneyHome8 原始文件、旧原始行、旧字段值。
5. 迁移审计、迁移报告、脱敏摘要或 PC 机器环境诊断。
6. 授权服务的私密凭据。

云端可以保存：

1. 账号级展示偏好。
2. 设备显示名和撤销状态。
3. 已开启同步账本的账本级设置。
4. 通知已读和忽略状态。

## 8. 验收口径

1. PC 未登录也能保存本机窗口、最近账本和本地账本设置。
2. PC 登录后未显式开启同步时，本地账本设置不自动上传。
3. Web 和手机必须登录后读取账号级设置。
4. Viewer 修改账本级设置被拒绝。
5. 设置取消不写入，保存失败返回逐项错误。
6. 通知不包含旧迁移证据、PC 本地路径、令牌或密码。
7. 设备撤销后通知用户重新登录，并停止同步上传。
8. 快捷键不能绕过权限或对象状态。
9. 手机能展示同步失败、冲突摘要和提醒摘要。
10. 最近账本和窗口状态不写入财务真相表。
11. 手机快查不保存完整本地账本，远程通知不发送旧迁移证据、附件内容或 PC 本地路径。
12. 关于页、软件许可、检查更新和验证码刷新不读取或改变财务对象。
13. 旧设置、窗口状态、快捷键、最近账簿和授权协议校准证据只保存在 PC 本地；同步时只传新系统设置值和必要脱敏审计。
14. 手机快查失败能区分网络、权限、设备撤销、账本未同步和缓存过期，并保留可解释缓存状态。
15. 远程通知投递失败、重试和权限抑制使用幂等键去重，通知正文不包含完整交易备注、附件内容、旧证据或本地路径。

## 9. 当前无需人工确认

本计划没有引入新的产品取舍；它细化的是已确认的三端设置入口、PC 本地未登录、Web/手机登录、账本隔离、通知摘要、设备撤销、安全日志脱敏和旧迁移隐私边界。
