# 共享 UI、AI、诊断与自动化边界需求计划

本文档承接 `three-client-requirements-analysis.md`、`three-client-ui-navigation-plan.md`、`command-form-lifecycle-plan.md`、`security-audit-error-handling-plan.md`、`localization-accessibility-display-plan.md`、`runtime-shared-ui-contract.md`、`runtime-ai-console-calculator-contract.md` 和 `runtime-automation-boundaries.md`，定义 Finance Own 第一版共享 UI 组件、金额计算器、Web 内容宿主、AI 面板、内部诊断控制台和旧程序自动化证据的需求边界。本文只定义产品和安全口径，不把旧版内部工具或自动化探测路径作为普通用户功能复刻。

## 1. 目标

1. 收敛金额筛选、日期范围、树选择、弹窗、进度、统计工作区和只读详情等共享 UI 能力。
2. 保留共享金额计算器弹层能力，统一金额解析、错误、取消和回填行为。
3. 明确 AI 面板为可选适配器，默认关闭，禁止照搬旧版明文 HTTP、内置秘密或弱签名协议。
4. 明确内部控制台只用于开发或诊断构建，与普通财务数据权限隔离。
5. 明确旧程序运行态自动化证据只用于迁移分析和验证，不作为新系统用户自动化入口。
6. 共享组件不得直接访问 SQLite、旧账本文件或提交业务事务。

## 2. 非目标

1. 第一版不复刻 Delphi 继承层次、第三方工具栏定制器或旧窗体数量。
2. 第一版不提供普通用户可执行 SQL、远程命令、修复币种、修复价格或重命名账本的内部控制台。
3. 第一版不内置旧 AI 面板的外部 HTTP 地址、签名密钥或脚本桥协议。
4. 第一版不把运行态自动化脚本作为正式产品 API。
5. 第一版不允许 Web 内容宿主任意外部导航或任意脚本桥调用。

## 3. 共享 UI 组件

共享组件边界：

| 组件 | 用途 | 规则 |
| --- | --- | --- |
| `AmountFilter` | 金额筛选 | 支持不筛选、大于等于、小于等于、闭区间和十进制金额校验 |
| `DialogShell` | 通用弹窗 | 标题、关闭、帮助、默认按钮、取消、脏草稿保护和焦点恢复 |
| `DatePickerPopover` | 日期选择 | 日历下拉、月份切换、键盘导航、最小最大日期和草稿回填 |
| `TreeSelectPopover` | 树选择 | 单选、多选、展开、键盘、失焦关闭和宿主回填 |
| `DateRangeControl` | 日期范围 | 日/周/月/季/年、最近区间、自定义起止日期和规范化边界 |
| `WorkspaceFrame` | 工作区宿主 | 页面激活、刷新、页签、懒加载、脏草稿切换和状态恢复 |
| `ProgressOverlay` | 长任务进度 | 阶段、进度、取消、不可取消阶段、错误、重试和退出协商 |
| `StatisticsWorkspace` | 报表工作区 | 树导航、表格选择、图表明细联动、导出和打印共享查询快照 |
| `DetailProjection` | 只读详情 | 主信息、附加信息、账户属性、密码遮罩和字段级权限 |
| `WebContentHost` | 本地 Web 内容 | 本地资源加载、导航限制、脚本桥白名单、故障降级和进程隔离 |

规则：

1. 共享组件只接收宿主提供的模型、草稿和命令回调。
2. 共享组件不得直接访问 SQLite、云端数据库、旧账本文件或迁移审计。
3. 筛选、日期、选择和计算结果先进入宿主草稿；只有宿主命令可以提交业务数据。
4. 日期范围统一转换为明确时区下的查询区间，UI 展示和查询边界必须一致。
5. 统计树、表格、图表、导出和打印必须共享同一不可变查询快照。
6. 共享组件状态可以保存为用户偏好，但不得混入账务领域表或改变历史业务口径。

## 4. 金额计算器

`AmountCalculatorResultDto` 字段：

| 字段 | 说明 |
| --- | --- |
| `source_field_id` | 调用金额字段 |
| `expression` | 用户输入表达式 |
| `result_minor` | 结果金额，按目标币种最小单位 |
| `currency_code` | 目标币种 |
| `rounding_mode` | 舍入口径 |
| `status` | `completed`、`cancelled`、`error` |
| `error_code` | 错误码 |

规则：

1. 金额编辑器以共享弹层打开计算器，不复制多套计算逻辑。
2. 有效结果只有在明确完成时回填。
3. 取消、Esc、方向上键或失焦关闭不得改变原值。
4. 计算错误必须与取消区分，保留原值并展示可理解错误原因。
5. 关闭后焦点回到原金额输入框。
6. 金额解析、精度和舍入必须由统一金额类型处理，不使用二进制浮点作为账务真相。

## 5. Web 内容宿主与 AI 面板

`WebContentHostPolicyDto` 字段：

| 字段 | 说明 |
| --- | --- |
| `host_id` | 宿主 ID |
| `content_kind` | `local_help`、`diagnostic`、`ai_adapter` |
| `allowed_origins` | 允许来源 |
| `bridge_capabilities` | 允许脚本桥能力 |
| `network_policy` | `local_only`、`approved_https_only`、`disabled` |
| `secret_policy` | 秘密存储边界 |
| `enabled` | 是否启用 |

AI 面板规则：

1. 第一版默认关闭旧式 AI 面板。
2. 启用 AI 适配器必须使用 HTTPS、显式配置、秘密安全存储和账本权限隔离。
3. 不复用旧版明文 HTTP、MD5 签名或内置秘密。
4. AI 请求不得默认携带账本全量数据、旧迁移证据、PC 本地路径、附件内容或敏感字段。
5. AI 响应不能直接提交财务命令；必须转为用户可审阅草稿或建议。
6. AI 适配器日志必须脱敏，并只保留诊断 ID、模型/服务标识、错误码和时间。

Web 内容宿主规则：

1. 默认禁止任意外部导航。
2. 脚本桥只开放版本化声明的本地能力。
3. 本地资源加载失败必须有降级状态，不阻塞核心记账。
4. Web 内容崩溃或脚本错误不得影响账本事务。
5. Web 内容宿主必须运行在受限上下文；本地帮助、诊断页和 AI 适配器不能共享无限制脚本桥。
6. 脚本桥请求必须携带 `host_id`、能力名、版本、来源和幂等键；未知能力默认拒绝并审计。
7. 任何外部 HTTPS 导航都必须来自受控 allowlist，且打开前不得自动附带账本数据、附件、旧迁移证据或诊断包。

## 6. 内部诊断控制台

内部控制台第一版边界：

1. 只在开发、测试或受控诊断构建启用。
2. 普通用户发行版默认不可见、不可打开、不可执行命令。
3. 控制台命令不得绕过账本权限、同步权限、审计和危险命令确认。
4. 高风险维护命令必须由单独的受控修复流程承接，不由通用控制台直接暴露。
5. 控制台历史、输出和诊断包不得包含密码、令牌、完整 PC 本地路径、旧迁移证据或财务明细。
6. 控制台窗口状态和历史命令若保存，只能进入开发诊断配置，不进入账本数据。

`DiagnosticCommandDescriptorDto` 字段：

| 字段 | 说明 |
| --- | --- |
| `command_id` | 稳定命令 ID |
| `command_name` | 脱敏命令名 |
| `availability` | disabled、diagnostic_build_only、test_ledger_only、allowed |
| `risk_level` | read_only、preview_only、mutating、dangerous |
| `input_schema_version` | 输入参数版本 |
| `output_schema_version` | 输出结果版本 |
| `requires_ledger_scope` | 是否要求账本范围 |
| `requires_approval` | 是否要求审批或危险确认 |
| `audit_required` | 是否必须审计 |

诊断命令规则：

1. 旧控制台的 `25` 个命令类只能作为排查清单，不自动成为新系统命令。
2. 每个保留命令必须先登记 `DiagnosticCommandDescriptorDto`，声明输入、输出、风险、副作用和可用构建。
3. 未登记命令、未知别名、隐藏入口和旧快捷键触发必须返回 `diagnostic_command_unknown`。
4. 读命令只能输出脱敏结构化结果；不得输出 SQL 连接串、令牌、完整本地路径、旧迁移证据或财务明细。
5. 修复、重算、删除、迁移和远程命令必须走独立受控修复流程；控制台只可发起预览或跳转授权流程。
6. 控制台可达性验证只能使用隔离测试账本或诊断构建，不得用真实账本验证高风险副作用。

受控诊断构建可以保留：

| 能力 | 边界 |
| --- | --- |
| 帮助和系统信息 | 脱敏输出 |
| 日志查看 | 只读、脱敏、按诊断 ID |
| 网络诊断 | 不输出令牌或请求体 |
| 数据修复预览 | 只读预览和独立审批 |
| SQL 或脚本 | 默认禁用；启用时只对隔离测试账本开放 |

## 7. 运行态自动化证据

旧 MoneyHome8 自动化探测用于迁移分析、页面覆盖和兼容验证。

规则：

1. 旧程序自动化脚本、窗口句柄、DFM 解析和只读截图证据只作为研发证据。
2. 新系统不把 Win32 控件树枚举、ReadProcessMemory、PrintWindow 或 DFM 提取作为用户功能。
3. 动态验证只能对指定测试账簿执行，且遵守账簿路径、进程、锁文件和文件指纹检查。
4. 自动化证据中涉及的旧路径、旧原始行、迁移审计、迁移报告、脱敏摘要和诊断信息只保存在 PC 本地。
5. 运行态证据不得上传云端或进入用户同步对象。

## 8. 三端职责

| 能力 | PC | Web | 手机 |
| --- | --- | --- | --- |
| 共享金额计算器 | 支持 | 支持 | 后置或轻量 |
| 日期和金额筛选 | 支持 | 支持 | 轻量 |
| 统计工作区 | 支持 | 支持 | 摘要 |
| Web 内容宿主 | 本地帮助或诊断 | 受浏览器安全边界约束 | 后置 |

| 旧程序自动化 | PC 本地研发验证 | 不支持 | 不支持 |

## 9. 审计、隐私与错误

审计范围：

1. AI 适配器启用、禁用和配置变更。
2. Web 内容宿主脚本桥调用失败、越权阻止和崩溃。
3. 诊断控制台启用、命令执行和高风险阻止。
4. 长任务取消、不可取消阶段进入、失败和重试。
5. 共享组件触发的高风险命令提交。

隐私规则：

1. 旧 MoneyHome8 自动化证据和迁移证据只保存在 PC 本地。
2. 云端不得保存旧原始文件、旧路径、旧原始行、旧字段值、迁移审计、迁移报告、脱敏摘要或 PC 机器环境诊断。
3. AI、控制台、Web 内容宿主、错误响应和日志不得包含密码、令牌、PC 完整本地路径、附件内容、敏感身份信息或旧迁移证据。

错误码：

| 错误码 | 含义 | 行为 |
| --- | --- | --- |
| `calculator_expression_invalid` | 金额表达式非法 | 保留原值 |
| `calculator_divide_by_zero` | 除零 | 保留原值并提示 |
| `web_host_navigation_blocked` | 外部导航被阻止 | 显示受限状态 |
| `script_bridge_forbidden` | 脚本桥能力未授权 | 阻止调用并审计 |
| `web_host_origin_forbidden` | Web 内容来源不在 allowlist | 阻止导航或脚本桥 |
| `ai_adapter_disabled` | AI 适配器未启用 | 不发送请求 |
| `ai_payload_forbidden` | 请求包含禁止内容 | 阻止发送 |
| `diagnostic_console_forbidden` | 普通构建禁止控制台 | 阻止打开 |
| `diagnostic_command_unknown` | 控制台命令未登记或隐藏命令触发 | 拒绝执行并审计 |
| `diagnostic_command_scope_required` | 诊断命令缺少测试账本或授权范围 | 要求补充范围 |
| `automation_evidence_local_only` | 自动化证据只能本地保存 | 阻止上传 |

## 10. 验收场景

1. 金额计算器完成计算后回填金额；取消、Esc 或方向上键关闭时原值不变。
2. 金额计算器除零或非法表达式返回错误状态，不生成账务命令。
3. 日期范围筛选、表格、图表、导出和打印使用同一查询快照。
4. 长任务进入不可取消阶段后明确展示状态，并等待事务结果。
5. Web 内容宿主阻止未授权外部导航和脚本桥调用。
6. AI 适配器默认关闭；启用后也不能发送账本全量、旧迁移证据、附件内容或 PC 本地路径。
7. 普通用户发行版不能打开内部诊断控制台。
8. 诊断构建中的每个控制台命令都有命令描述符、输入输出版本、风险等级和审计要求；未登记命令拒绝执行。
9. 控制台读命令输出脱敏结构化结果；修复类命令只能进入预览或授权流程。
10. 旧程序自动化证据、迁移审计、迁移报告、脱敏摘要、旧路径和旧原始行只保存在 PC 本地。

## 11. 当前无需人工确认

本计划没有引入新的产品取舍；它细化的是已确认的共享 UI、金额计算器、Web 内容宿主、AI 适配器默认关闭、内部控制台诊断隔离、旧程序自动化证据本地化和旧迁移证据 PC 本地保存边界。
