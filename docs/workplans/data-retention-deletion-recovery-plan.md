# 数据删除、归档、保留与恢复需求计划

本文档承接 `three-client-requirements-analysis.md`、`command-form-lifecycle-plan.md`、`conflict-resolution-plan.md`、`ledger-lifecycle-storage-plan.md`、`attachment-privacy-plan.md` 和 `backup-import-export-plan.md`，定义 Finance Own 第一版数据删除、归档、保留、恢复、清理和三端同步的需求边界。

## 1. 核心原则

1. 财务事实默认不做无审计硬删除。
2. 业务删除、归档、撤销、解绑、云端账本删除和 PC 本地文件删除必须是不同动作。
3. 删除必须通过对象版本、墓碑或作废状态同步到其它端，不能依赖物理消失。
4. 恢复必须校验权限、版本、引用关系和影响范围。
5. 设备撤销、成员移除、角色降级和云端账本删除不得远程删除 PC 本地账本文件。
6. 旧 MoneyHome8 迁移证据只保存在 PC 本地，不进入云端删除、恢复或保留策略。

## 2. 删除动作分类

| 动作 | 含义 | 是否同步 | 第一版要求 |
| --- | --- | --- | --- |
| 取消表单 | 用户放弃未提交输入 | 否 | 零写入 |
| 删除草稿 | 删除本机未上传草稿 | 否 | 只影响本机队列 |
| 作废交易 | 财务事实保留但业务上失效 | 是 | 生成新版本和审计 |
| 撤销交易 | 用反向或撤销记录表达业务纠正 | 是 | 生成可审计命令 |
| 归档对象 | 对象不再出现在常用选择器 | 是 | 历史引用继续展示 |
| 墓碑删除 | 对象被删除但保留同步墓碑 | 是 | 防止其它端误恢复 |
| 解除附件引用 | 业务对象不再引用附件 | 是 | 附件内容清理后置 |
| 删除云端账本 | 云端对象进入删除流程 | 是 | Owner 二次确认 |
| 删除 PC 本地文件 | 删除本机 SQLite 和受管目录 | 否 | 只能本机二次确认 |
| 物理清理 | 后台清理无引用内容或过期临时文件 | 部分 | 必须可审计或可解释 |

## 3. 对象删除口径

| 对象 | 第一版处理 | 不能做 |
| --- | --- | --- |
| 交易 | 作废、撤销或墓碑；保留审计 | 无审计硬删除事实 |
| 分录 | 跟随交易状态，不单独静默删除 | 只删分录导致交易不平 |
| 账户 | 有历史引用时关闭或隐藏 | 物理删除历史账户 |
| 账户组 | 有子项时归档或要求迁移子项 | 删除后让账户消失 |
| 分类 | 归档，历史记录继续展示路径 | 删除后历史交易无法显示分类 |
| 标签 | 归档或解除新引用，历史记录继续展示 | 删除后历史筛选失真 |
| 往来方 | 归档 | 删除后历史对象失去名称 |
| 币种 | 被引用后禁止删除 | 删除导致金额无法格式化 |
| 汇率快照 | 作废或新版本替代 | 覆盖历史折算依据 |
| 预算 | 停用或归档；历史执行摘要保留 | 删除预算历史口径 |
| 提醒/计划 | 停用、跳过或归档；实例保留审计 | 删除已产生实例 |
| 附件引用 | 解除引用，内容清理后置 | 立即删除仍被引用内容 |
| 投资输入 | 作废、归档或墓碑；校准结果失效 | 删除后仍保留正式结果 |
| 账本 | 云端删除流程和本地文件删除分开 | 云端动作远程删 PC 文件 |

## 4. 三端行为

### 4.1 PC

PC 端支持：

1. 本地交易作废、撤销、归档和墓碑同步。
2. 本地草稿、导入预览和临时附件清理。
3. 删除 PC 本地账本文件，但必须本机二次确认。
4. 恢复本地备份为新账本或经确认覆盖当前账本。
5. 开启同步后上传新系统对象的删除状态和墓碑。

PC 端禁止：

1. 因云端成员变化、设备撤销或角色降级自动删除本地账本文件。
2. 删除旧 MoneyHome8 原始文件作为迁移流程的一部分。
3. 将迁移审计、迁移报告、脱敏摘要、旧路径或旧原始行上传给云端删除服务。

### 4.2 Web

Web 端支持：

1. 在线常用财务对象删除、归档和恢复入口。
2. 账本删除、对象恢复和高风险操作二次确认。
3. 查看云端墓碑、归档状态、删除审计和冲突。
4. 对可恢复对象发起恢复或另存副本。

Web 端禁止：

1. 读取或删除 PC 本地 SQLite 文件。
2. 读取或删除旧 MoneyHome8 原始文件。
3. 展示旧迁移审计、迁移报告、脱敏摘要、旧路径或旧原始行。

### 4.3 手机

手机端支持：

1. 删除本机未上传草稿。
2. 撤回待上传草稿或停止重试。
3. 查看对象已删除、已归档、权限变化或冲突摘要。
4. 在线常用删除可以后置或限制。

手机端第一版不承担：

1. 高风险删除确认。
2. 账本删除。
3. 完整恢复流程。
4. 删除与修改冲突的完整解决。

## 5. 删除确认

高风险删除必须展示影响范围：

| 内容 | 要求 |
| --- | --- |
| 对象名称和类型 | 明确用户要处理的对象 |
| 账本 | 展示账本名称，避免跨账本误删 |
| 引用数量 | 展示交易、附件、预算、提醒或计划引用影响 |
| 同步影响 | 说明会同步到其它端或仅本机生效 |
| 本地文件影响 | PC 删除本地文件时必须展示文件和受管目录范围 |
| 可恢复性 | 说明可恢复、可另存副本或不可恢复 |
| 权限 | 展示当前角色是否有权执行 |

确认必须带确认令牌、对象版本和幂等 ID。确认令牌只表达本次用户确认，不能长期复用。

## 6. 同步墓碑

墓碑用于让其它端知道对象已删除或作废。

墓碑字段至少包括：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `object_id` | 是 | 被删除对象 ID |
| `ledger_id` | 是 | 所属账本 |
| `object_type` | 是 | 对象类型 |
| `deleted_version` | 是 | 删除生成的版本 |
| `deleted_at` | 是 | 删除时间 |
| `deleted_by_account_id` | 是 | 删除人 |
| `delete_kind` | 是 | void、archive、tombstone、unlink、ledger_delete |
| `reason` | 否 | 用户输入或系统原因，必须脱敏 |
| `previous_version` | 是 | 删除前对象版本 |

规则：

1. 删除和归档都必须进入对象版本序列。
2. 拉取同步时，端侧不能因为本地还有旧对象就忽略墓碑。
3. 离线端修改已被其它端删除的对象时进入删除与修改冲突。
4. 墓碑保留周期不得短于任意端可能离线的合理同步窗口；第一版不固化具体天数，技术设计需结合产品策略配置。

## 7. 恢复

恢复对象必须校验：

1. 当前用户角色。
2. 对象是否仍在同一账本。
3. 引用对象是否存在、归档或被删除。
4. 恢复后是否影响余额、报表、预算、提醒、附件或冲突。
5. 是否需要另存副本而不是原位恢复。

恢复结果：

| 场景 | 结果 |
| --- | --- |
| 可原位恢复 | 生成新版本，状态从 deleted/archive 回到 active |
| 引用缺失 | 要求重选引用或另存副本 |
| 权限不足 | 阻止恢复 |
| 删除与修改并发 | 进入冲突解决 |
| 账本已删除 | 仅 Owner 可按云端删除策略处理 |

PC 本地备份恢复默认恢复为新账本；覆盖当前账本必须独立确认并先生成安全快照。

## 8. 物理清理

第一版物理清理只允许用于：

1. 本机未上传草稿。
2. 临时附件缓存。
3. 已解除引用且超过保留策略的附件内容。
4. 用户明确删除的 PC 本地账本文件。

物理清理禁止：

1. 清理仍被业务对象引用的附件。
2. 清理同步尚未传播完成的墓碑。
3. 清理未备份且用户未确认的 PC 本地账本文件。
4. 清理旧迁移审计、迁移报告或脱敏摘要后仍声称可追溯迁移结果。

物理清理必须返回可解释结果：清理对象数量、跳过数量、失败数量和原因。不得在云端日志中记录 PC 完整本地路径。

## 9. 审计和日志

以下操作必须审计：

1. 作废、撤销、归档、墓碑删除和恢复。
2. 账本删除和本地文件删除确认。
3. 附件解除引用和物理清理结果。
4. 高风险批量删除。
5. 删除与修改冲突解决。

审计不得包含：

1. 密码、令牌、刷新令牌或密钥。
2. PC 完整本地路径。
3. 旧 MoneyHome8 原始文件。
4. 旧原始行、旧字段值或旧类别码诊断。
5. 迁移审计、迁移报告、脱敏摘要或 PC 机器环境诊断。

## 10. 权限

| 操作 | Owner | Editor | Viewer |
| --- | --- | --- | --- |
| 删除本机未上传草稿 | 本机允许 | 本机允许 | 本机允许 |
| 作废或删除常规交易 | 允许 | 允许 | 禁止 |
| 归档基础资料 | 允许 | 允许 | 禁止 |
| 恢复常规对象 | 允许 | 允许 | 禁止 |
| 删除云端账本 | 允许 | 禁止 | 禁止 |
| 删除 PC 本地账本文件 | 本机用户二次确认 | 本机用户二次确认 | 本机用户二次确认 |
| 物理清理云端附件内容 | 按云端策略 | 按云端策略 | 禁止 |

Viewer 权限变化不得导致本地草稿或 PC 本地文件被静默删除。

## 11. 错误模型

删除、归档和恢复错误码至少包括：

| 错误码 | 含义 | 三端处理 |
| --- | --- | --- |
| `delete_requires_confirmation` | 需要二次确认 | 展示确认面板 |
| `delete_referenced_object` | 对象仍被引用 | 展示影响范围或改为归档 |
| `delete_version_conflict` | 删除版本不匹配 | 进入冲突或刷新 |
| `delete_permission_denied` | 当前角色无权删除 | 阻止提交 |
| `restore_reference_missing` | 恢复所需引用不存在 | 要求重选或另存副本 |
| `restore_version_conflict` | 恢复版本冲突 | PC/Web 冲突解决 |
| `cleanup_skipped_referenced` | 物理清理跳过仍被引用对象 | 展示跳过原因 |
| `local_file_delete_forbidden_remote` | 远程请求不能删除 PC 本地文件 | 阻止操作 |

错误响应不得包含 PC 完整本地路径、旧 MoneyHome8 原始路径、旧原始行、旧字段值、迁移审计、迁移报告、脱敏摘要或 PC 机器环境诊断。

## 12. 验收要点

1. 删除交易生成作废、撤销或墓碑，不做无审计硬删除。
2. 删除账户、分类、标签、预算、提醒前展示影响范围或引用阻断。
3. Web 删除必须二次确认并同步到 PC 和手机。
4. 手机删除未上传草稿只影响本机。
5. 删除与修改并发进入 PC/Web 冲突解决。
6. 设备撤销、成员移除或云端账本删除不会删除 PC 本地文件。
7. 附件解除引用不立即物理删除仍被引用内容。
8. 恢复对象必须校验权限、版本和引用关系。
9. 墓碑保留足以防止离线端误恢复旧对象。
10. 审计、日志和错误响应不泄露旧迁移证据或 PC 本地完整路径。

## 13. 当前无需人工确认

本计划没有引入新的产品取舍；它细化的是已确认的显式删除确认、对象级墓碑同步、PC 本地文件不受云端远程删除、附件物理清理后置、手机轻量草稿删除和旧迁移证据只保存在 PC 本地的边界。
