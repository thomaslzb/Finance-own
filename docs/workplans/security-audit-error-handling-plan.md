# 安全、审计与错误恢复需求计划

本文档承接 `three-client-requirements-analysis.md`、`dotnet-sync-api-plan.md`、`attachment-privacy-plan.md` 和 `conflict-resolution-plan.md`，统一定义 Finance Own 第一版三端安全、审计、日志脱敏、错误模型和恢复边界。本文只记录已确认的一版要求，不引入完整端到端加密作为第一版阻塞项。

## 1. 目标

第一版必须支持：

1. HTTPS 传输加密。
2. 云端静态加密和密钥管理策略。
3. 自有账号、访问令牌、刷新令牌和设备撤销。
4. 账本级权限隔离和 Owner/Editor/Viewer 粗粒度角色。
5. 附件下载权限校验或短期授权。
6. 关键写入、删除、同步、冲突解决和成员变更审计。
7. 三端结构化错误、字段错误和诊断 ID。
8. 日志、错误响应和诊断信息脱敏。
9. 网络失败、权限变化、版本冲突和幂等重放的可恢复路径。

第一版禁止事项：

1. 禁止把未实现完整端到端加密理解为弱化 HTTPS、静态加密或权限隔离。
2. 禁止在云端保存旧 MoneyHome8 原始文件、迁移审计、迁移报告、脱敏摘要、旧路径、旧原始行或 PC 机器环境诊断。
3. 禁止在普通日志、错误响应、截图或遥测中记录密码、令牌、刷新凭据、完整附件内容、完整本地路径或未脱敏财务明细。
4. 禁止让云端静默覆盖 PC 本地对象。
5. 禁止让只读成员通过同步、冲突解决或附件接口绕过权限。

## 2. 传输与凭据

### 2.1 HTTPS

所有 Web、手机、PC 同步和附件云端 API 都必须使用 HTTPS。

验收：

1. 明文 HTTP 不得作为第一版正式 API 入口。
2. 重定向、回调和附件短期授权 URL 不得降级为 HTTP。
3. API 错误不得回显请求中的令牌、密码或刷新凭据。

### 2.2 访问令牌和刷新令牌

| 项目 | 要求 |
| --- | --- |
| 访问令牌 | 短期有效，用于 API 请求 |
| 刷新令牌 | 用于换取新访问令牌，设备撤销后失效 |
| PC 存储 | 登录凭据只存在系统凭据存储或等价安全设施，不进入 Rust 核心领域表 |
| 手机存储 | 使用平台安全存储 |
| Web 存储 | 使用浏览器安全策略，刷新令牌不得进入普通日志或页面可见状态 |

设备撤销后：

1. 刷新令牌失效。
2. 后续同步上传返回 `device_revoked` 或等价权限错误。
3. 不删除 PC 本地账本文件。

## 3. 云端静态加密与密钥

第一版云端必须定义静态加密和密钥管理策略。

| 数据 | 第一版要求 |
| --- | --- |
| PostgreSQL 存储 | 使用云平台或数据库层静态加密 |
| 附件内容 | 存储层加密，下载必须经权限校验或短期授权 |
| 密钥管理 | 不硬编码密钥；生产密钥由云平台 KMS 或等价机制管理 |
| 备份 | 云端备份继承静态加密和访问控制 |
| 日志 | 日志系统不得保存秘密和旧迁移证据 |

完整端到端加密第一版后置；后续若启用 E2EE，必须重新设计 Web 在线编辑、冲突字段差异、附件预览和服务端报表能力。

## 4. 权限隔离

### 4.1 账本级隔离

1. 所有云端对象必须带 `ledger_id`。
2. 所有 API 请求必须校验用户对 `ledger_id` 的成员权限。
3. 同一账号下多个账本的对象、附件、同步批次、冲突、报表缓存和审计不得串账。
4. PC 本地未开启同步的账本没有云端成员概念。

### 4.2 角色边界

| 操作 | Owner | Editor | Viewer |
| --- | --- | --- | --- |
| 查询账本数据 | 是 | 是 | 是 |
| 新增/修改常规财务对象 | 是 | 是 | 否 |
| 删除/归档常规财务对象 | 是 | 是 | 否 |
| 上传附件 | 是 | 是 | 否 |
| 下载附件 | 是 | 是 | 是 |
| 解决冲突 | 是 | 是 | 否 |
| 邀请和管理成员 | 是 | 否 | 否 |
| 删除或归档账本 | 是 | 否 | 否 |

权限变化处理：

1. Editor 降级为 Viewer 后，未上传的 PC/手机变更必须失败或进入权限冲突提示。
2. 被移除成员后续访问返回 `ledger_forbidden`。
3. PermissionChanged 冲突不能通过字段合并绕过权限。

## 5. 审计事件

第一版必须审计以下事件：

| 事件 | 审计字段 |
| --- | --- |
| 登录成功/失败 | 用户、设备、时间、结果、诊断 ID |
| 设备撤销 | 用户、被撤销设备、时间、操作者 |
| 账本创建/更新/归档 | 账本、用户、设备、时间、变更摘要 |
| 成员邀请/接受/角色修改/移除 | 账本、操作者、目标用户、旧角色、新角色、时间 |
| 对象写入 | 账本、对象类型、对象 ID、版本、用户、设备、时间 |
| 删除/作废/墓碑 | 对象、版本、影响范围、用户、设备、原因 |
| 同步批次 | 批次 ID、设备、对象数量、结果、冲突 ID |
| 冲突解决 | 冲突 ID、处理方式、输入版本、生成版本、处理人、处理端 |
| 附件上传/下载/删除引用 | 附件、业务对象、用户、设备、授权方式 |

审计记录不得包含：

1. 旧 MoneyHome8 原始文件。
2. 迁移审计、迁移报告或脱敏摘要。
3. 旧路径、旧原始行或旧字段值。
4. PC 机器环境诊断。
5. 密码、访问令牌、刷新令牌。
6. 完整附件内容。

## 6. 结构化错误

### 6.1 错误响应字段

| 字段 | 可为空 | 说明 |
| --- | --- | --- |
| `code` | 否 | 稳定错误码 |
| `message` | 否 | 可展示的脱敏错误说明 |
| `diagnostic_id` | 否 | 服务端或本地诊断标识 |
| `field_errors` | 否 | 字段错误列表，没有时为空数组 |
| `recoverable` | 否 | 用户修正输入或重试是否有意义 |
| `conflict_id` | 是 | 冲突相关错误返回 |
| `batch_id` | 是 | 同步批次相关错误返回 |

### 6.2 必备错误码

| 错误码 | 使用场景 | 恢复路径 |
| --- | --- | --- |
| `unauthenticated` | 未登录或令牌无效 | 登录或刷新令牌 |
| `token_expired` | 访问令牌过期 | 刷新令牌 |
| `device_revoked` | 设备已撤销 | 重新登录或停用同步 |
| `ledger_forbidden` | 无账本权限 | 切换账本或联系 Owner |
| `ledger_readonly` | Viewer 写入 | 保留本地草稿并提示权限变化 |
| `validation_failed` | 字段校验失败 | 标记字段，允许编辑 |
| `version_conflict` | 对象版本过期 | 刷新或进入冲突解决 |
| `sync_conflict_created` | 已创建显式冲突 | 跳转 PC/Web 冲突处理 |
| `idempotency_replay` | 幂等重放 | 返回原结果，不重复创建 |
| `attachment_too_large` | 附件过大 | 重新选择或压缩附件 |
| `storage_failed` | 云端或本地存储失败 | 重试或展示诊断 ID |
| `legacy_invalid_format` | 旧来源格式不识别 | 停留 PC 本地迁移流程 |
| `legacy_auth_failed` | 旧来源认证失败 | 展示迁移阻塞 |
| `legacy_locked` | 旧来源被占用 | 提示关闭原程序或重试 |

## 7. 恢复策略

### 7.1 PC

1. 本地账本断网可写。
2. 云同步失败不影响本地继续记账。
3. 登录失败不影响未绑定云端的本地账本。
4. 打开本地账本失败必须返回明确错误，例如文件不存在、外来 SQLite、版本不支持或权限失败。
5. 迁移失败必须保留 PC 本地迁移预览和诊断，不上传云端。

### 7.2 Web

1. Web 离线时不得提交主账本写入。
2. 令牌过期优先刷新；刷新失败引导重新登录。
3. 表单校验失败保留用户输入。
4. 版本冲突进入刷新、拒绝或冲突解决路径。
5. 删除和高风险操作失败不得伪装成成功。

### 7.3 手机

1. 网络失败时队列项保留为可重试状态。
2. 字段校验失败时队列项可编辑。
3. 权限失败时本地草稿不得静默删除。
4. 冲突只提示摘要并引导 PC/Web 处理。
5. 附件上传失败不得丢失业务草稿。

## 8. 验收口径

1. 普通日志和错误响应不包含密码、令牌、刷新凭据、完整附件内容、完整本地路径、旧原始行或旧迁移诊断。
2. Viewer 不能通过 Web、手机队列、PC 同步或冲突解决写入云端。
3. 设备撤销后刷新令牌和同步上传均失效，但 PC 本地账本不删除。
4. 跨账本对象、附件、同步批次和审计查询被权限隔离。
5. 旧 MoneyHome8 原始文件、迁移审计、迁移报告、脱敏摘要、旧路径和旧原始行不进入云端对象、副本、审计、日志或错误响应。
6. 网络失败、版本冲突、幂等重放、权限变化和附件失败都有可解释状态。

## 9. 当前无需人工确认

本计划没有引入新的产品取舍；它把已确认的 HTTPS、静态加密、密钥管理、账本级权限隔离、非第一版完整 E2EE、审计、错误和恢复边界整理成统一需求。
