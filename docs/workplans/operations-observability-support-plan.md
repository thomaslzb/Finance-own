# 运维、监控、诊断与支持需求计划

本文档承接 `security-audit-error-handling-plan.md`、`dotnet-sync-api-plan.md`、`account-device-ledger-membership-plan.md`、`auth-session-secret-storage-plan.md`、`data-retention-deletion-recovery-plan.md`、`backup-import-export-plan.md`、`feature-catalog.md` 和 `runtime-dfm-functional-evidence.md`，定义 Finance Own 第一版云端运行监控、诊断 ID、告警、支持入口、客户服务入口、数据修复和隐私边界需求。

## 1. 核心原则

1. 运维监控只收集服务健康、性能、错误、同步和容量指标，不收集财务明细。
2. 支持人员只能通过脱敏诊断 ID、账本范围权限和审计入口定位问题。
3. 数据修复必须走受控流程，不能绕过账本权限、审计和对象版本。
4. 云端运维日志、告警和支持工单不得包含旧 MoneyHome8 原始文件、旧路径、旧原始行、旧字段值、迁移审计、迁移报告、脱敏摘要或 PC 机器环境诊断。
5. PC 本地迁移诊断只保存在 PC 本地，不能上传为支持附件。

## 2. 监控范围

第一版需要监控：

| 范围 | 指标 |
| --- | --- |
| API 健康 | 请求量、错误率、延迟、可用性 |
| 登录会话 | 登录成功/失败计数、刷新失败计数、设备撤销计数 |
| 同步 | 批次数、对象数、冲突数、失败原因分布 |
| 附件 | 上传失败、下载失败、短期授权失败、容量 |
| 数据库 | 连接池、慢查询、迁移状态、存储容量 |
| 后台任务 | 物理清理、备份、导出、告警发送结果 |
| 安全 | 权限拒绝、异常刷新、频繁失败、可疑设备活动 |

第一版不收集：

1. 交易金额明细。
2. 账户名称、分类名称、备注、附件内容。
3. PC 完整本地路径。
4. 旧 MoneyHome8 原始文件、旧字段值或迁移诊断。
5. 密码、访问令牌、刷新令牌或密钥材料。

## 3. 诊断 ID

结构化错误必须返回脱敏 `diagnostic_id`。

诊断 ID 要求：

| 字段 | 说明 |
| --- | --- |
| `diagnostic_id` | 用户可提供给支持人员的脱敏标识 |
| `service` | 产生诊断的服务或端侧模块 |
| `occurred_at` | 产生时间 |
| `error_code` | 稳定错误码 |
| `ledger_id_hash` | 可选脱敏账本标识 |
| `request_id` | 服务端请求追踪 ID |
| `sync_batch_id` | 同步相关时可记录 |

诊断 ID 不得包含：

1. 邮箱明文。
2. 账本名称。
3. 交易对象字段。
4. PC 完整本地路径。
5. 旧迁移证据。
6. 令牌或密码。

## 4. 告警

第一版告警类型：

| 告警 | 触发 |
| --- | --- |
| API 错误率高 | 服务端 5xx 或关键业务错误升高 |
| 同步失败率高 | 批次失败、版本冲突异常升高 |
| 附件上传失败高 | 存储或授权异常 |
| 登录异常 | 登录失败或刷新失败异常升高 |
| 权限拒绝异常 | `ledger_forbidden`、`device_revoked` 等异常升高 |
| 数据库容量或延迟异常 | 容量、连接池、慢查询 |
| 后台任务失败 | 清理、备份、导出、通知任务失败 |

告警内容只能包含脱敏聚合信息、服务名、错误码、时间窗口、诊断 ID 样本和运行指标，不包含用户财务明细。

## 5. 支持入口

支持入口第一版可以提供：

1. 根据 `diagnostic_id` 查找脱敏错误上下文。
2. 查看 API 错误码、时间、服务、请求 ID 和批次 ID。
3. 查看同步批次摘要：对象数量、成功数、失败数、冲突数。
4. 查看设备撤销和登录异常摘要。
5. 查看云端账本权限摘要，必须按最小必要权限展示。
6. 生成用户可读的脱敏排障建议。
7. 提供官网、FAQ、服务时间和受控联系方式入口。

客户服务入口规则：

1. PC/Web/手机展示客户服务入口时，不得自动发送账本数据、迁移证据、诊断包、附件内容或 PC 本地路径。
2. 打开外部网站、邮件、即时通讯或二维码前必须使用受控链接清单或配置，不从旧程序硬编码地址继承明文不安全行为。
3. 用户主动联系支持时，只能默认携带脱敏 `diagnostic_id`、客户端版本和错误码。
4. 服务时间、FAQ、官网和联系方式属于可配置内容，更新不得要求修改财务领域模型。
5. 旧客户服务页面证据、旧外链、二维码截图、迁移诊断和 PC 机器环境信息只保存在 PC 本地证据范围。

支持入口不得提供：

1. 查看用户密码、令牌或刷新凭据。
2. 查看附件原始内容。
3. 查看交易备注、账户名称、分类名称等财务明细，除非后续建立专门授权流程。
4. 查看 PC 本地完整路径。
5. 查看旧 MoneyHome8 迁移审计、迁移报告、脱敏摘要、旧路径或旧原始行。
6. 直接修改财务对象绕过对象版本和审计。

## 6. 数据修复

第一版数据修复只允许通过受控命令执行。

修复要求：

1. 修复命令必须有修复原因、操作者、审批或授权来源、影响范围和回滚方案。
2. 修复常规对象必须生成对象新版本。
3. 修复删除、墓碑、冲突或权限数据必须留下审计。
4. 修复前必须能预览影响对象数量和账本范围。
5. 修复后必须产生结果报告：成功、失败、跳过和冲突数量。

禁止：

1. 直接在数据库中无审计修改财务对象。
2. 跨账本批量修复时不带账本范围。
3. 用支持入口恢复旧迁移审计或旧原始行。
4. 用云端修复命令删除 PC 本地账本文件。

## 7. 日志保留和清理

日志分类：

| 日志 | 保留口径 |
| --- | --- |
| API 访问日志 | 脱敏路径、状态码、延迟、诊断 ID |
| 应用错误日志 | 错误码、服务、脱敏上下文 |
| 审计日志 | 关键业务操作、账号设备、同步和冲突 |
| 安全日志 | 登录失败、刷新失败、权限拒绝、设备撤销 |
| 运维指标 | 聚合指标和运行状态 |

日志清理规则：

1. 日志保留周期由技术设计配置，不在需求阶段固化具体天数。
2. 删除日志不得影响财务对象的审计可追溯性要求。
3. 脱敏策略失败时应阻止记录敏感字段，而不是先写入后清理。
4. PC 本地迁移诊断不进入云端日志保留策略。

## 8. 三端诊断导出

PC 可以导出本机诊断包，但必须分级：

| 级别 | 内容 |
| --- | --- |
| 基础诊断 | 版本、错误码、脱敏诊断 ID、模块状态 |
| 同步诊断 | 同步状态、批次摘要、冲突数量 |
| 迁移诊断 | 仅 PC 本地查看，不作为云端支持附件 |

规则：

1. 用户导出诊断包前必须看到内容范围。
2. 默认诊断包不得包含 PC 完整本地路径、旧原始行、迁移审计、迁移报告或脱敏摘要。
3. 手机诊断只包含队列状态、错误码、诊断 ID 和设备摘要。
4. Web 诊断只包含浏览器会话状态、API 错误码和诊断 ID。

## 9. 权限和审计

运维和支持操作必须审计：

1. 查看诊断详情。
2. 查看同步批次摘要。
3. 触发数据修复预览。
4. 执行数据修复。
5. 导出脱敏诊断报告。
6. 调整告警或日志保留配置。

审计字段至少包括操作者、时间、操作类型、目标范围、诊断 ID、结果和理由。

审计不得包含密码、令牌、PC 完整本地路径、旧迁移证据或财务明细。

## 10. 错误模型

运维和支持错误码至少包括：

| 错误码 | 含义 | 处理 |
| --- | --- | --- |
| `diagnostic_not_found` | 诊断 ID 不存在或已过期 | 提示重新获取 |
| `diagnostic_access_denied` | 无权查看诊断 | 阻止访问并审计 |
| `support_scope_required` | 缺少账本或诊断范围 | 要求补充范围 |
| `repair_preview_required` | 修复前缺少预览 | 阻止执行 |
| `repair_permission_denied` | 无权修复 | 阻止执行 |
| `repair_version_conflict` | 修复对象版本变化 | 重新预览 |
| `telemetry_redaction_failed` | 脱敏失败 | 阻止写入敏感日志 |

错误响应不得包含 PC 完整本地路径、旧 MoneyHome8 原始路径、旧原始行、旧字段值、迁移审计、迁移报告、脱敏摘要、密码、令牌或 PC 机器环境诊断。

## 11. 验收要点

1. API 错误响应包含脱敏诊断 ID。
2. 运维指标不包含财务明细。
3. 告警内容只包含脱敏聚合信息。
4. 支持入口不能查看旧迁移证据或 PC 本地完整路径。
5. 支持入口不能直接无审计修改财务对象。
6. 数据修复必须先预览并留下审计。
7. PC 默认诊断包不包含旧迁移审计、迁移报告、脱敏摘要、旧路径或旧原始行。
8. 手机和 Web 诊断只包含会话、队列、API 错误和脱敏诊断信息。
9. 日志脱敏失败时不写入敏感日志。
10. 所有支持和修复操作可审计。
11. 客户服务入口不会自动上传账本数据、附件内容、旧迁移证据、PC 本地完整路径或诊断包。

## 12. 当前无需人工确认

本计划没有引入新的产品取舍；它细化的是已确认的结构化错误、诊断 ID、审计、日志脱敏、云端运行监控、数据修复受控流程和旧迁移证据只保存在 PC 本地的边界。
