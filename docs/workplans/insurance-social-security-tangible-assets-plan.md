# 保险、社保与重大资产需求计划

本文档承接 `three-client-requirements-analysis.md`、`investment-advanced-assets-calibration-plan.md`、`schedule-reminder-occurrence-plan.md`、`amount-currency-exchange-rate-plan.md`、`runtime-insurance-and-social-security-contract.md` 和 `runtime-major-and-tangible-assets-contract.md`，定义 Finance Own 第一版商业保险、社会保障、保险现金价值、重大资产、家居物品、估值、买卖、追加投资、处置和相关计划实例的需求边界。本文只定义需求口径，不把未校准的旧版保险公式、社保地区规则、成本市值比例和分期公式标记为已兼容。

## 1. 目标

1. 支持商业保险账户、社保账户、保险事件、现金价值快照、缴费计划和保险提醒实例。
2. 支持重大资产账户、家居物品账户、买入、追加投资、卖出、收益、费用、估值和分期买入基础对象。
3. 区分业务事件、资金交易、估值快照、派生投影和审计。
4. 保证保险、社保和重大资产资金流的分录平衡、幂等提交和失败回滚。
5. 支持 PC/Web 完整维护，手机端摘要查看和提醒状态。
6. 明确旧迁移证据、旧原始行、迁移报告和脱敏摘要只保存在 PC 本地。

## 2. 非目标

1. 第一版不复刻旧程序不可达的保险价值增减对话框。
2. 第一版不承诺完整保险现金价值、退保损益、费用税务、社保地区差异或重大资产成本市值比例公式。
3. 第一版不把自动缴费或自动计划执行作为无审计后台静默入账。
4. 第一版不在手机端提供复杂保单、社保、资产估值或分期配置。
5. 第一版不上传旧 MoneyHome8 保险、社保、重大资产、物品、估值或分期的原始证据。

| `beneficiary_person_ids` | 受益人 |
| `coverage_start_date` | 保障开始业务日期 |
| `coverage_end_date` | 保障结束业务日期 |
| `premium_summary_mode` | 缴费统计口径 |
| `status` | `active`、`surrendered`、`closed`、`archived` |

| `as_of_date` | 估值业务日期 |

`SocialSecurityAccountDto` 字段：

| 字段 | 说明 |
| --- | --- |
| `social_security_account_id` | 社保账户 ID |
| `ledger_id` | 所属账本 |
| `person_id` | 参保人 |
| `region_code` | 地区编码 |
| `project_type` | `pension`、`medical`、`unemployment`、`injury`、`maternity`、`housing_fund` |
| `currency_code` | 币种 |
| `status` | `active`、`closed`、`archived` |
| `version` | 对象版本 |

规则：

1. 现金价值是按估值日保存的快照，不等同于账户资金余额，也不能由累计保费替代。
2. 同一保单同一估值日只有一个有效现金价值快照；重复新增使用显式 upsert 并保存审计。
3. 现金价值变化不自动产生资金收入、支出或已实现收益。
4. 保费缴纳、保费返还、保险分红、退保和社保缴费必须是不同事件类型，不能由金额正负推断。
5. 社保缴费与领取必须关联具体项目，养老、医疗、失业、工伤、生育和住房公积金不得只用显示名称区分。
6. 保单号、人员身份信息和敏感备注不得进入普通日志、截图、导出、错误响应或搜索索引。

## 4. 保费计划与保险事件

`PremiumScheduleDto` 字段：

| 字段 | 说明 |
| --- | --- |
| `premium_schedule_id` | 缴费计划 ID |
| `policy_account_id` | 所属保单 |
| `schedule_version` | 计划版本 |
| `frequency` | 年缴、半年缴、季缴、月缴或一次性 |
| `premium_amount_minor` | 应缴金额 |
| `payment_account_id` | 可选支付账户 |
| `execution_policy` | `reminder_only`、`manual_action`、`auto_post_candidate` |
| `start_date` | 开始业务日期 |
| `end_rule` | 结束条件 |
| `status` | `active`、`paused`、`archived` |

规则：

1. “仅做提醒”允许不绑定资金账户，发生实例不可执行、可跳过；跳过只写实例动作，不生成保险事件或资金交易。
2. “固定账户定期扣款”必须绑定有效资金账户；保存计划定义不得立即扣款。
3. 手工执行先生成可审阅草稿；后台执行使用同一校验、幂等键和审计。
4. 修改保费计划只替换未来未处理实例，不能静默修改历史实例。
5. 缴费编辑器内联新建账户必须保留保费草稿；账户创建和保费保存是可独立回滚的动作。
6. 自动提交后账户中心、资金账户、保险工作区、计划列表和报表必须从同一提交版本刷新。

保险事件规则：

1. 正常缴纳保费选择资金账户时，保险事件和资金支出必须原子提交。
2. 开户已缴保费在无资金账户时保存为来源明确的初始调整事件，不虚构资金流水。
3. 保费返还和保险分红都增加累计领取，但必须保留不同业务类型。
4. 退保资金事件与账户生命周期转换是两个可审计动作；是否终止保单由显式字段表达。
5. 重复提交、页面刷新或任务重试不得重复到账或扣款。
6. 保费缴纳、返还、分红和退保必须保存业务日期来源，不能用同步接收时间、客户端当前时间或旧证据文件时间替代。
7. 保费统计口径必须显式区分收入、支出和中性调整；保费返还、保险分红和退保所得不得被金额正负号误归类为普通保费缴纳。
8. 退保命令必须返回保留保单与终止保单两种状态影响预览，终止保单不得删除历史保费、现金价值、资金交易或附件引用。
9. 从保单或计划进入资金账户、分类和候选对象选择时必须携带候选版本；候选被关闭、归档、移权、跨账本失效或权限变化时拒绝提交并保留草稿。
10. 保费返还、分红、退保、费用和税务拆分尚未校准时，事件可以保存事实组成，但损益和税务结论必须标记为 `pending_calibration`。

## 5. 重大资产与家居物品对象

`MajorAssetAccountDto` 字段：

| 字段 | 说明 |
| --- | --- |
| `major_asset_id` | 重大资产 ID |
| `ledger_id` | 所属账本 |
| `name` | 资产名称 |
| `currency_code` | 币种 |
| `asset_kind` | 房产、车辆、收藏、其它重大资产 |
| `owner_person_id` | 所有人 |
| `account_group_id` | 账户组 |
| `status` | `active`、`disposed`、`closed`、`archived` |
| `version` | 对象版本 |

`MajorAssetValuationDto` 字段：

| 字段 | 说明 |
| --- | --- |
| `valuation_id` | 估值 ID |
| `major_asset_id` | 重大资产 |
| `valuation_date` | 估值业务日期 |
| `market_value_minor` | 市值 |
| `currency_code` | 币种 |
| `source_type` | `manual`、`migration`、`appraisal`、`statement` |
| `old_value_minor` | 审计用旧值 |
| `new_value_minor` | 审计用新值 |
| `version` | 对象版本 |

`HouseholdItemAccountDto` 字段：

| 字段 | 说明 |
| --- | --- |
| `item_account_id` | 物品账户 ID |
| `ledger_id` | 所属账本 |
| `name` | 账户名称 |
| `currency_code` | 币种 |
| `usage_kind` | `personal_use`、`investment` |
| `status` | `active`、`archived` |
| `version` | 对象版本 |

规则：

1. 重大资产买入原子创建资产身份、买入事件、取得成本和同日初始市值。
2. 支付账户为空时保存外部资金来源；有支付账户时资产取得和资金流出必须原子提交。
3. 有贷款融资时资产、首付、负债本金和资产债务关系共享业务版本。
4. 当前市值来自不晚于查询日的最新有效估值快照；估值变化默认是未实现损益，不生成资金流水。
5. 同资产同日估值使用显式 upsert，保存旧值、新值和操作者审计。
6. 家居物品账户创建只写账户和可选关系，不预造物品主档、持仓、价格、交易或期初资金事件。
7. 同一重大资产可关联多笔贷款或既有贷款；买入和追加投资必须记录首付、贷款本金、费用、税费和外部来源的分配版本。
8. 选择既有贷款时必须返回候选范围、剩余本金、可用额度、币种和版本；候选为空只返回阻断状态，不创建空资产债务关系。
9. 重大资产和家居物品支持非本位币事实金额；原币、汇率方向、汇率来源和本位币投影必须同快照保存，缺汇率时不得混加。
10. 现金价值、资产估值和物品估值输入必须统一规范小数精度、千分位、科学计数法、负数、空值、最大值和聚合溢出错误。

## 6. 买卖、追加、收益、费用与处置

第一版资产命令：

| 命令 | 规则 |
| --- | --- |
| 买入重大资产 | 名称、币种和交易日必填；正金额创建成本和初始市值 |
| 追加投资 | 绑定稳定资产 ID；可选择是否同步增加市值 |
| 卖出或处置 | 指定卖出所得、成本结转和市值处理策略 |
| 投资收益 | 正金额，增加累计收益，不修改成本或市值 |
| 投资费用 | 正金额，减少累计收益，不修改成本或市值 |
| 估值新增或修改 | 写估值快照，不生成资金流水 |
| 家居物品买入 | 物品账户、分类、名称、数量、单价或金额和交易日必填 |
| 分期买入 | 原子创建买入交易、持仓批次、分期协议、负债或资金分录和计划交易 |

规则：

1. 成本来自有效买入批次、追加投资和成本结转，不被后续估值覆盖。
2. 全额或部分卖出必须原子结转成本、确认已实现收益，并按所选规则调整市值。
3. 无收入账户时保存外部所得，不伪造资金账户引用。
4. 追加投资仅成本追加不得生成或修改估值版本。
5. 绑定资金账户的收益或费用必须与资金账户流入或流出原子提交。
6. 零金额旧资产或历史事件可以迁移和查询；新建是否允许零金额由产品规则和字段错误明确表达。
7. 分期买入取消、校验失败或保存失败不得留下协议、占位持仓、提醒或计划分录。
8. 成本与市值不相等时，部分卖出的成本结转比例、舍入规则和尾差归属在校准前必须标记为 `pending_calibration`，不能输出正式损益。
9. 全额卖出、部分卖出、收益和费用必须拆分资金事实、成本结转、费用税务和估值处理策略；任何一步失败都整体回滚。
10. 删除唯一估值快照、最新估值快照和非最新估值快照必须返回不同影响预览，并重建账户、明细、趋势和报表投影。
11. 家居物品买入、卖出、重估、分期和持有成本必须保存批次、数量、单位、成本算法和公式状态；成本算法未校准时只展示事实和 `pending_calibration`。
12. 分期买入跨期生成计划时必须保护已入账期次，重算只影响未来未处理期次，并保留计划版本和审计。

## 8. 同步、冲突与删除

同步规则：

1. 保单、社保账户、现金价值快照、保险事件、重大资产、估值、资产交易和分期协议作为新系统对象同步。
2. 云端、Web 和手机不得保存或请求旧 MoneyHome8 原始文件、旧路径、旧原始行、旧字段值、迁移审计、迁移报告、脱敏摘要或 PC 机器环境诊断。
3. 并发修改同一现金价值、估值快照、保费计划、资产交易或退保状态时进入冲突解决。
4. 手机离线只保留摘要缓存或本机草稿；上传失败不得丢弃用户输入。

删除和关闭规则：

1. 存在保险事件、资金交易、现金价值、估值、持仓、分期、附件或审计引用时，不做无审计物理删除。
2. 删除保单、社保项目、重大资产、物品账户或估值快照前必须返回影响预览。
3. 退保、关闭、处置、归档和删除是不同动作。
4. 删除与其它端修改并发时进入冲突解决。

## 9. 查询与报表

查询规则：

1. 保险工作区的账户列表、交易明细、现金价值和账户概况必须绑定同一账户选择和查询时点。
2. 删除快照后，账户列表、交易页、趋势图、资产汇总和报表必须从同一已提交版本重建。
3. 重大资产交易明细、当前持有范围、购买成本、市值和成本市值构成必须使用同一查询快照。
4. 当前持有范围、所有记录范围、零金额兼容对象和清仓对象的包含规则必须稳定、可解释和可测试。
5. 跨币种投影保存原币金额、汇率方向、汇率来源和快照时间；原币与本位币不得混加。
6. 导出与打印复用当前查询快照，不在导出过程中混入后续写入。

报表规则：

1. 保险账户余额取当前有效现金价值，不取投保金额或累计缴费。
2. 现金价值快照更新不得新增或改写保险交易。
3. 重大资产估值变化默认是未实现损益；处置时才计算已实现损益。
4. 成本市值不相等时的比例、舍入和尾差在校准前标记为 `pending_calibration`。
5. 导出不得包含旧迁移证据、PC 本地完整路径、保单号明文或敏感人员信息。

## 10. 审计与隐私

审计必须覆盖：

1. 创建、修改、关闭、退保、处置、归档和删除对象。
2. 现金价值和重大资产估值的新增、upsert、修改和删除。
3. 保费缴纳、返还、分红、社保缴费、社保领取、资产买入、追加、卖出、收益、费用和分期。
4. 自动计划实例领取、跳过、执行、失败和重试。
5. 冲突解决、权限阻止、引用影响预览和迁移导入。

隐私规则：

1. 旧 MoneyHome8 迁移证据只保存在 PC 本地。
2. 云端、Web 和手机不得保存或请求旧原始文件、旧路径、旧原始行、旧字段值、迁移审计、迁移报告、脱敏摘要或 PC 机器环境诊断。
3. 保单号、人员身份信息、联系方式和敏感备注不得进入普通日志、截图、导出、错误响应或搜索索引。
4. 错误响应和审计不得包含密码、令牌、PC 完整本地路径或旧迁移证据。

## 11. 错误码

| 错误码 | 含义 | 行为 |
| --- | --- | --- |
| `insurance_cash_value_negative` | 现金价值为负 | 阻止保存 |
| `insurance_cash_value_overflow` | 现金价值溢出 | 阻止保存 |
| `premium_occurrence_replay` | 缴费实例幂等重放 | 返回原结果 |
| `premium_schedule_history_locked` | 历史缴费实例阻止无痕重算 | 返回影响预览 |
| `insurance_surrender_state_conflict` | 退保状态并发冲突 | 进入冲突解决 |
| `insurance_event_allocation_invalid` | 保费、返还、分红、退保、费用或税务组成分配不平衡 | 阻止提交 |
| `social_security_project_invalid` | 社保项目不合法 | 阻止保存 |
| `asset_valuation_replay` | 估值 upsert 幂等重放 | 返回原结果 |
| `asset_valuation_unique_delete` | 唯一、最新或非最新估值删除影响不同 | 返回影响预览 |
| `asset_cost_allocation_pending` | 成本市值比例未校准 | 标记结果状态 |
| `asset_loan_allocation_invalid` | 资产首付、既有贷款、费用、税费或外部来源分配不平衡 | 阻止提交 |
| `household_item_cost_pending_calibration` | 物品成本算法未校准 | 标记结果状态 |
| `asset_reference_blocking` | 资产引用阻止删除 | 返回影响预览 |
| `sensitive_policy_field_forbidden` | 敏感字段进入禁止范围 | 阻止输出 |

错误响应不得包含 PC 完整本地路径、旧 MoneyHome8 原始路径、旧原始行、旧字段值、迁移审计、迁移报告、脱敏摘要、保单号明文、人员身份信息、联系方式、令牌或密码。

## 12. 验收场景

1. PC 创建商业保险账户、现金价值快照和保费计划，保存后账户中心、保险工作区和报表读取同一版本。
2. 同一保单同一日期重复新增现金价值时使用 upsert，并保存旧值和新值审计。
3. 删除唯一现金价值快照后，账户、交易页、趋势图和报表都投影为零，不从缓存回填旧值。
4. 仅提醒保费实例可跳过但不可执行；固定账户缴费实例执行后资金账户和保险事件原子提交。
5. 退保不终止与退保并终止产生不同状态，历史保费、现金价值和资金关联保留。
6. 社保缴费必须关联参保人、地区和具体项目。
7. 重大资产买入、追加投资、卖出、收益和费用均保持成本、市值、现金和负债投影一致。
8. 同资产同日估值重复新增使用 upsert；删除最新估值回退到上一有效快照。
9. 手机只展示保单、社保、资产和到期提醒摘要，不显示复杂配置入口。
10. 保费返还、分红和退保保存为不同事件类型，保留保单和终止保单必须生成不同影响预览。
11. 现金价值边界覆盖负数、空值、千分位、科学计数法、外币精度、最大值和聚合溢出，错误响应不得泄露旧路径或旧原始行。
12. 多贷款重大资产买入必须保持首付、既有贷款、费用、税费、外部来源、资产成本和初始市值投影一致。
13. 成本与市值不相等时部分卖出标记成本比例、舍入和尾差公式状态；未校准时不输出正式损益。
14. 家居物品买入、卖出、重估、分期和持有成本保存批次和公式状态；未校准成本算法不进入正式结论。
15. 旧迁移相关保险、社保、资产、估值、分期证据、迁移审计、迁移报告、脱敏摘要、旧路径和旧原始行只保存在 PC 本地，云端、Web 和手机不得保存或请求。

## 13. 当前无需人工确认

本计划没有引入新的产品取舍；它细化的是已确认的保险、社保、现金价值、重大资产、家居物品、估值、分期、三端职责、幂等审计、敏感信息保护和旧迁移证据 PC 本地保存边界。
