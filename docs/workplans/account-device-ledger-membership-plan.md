# 账号、设备与账本成员需求计划

本文档承接 `three-client-requirements-analysis.md`、`dotnet-sync-api-plan.md`、`mobile-offline-queue-plan.md` 和 `three-client-acceptance-scenarios.md`，把 Finance Own 第一版账号、设备、账本成员、角色变化和跨端权限状态整理成可实施需求边界。本文只定义需求，不进入具体认证框架、数据库 DDL 或 UI 组件实现。

## 1. 目标

第一版必须支持：

1. 自有账号体系，优先邮箱、密码和昵称。
2. Web 和手机必须登录后使用。
3. PC 可未登录完整使用本地账本。
4. PC 登录后必须显式确认，才把本地账本绑定账号并开启同步。
5. 三端登录设备登记、设备列表和设备撤销。
6. 多账本成员模型，至少支持 Owner、Editor、Viewer。
7. 账本级权限隔离，所有云端对象、附件、同步批次和报表缓存都必须限定 `ledger_id`。
8. 权限变化后，PC/手机本地未上传变更不得静默丢失或静默上传。

第一版不要求：

1. 手机号登录、第三方登录、企业 SSO。
2. 账户级、分类级、金额级细粒度权限。
3. 手机端完整成员管理台。
4. PC 未开启同步的本地账本参与云端成员管理。
5. 设备撤销后远程删除 PC 本地账本文件。

## 2. 账号边界

账号由 .NET 云端服务管理，PC 本地核心不保存密码、访问令牌或刷新令牌。

账号字段第一版至少包括：

| 字段 | 说明 |
| --- | --- |
| `user_id` | 云端用户稳定标识 |
| `email` | 第一版主登录标识 |
| `nickname` | 展示名 |
| `phone_reserved` | 手机号预留字段；第一版可以为空 |
| `created_at` | 账号创建时间 |
| `status` | active、disabled 或 deleted |

账号规则：

1. 密码只通过 HTTPS 提交，不进入普通日志、错误响应或 PC 本地核心领域表。
2. 登录成功后返回访问令牌、刷新令牌、用户资料和当前设备摘要。
3. Web 和手机未登录时不能进入账本数据页。
4. PC 未登录时只能访问本地账本，不调用云端账本、成员或同步 API。
5. PC 登录不等于开启同步；同步必须由用户在账本范围内显式确认。

## 3. 设备边界

设备用于会话管理、同步来源追踪、撤销和审计。

设备类型：

| 类型 | 说明 |
| --- | --- |
| `pc` | Flutter Desktop 客户端 |
| `web` | Flutter Web 浏览器会话 |
| `mobile` | Flutter Mobile 客户端 |

设备字段第一版至少包括：

| 字段 | 说明 |
| --- | --- |
| `device_id` | 云端设备稳定标识 |
| `user_id` | 设备所属账号 |
| `device_type` | pc、web 或 mobile |
| `device_name` | 用户可识别名称 |
| `client_instance_id` | 客户端安装或浏览器会话生成的幂等标识 |
| `last_seen_at` | 最近活跃时间 |
| `last_sync_at` | 最近成功同步时间 |
| `revoked_at` | 撤销时间；未撤销时为空 |

设备撤销规则：

1. 撤销设备后，该设备刷新令牌失效。
2. 被撤销设备继续调用云端同步 API 时返回 `device_revoked` 或等价权限错误。
3. 撤销 Web 设备后，浏览器必须重新登录。
4. 撤销手机设备后，待上传队列停止上传，并保留本地草稿状态提示。
5. 撤销 PC 设备后，不删除 PC 本地账本文件；已开启同步的账本进入需要重新登录或重新授权的状态。

## 4. 账本成员模型

第一版采用账本级成员模型，不把系统写死为单人单账本。

角色：

| 角色 | 第一版权限 |
| --- | --- |
| Owner | 账本完整读写、成员管理、同步管理、归档或删除账本 |
| Editor | 常规财务对象读写、附件上传、冲突解决、查看同步状态 |
| Viewer | 查看账本、基础报表、附件下载；不能写入、上传或解决冲突 |

成员字段第一版至少包括：

| 字段 | 说明 |
| --- | --- |
| `member_id` | 成员记录稳定标识 |
| `ledger_id` | 所属账本 |
| `user_id` | 成员用户 |
| `email` | 成员邮箱 |
| `nickname` | 展示名 |
| `role` | Owner、Editor 或 Viewer |
| `status` | invited、active、removed |
| `invited_by` | 邀请人 |
| `joined_at` | 加入时间 |
| `updated_at` | 最近角色或状态变化时间 |

成员规则：

1. 每个云端账本至少有一个 Owner。
2. 最后一个 Owner 不能被移除或降级。
3. 第一版邀请成员只能邀请为 Editor 或 Viewer，不能直接邀请为 Owner。
4. Owner 可修改 Editor/Viewer 角色或移除成员。
5. Editor 和 Viewer 不能管理成员或删除账本。
6. PC 本地账本未开启同步前没有云端成员概念。
7. PC 本地账本开启同步后，云端成员变化只影响云端读写和同步能力，不自动删除 PC 本地文件。

## 5. 权限矩阵

| 操作 | Owner | Editor | Viewer |
| --- | --- | --- | --- |
| 查看账本和基础报表 | 是 | 是 | 是 |
| 新增收入、支出、转账 | 是 | 是 | 否 |
| 修改或删除常规交易 | 是 | 是 | 否 |
| 上传附件 | 是 | 是 | 否 |
| 下载附件 | 是 | 是 | 是 |
| 查看同步状态 | 是 | 是 | 是 |
| 解决冲突 | 是 | 是 | 否 |
| 邀请成员 | 是 | 否 | 否 |
| 修改成员角色 | 是 | 否 | 否 |
| 移除成员 | 是 | 否 | 否 |
| 归档或删除云端账本 | 是 | 否 | 否 |
| 删除 PC 本地账本文件 | 本机用户单独确认 | 本机用户单独确认 | 本机用户单独确认 |

权限错误必须区分：

| 错误码 | 场景 |
| --- | --- |
| `unauthenticated` | 未登录或访问令牌无效 |
| `token_expired` | 访问令牌过期，可刷新 |
| `device_revoked` | 当前设备已撤销 |
| `ledger_forbidden` | 用户不是账本成员或成员已移除 |
| `ledger_readonly` | Viewer 尝试写入、上传或解决冲突 |
| `last_owner_required` | 尝试移除或降级最后一个 Owner |

## 6. 三端行为

### 6.1 PC

PC 必须支持：

1. 未登录创建、打开、维护本地账本。
2. 登录后查看当前账号和设备摘要。
3. 对每个本地账本单独确认是否开启同步。
4. 开启同步时展示账本名称、对象数量、附件规模和隐私提示。
5. 角色变化后，未上传变更进入同步失败或冲突提示，不静默上传。
6. 设备撤销后保留本地账本和本地迁移证据，只停止云端同步能力。

PC 不得：

1. 把密码、刷新令牌写入 Rust 核心领域表。
2. 因云端成员移除自动删除本地账本文件。
3. 上传旧 MoneyHome8 原始文件、迁移审计、迁移报告、脱敏摘要、旧路径或旧原始行。

### 6.2 Web

Web 必须支持：

1. 未登录进入登录页。
2. 登录后查看账本列表、当前角色和成员基础信息。
3. Owner 管理成员。
4. Viewer 只能查询，不显示可成功提交的写入、上传或冲突解决入口。
5. 设备撤销后重新登录。

Web 不得：

1. 读取 PC 本地 SQLite。
2. 展示 PC 本地账本完整路径。
3. 展示旧迁移审计、迁移报告、脱敏摘要、旧路径或旧原始行。

### 6.3 手机

手机必须支持：

1. 登录后选择账本。
2. 显示当前账本角色和同步摘要。
3. Editor/Owner 可新增常用记账并上传队列。
4. Viewer 只能查看和保存不会上传的本机草稿提示，不能成功提交写入。
5. 成员被移除、降级为 Viewer 或设备被撤销时，待上传队列停止上传并显示可解释状态。

手机不要求：

1. 完整成员管理。
2. 字段级冲突解决。
3. 完整本地账本维护。

## 7. 角色变化与待上传数据

权限变化会影响同步安全，不能被简化成普通网络错误。

处理规则：

1. Editor 降级为 Viewer 后，云端必须拒绝后续写入。
2. 手机本地待上传队列遇到 `ledger_readonly` 时进入 `Failed` 或 `Conflict` 摘要，并保留草稿内容。
3. PC 本地待上传对象遇到 `ledger_readonly` 时进入同步失败或冲突提示，用户可另存本地副本或联系 Owner。
4. 成员被移除后，云端返回 `ledger_forbidden`，本地数据不自动删除。
5. 设备撤销后返回 `device_revoked`，本地草稿和 PC 本地账本仍保留。
6. 权限错误不得触发自动覆盖、自动删除或自动丢弃用户输入。

## 8. 审计和隐私

云端审计必须记录：

1. 登录、刷新、退出和设备撤销。
2. 账本创建、归档或删除。
3. 成员邀请、接受、移除和角色变化。
4. 同步批次来源设备和处理结果。
5. 权限拒绝和冲突解决。

云端审计不得记录：

1. 密码、访问令牌、刷新令牌。
2. PC 本地账本完整路径。
3. 旧 MoneyHome8 原始文件、旧原始行或旧字段值。
4. 迁移审计、迁移报告、脱敏摘要或 PC 机器环境诊断。
5. 附件完整内容。

## 9. 验收口径

1. Web 和手机未登录不能访问账本数据。
2. PC 未登录可以完整使用本地账本。
3. PC 登录后未显式确认同步时，本地账本不上传云端。
4. 设备撤销后刷新令牌和同步上传失效，但 PC 本地账本文件不删除。
5. Owner 可邀请 Editor/Viewer，Editor/Viewer 不能管理成员。
6. 最后一个 Owner 不能被移除或降级。
7. Viewer 写入、附件上传和冲突解决被拒绝，并返回明确权限错误。
8. Editor 降级为 Viewer 后，手机和 PC 待上传数据保留但不能静默上传。
9. 不同账本的对象、附件、同步批次、冲突和报表缓存互相隔离。
10. 云端响应和审计不包含旧迁移证据或 PC 本地敏感路径。

## 10. 当前无需人工确认

本计划没有引入新的产品取舍；它细化的是已确认的自有账号、设备撤销、多账本成员、账本级权限、PC 本地未登录和显式开启同步边界。
