# 账本生命周期与本地存储需求计划

本文档承接 `three-client-requirements-analysis.md`、`account-device-ledger-membership-plan.md`、`backup-import-export-plan.md`、`security-audit-error-handling-plan.md` 和 `flutter-pc-local-api-plan.md`，定义 Finance Own 第一版账本创建、打开、关闭、删除、云端绑定、本地文件和三端可见性的需求边界。

## 1. 核心原则

1. PC 本地账本可以在未登录状态完整使用。
2. 登录不等于开启同步，开启同步必须由用户显式确认。
3. PC 本地账本文件由本机用户控制，云端权限变化不得自动删除 PC 本地文件。
4. Web 端在线为主，必须登录后使用云端账本。
5. 手机端依赖云端账本和轻量缓存，不保存完整本地账本。
6. 旧 MoneyHome8 迁移相关证据只保存在 PC 本地。

## 2. 账本类型

| 类型 | 位置 | 是否必须登录 | 第一版用途 |
| --- | --- | --- | --- |
| PC 本地账本 | PC SQLite 和受管附件目录 | 否 | 离线完整账本、旧迁移、备份恢复 |
| 云端账本 | .NET API + PostgreSQL 对象副本 | 是 | Web 在线、三端同步、权限和冲突协调 |
| 手机缓存账本 | 手机轻量缓存和待上传队列 | 是 | 最近数据展示、离线草稿、队列上传 |

PC 本地账本开启同步后会绑定或创建对应云端账本，但本地文件仍然是 PC 端本机资产，不因为云端账本存在而变成云端托管文件。

## 3. PC 本地账本状态

| 状态 | 含义 | 允许操作 |
| --- | --- | --- |
| `NoLedger` | 未打开账本 | 创建、打开、导入 |
| `LocalOnly` | 已打开本地账本，未登录或未开启同步 | 本地记账、基础资料、备份、旧迁移 |
| `LoggedInNotSynced` | 已登录但未开启同步 | 本地使用、查看同步说明、显式开启同步 |
| `SyncEnabled` | 已绑定云端账本 | 本地使用、上传、下载、冲突处理 |
| `SyncPaused` | 用户暂停或网络不可用 | 本地使用、保留待上传队列 |
| `PermissionChanged` | 云端角色变化影响同步 | 本地保留、提示权限、阻止无权上传 |
| `DeviceRevoked` | 当前设备授权被撤销 | 本地保留、停止同步、要求重新登录或重新授权 |
| `LocalCorrupt` | 本地文件损坏或校验失败 | 阻止写入、提示恢复备份 |
| `Closing` | 正在关闭账本 | 阻止新写入、等待任务收敛 |

## 4. 创建账本

PC 创建本地账本至少需要：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `ledger_name` | 是 | 账本名称 |
| `base_currency_code` | 是 | 本位币 |
| `storage_location` | 是 | PC 本地受管目录或用户确认的保存位置 |
| `first_account` | 否 | 首个账户资料 |

规则：

1. 创建本地账本不要求登录。
2. 创建时初始化 SQLite schema、账本元数据、默认币种和必要基础资料。
3. 本地账本路径只在 PC 本地保存，不能上传云端或出现在云端错误响应中。
4. 默认不自动开启同步。

Web 创建云端账本至少需要登录账号、账本名称、本位币和初始 Owner。Web 创建的账本没有 PC 本地文件，PC 登录后可以选择同步下载为本地账本副本。

手机第一版不承担完整账本初始化能力；可选择已有云端账本并创建离线草稿。

## 5. 打开和关闭

PC 打开账本：

1. 校验文件存在、格式版本、SQLite 可读写状态和受管附件目录。
2. 读取账本 ID、本位币、schema 版本、最近同步状态和本地设置。
3. 检查是否有未完成迁移批次、未上传对象、冲突或本地恢复任务。
4. 不因为检测到云端账号而自动上传本地对象。

PC 关闭账本：

1. 阻止新的写命令进入。
2. 等待本地写事务、备份任务和导入预览收敛。
3. 同步上传可以取消或后台暂停，但必须保留可恢复状态。
4. 关闭后释放 SQLite 连接和附件文件句柄。

## 6. 云端绑定和开启同步

PC 本地账本开启同步必须显式确认：

1. 用户登录。
2. 系统展示同步范围：新系统对象、基础资料、交易、附件元数据和可选附件内容。
3. 系统展示禁止上传范围：旧 MoneyHome8 原始文件、旧路径、旧原始行、旧字段值、迁移审计、迁移报告、脱敏摘要和 PC 机器环境诊断。
4. 用户选择绑定已有云端账本或创建新云端账本。
5. 系统建立本地 `sync_profile` 和云端账本映射。

开启同步后，仅新系统对象进入云端对象副本。旧迁移证据仍只保存在 PC 本地。

## 7. 删除和移除

删除需要区分三个动作：

| 动作 | 影响 | 权限和确认 |
| --- | --- | --- |
| 从当前设备移除云端账本入口 | 不删除云端账本，不删除其它设备数据 | 当前用户确认 |
| 删除 PC 本地账本文件 | 删除本机文件和受管附件目录 | 本机用户二次确认 |
| 删除云端账本 | 云端对象进入删除流程 | Owner 二次确认，按服务端策略执行 |

规则：

1. 云端删除账本不自动删除 PC 本地账本文件。
2. 设备撤销不自动删除 PC 本地账本文件。
3. Viewer 不能删除云端账本。
4. PC 本地删除前应提示备份状态、未上传对象和冲突数量。
5. 删除本地文件不得通过 Web 或手机远程触发。

## 8. 备份和恢复

PC 本地备份恢复以 `backup-import-export-plan.md` 为准，本计划补充账本生命周期口径：

1. 本地备份默认包含新系统 SQLite、受管附件目录和必要本地设置。
2. 本地备份不得包含访问令牌、刷新令牌或云端密钥。
3. 旧迁移审计、迁移报告和脱敏摘要是否进入本地备份，应作为 PC 本地备份选项处理，不上传云端。
4. 恢复本地备份默认生成新的本地账本副本，避免覆盖当前打开账本。
5. 恢复后的云端绑定必须重新校验，不能继承已撤销设备授权。

Web 第一版可以提供云端对象恢复入口，但不读取 PC 本地备份文件。

手机第一版不提供完整账本备份恢复，只保留草稿队列和缓存恢复。

## 9. 账簿结算与恢复点

账簿结算用于把旧期间的账户余额、未结清对象和必要摘要结转到新的业务期间或新账本状态。第一版只允许 PC 本地完整执行，Web 和手机只能在已同步的新系统对象上查看结算结果或摘要。

`LedgerSettlementPreviewDto` 字段：

| 字段 | 说明 |
| --- | --- |
| `ledger_id` | 目标账本 |
| `cutoff_date` | 结算截止业务日期，采用账本本地自然日闭区间 |
| `scope` | 账户、币种、未结清债务、计划、持仓和其它参与结算的对象范围 |
| `restore_point_id` | 执行前生成的 PC 本地恢复点 |
| `generated_adjustments` | 将要生成的余额调整、结转分录或状态调整摘要 |
| `blocked_items` | 因缺汇率、未平衡、未校准公式、锁定对象或权限不足而阻断的项目 |
| `old_evidence_ref` | 仅 PC 本地可见的旧程序校准证据引用，不上传云端 |

规则：

1. 结算前必须生成 PC 本地恢复点或要求用户完成本地备份确认。
2. 结算必须固定 `cutoff_date`、参与对象版本、汇率快照和公式状态，不能用执行完成时间替代业务截止日。
3. 结算生成的余额调整、期初事件或状态变更必须同事务提交；失败时整体回滚到执行前状态。
4. 重复执行同一账本、截止日和对象版本的结算应返回原结果或明确拒绝，不能重复生成余额调整。
5. 已同步账本的结算结果可以作为新系统对象同步；旧程序校准证据、旧路径、旧原始行、结算迁移审计、迁移报告、脱敏摘要和 PC 机器环境诊断只保存在 PC 本地。
6. Web 和手机不得发起读取 PC 本地旧证据的结算；如果需要展示结算摘要，只读取云端中的新系统对象和脱敏审计。
7. 恢复点恢复后必须重建本地索引、余额投影和同步游标状态；已上传云端的结算对象如需撤销，必须走新系统对象版本、墓碑或冲突流程，不远程删除 PC 本地恢复点。

结算错误码至少包括：

| 错误码 | 含义 |
| --- | --- |
| `settlement_cutoff_invalid` | 截止日期无效或超出账本业务范围 |
| `settlement_restore_point_failed` | PC 本地恢复点创建失败 |
| `settlement_blocked_items` | 存在未平衡、缺汇率或未校准阻断项 |
| `settlement_already_applied` | 同一结算范围已经执行 |
| `settlement_rollback_failed` | 写入失败后自动回滚失败，账本进入只读恢复状态 |

## 10. 本地文件和受管目录

PC 本地账本文件包括：

1. SQLite 主账本文件。
2. SQLite WAL/SHM 或等价事务辅助文件。
3. 受管附件目录。
4. 本地设置和同步状态。
5. PC 本地迁移审计、迁移报告、旧 ID 映射和迁移诊断。

存储规则：

1. 文件路径只保存在 PC 本地。
2. 云端只保存新系统对象 ID、附件云端元数据和同步版本。
3. 错误日志、审计日志和遥测不得包含完整本地路径。
4. SQLite 写入必须通过 Rust PC 本地核心，不允许 Flutter 直接写库。
5. Web 和手机不得读取 PC 本地文件。

## 11. Schema 和版本升级

PC 本地账本 schema 升级要求：

1. 打开账本时检测 schema 版本。
2. 升级前生成可恢复点或提示备份。
3. 升级过程需要独占本地写入。
4. 升级失败必须回滚或进入只读恢复状态。
5. 已开启同步的账本升级后必须保持对象 ID、版本和同步游标一致。

云端对象 schema 升级由 .NET API 和 PostgreSQL 迁移管理。PC 本地 schema 与云端对象 schema 可以不同，但必须通过同步合同保持业务对象语义一致。

## 12. 多账本隔离

多账本隔离要求：

1. 每个账本有独立 `ledger_id`。
2. PC 本地文件和受管附件目录按账本隔离。
3. 云端对象必须携带 `ledger_id` 并按成员权限过滤。
4. 手机缓存按账号、设备和账本隔离。
5. 账本之间不能直接引用账户、分类、标签、往来方或附件对象。
6. 切换账本时必须清理当前页面的选择器、缓存和草稿上下文。

## 13. 错误模型

账本生命周期错误码至少包括：

| 错误码 | 含义 | 三端处理 |
| --- | --- | --- |
| `ledger_not_found` | 账本不存在或无权访问 | 返回账本选择 |
| `ledger_locked` | 本地账本文件被占用 | 提示关闭占用程序或重试 |
| `ledger_corrupt` | 本地账本损坏 | 阻止写入并提示恢复 |
| `ledger_schema_unsupported` | schema 版本不支持 | 提示升级或只读打开 |
| `sync_not_enabled` | 未开启同步 | 展示显式开启入口 |
| `sync_binding_conflict` | 本地账本绑定的云端账本不一致 | 要求用户选择绑定策略 |
| `device_revoked` | 当前设备被撤销 | 停止同步，保留本地文件 |
| `ledger_permission_denied` | 当前角色无权操作 | 阻止云端写入，保留本地草稿 |
| `settlement_blocked_items` | 结算存在阻断项 | 展示预览阻断原因，不写入 |
| `settlement_restore_point_failed` | 结算恢复点创建失败 | 阻止结算，提示本地备份或检查磁盘 |

错误响应不得包含 PC 完整本地路径、旧 MoneyHome8 原始文件、旧原始行、旧字段值、迁移审计、迁移报告、脱敏摘要或 PC 机器环境诊断。

## 14. 验收要点

1. PC 未登录可以创建、打开、关闭和继续使用本地账本。
2. PC 登录后不会自动上传本地账本，必须用户显式确认开启同步。
3. 开启同步时系统明确展示只上传新系统对象，不上传旧迁移证据。
4. Web 只能使用云端账本，不能读取 PC 本地文件。
5. 手机只能使用云端账本和轻量缓存，不能保存完整本地账本。
6. 设备撤销后 PC 本地账本文件仍保留，同步停止。
7. 云端删除账本不自动删除 PC 本地账本文件。
8. 删除 PC 本地账本文件必须本机二次确认。
9. 多账本切换后不能沿用上一个账本的选择器、缓存或草稿上下文。
10. 错误、日志和审计不泄露 PC 本地完整路径或旧迁移证据。
11. PC 账簿结算必须先生成本地恢复点和结算预览，失败整体回滚，旧结算校准证据只保存在 PC 本地。
12. Web 和手机不能发起或保存旧证据参与的本地结算，只能查看已同步的新系统结算对象摘要。

## 15. 当前无需人工确认

本计划没有引入新的产品取舍；它细化的是已确认的 PC 本地完整可用、Web 在线为主、手机轻量缓存、多账本隔离、显式开启同步、设备撤销不删除本地文件和旧迁移证据只保存在 PC 本地的边界。
