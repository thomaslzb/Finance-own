# 认证会话与秘密存储需求计划

本文档承接 `account-device-ledger-membership-plan.md`、`security-audit-error-handling-plan.md`、`dotnet-sync-api-plan.md`、`ledger-lifecycle-storage-plan.md` 和 `settings-preferences-notification-plan.md`，定义 Finance Own 第一版账号登录、会话、令牌刷新、退出登录、设备撤销、秘密存储和三端降级行为的需求边界。

## 1. 核心原则

1. 第一版使用自有账号体系，邮箱、密码和昵称优先。
2. Web 和手机必须登录后使用云端账本。
3. PC 未登录可以完整使用本地账本。
4. PC 登录不等于开启同步；开启同步必须由用户在账本范围内显式操作。
5. 密码、访问令牌、刷新令牌、账本密码材料和密钥材料不得进入 Rust 核心领域表、普通设置、日志、错误响应或导出。
6. 设备撤销、令牌过期、刷新失败或成员移除不得删除 PC 本地账本文件或手机本地草稿。

## 2. 第一版账号范围

第一版支持：

| 能力 | 要求 |
| --- | --- |
| 注册 | 邮箱、密码、昵称 |
| 登录 | 邮箱和密码 |
| 退出登录 | 当前设备令牌失效 |
| 刷新会话 | 使用刷新令牌获取新访问令牌 |
| 设备登记 | 登录成功后登记当前设备 |
| 设备撤销 | 撤销后该设备刷新和同步失效 |
| 当前用户 | 返回用户 ID、邮箱、昵称和设备摘要 |

第一版后置：

1. 手机号登录。
2. 第三方登录。
3. 企业 SSO。
4. 多因素认证。
5. 完整端到端加密。

## 3. 会话状态

三端会话状态至少包括：

| 状态 | 含义 | 三端处理 |
| --- | --- | --- |
| `anonymous_local` | PC 未登录本地使用 | PC 可继续本地账本；Web/手机不适用 |
| `unauthenticated` | 未登录或无有效会话 | Web/手机进入登录；PC 不调用云端 |
| `authenticated` | 访问令牌有效 | 可调用云端 API |
| `token_expired` | 访问令牌过期 | 尝试刷新 |
| `refresh_failed` | 刷新失败或刷新令牌失效 | 引导重新登录 |
| `device_revoked` | 当前设备被撤销 | 停止云端同步，保留本地数据 |
| `account_disabled` | 账号不可用 | 停止云端访问，保留本地草稿或 PC 本地文件 |
| `sync_not_enabled` | PC 已登录但账本未开启同步 | 展示开启同步入口，不自动上传 |

## 4. 令牌和秘密存储

秘密分类：

| 秘密 | 存储边界 |
| --- | --- |
| 用户密码 | 只通过 HTTPS 提交，不在客户端持久保存 |
| 访问令牌 | 客户端安全存储或内存，短期有效 |
| 刷新令牌 | 客户端安全存储，撤销后失效 |
| 账本密码材料 | 本地安全存储或本地加密边界，不进入普通设置 |
| 密钥派生参数明文 | 不进入普通设置、日志或云端响应 |
| 云端服务密钥 | 服务端 KMS 或等价机制管理 |

PC：

1. 登录凭据只保存在系统凭据存储或等价安全设施。
2. Rust 本地核心只接收认证状态摘要或同步授权结果，不保存密码、访问令牌或刷新令牌。
3. PC 未登录本地账本不得依赖云端令牌才能打开。

Web：

1. Web 会话必须防止令牌进入普通日志、错误提示或可导出数据。
2. 令牌过期时优先刷新；刷新失败跳转登录页并保留目标路由。
3. 浏览器设备被撤销后必须重新登录。

手机：

1. 刷新令牌必须放入平台安全存储或等价安全设施。
2. 刷新失败后待上传队列停止上传，但保留草稿。
3. 设备撤销后不得清理本地草稿和附件临时缓存，除非用户本机明确清理。

## 5. PC 账本密码、KDF 与本地密钥

PC 本地账本可使用账本密码、KDF 参数和本地加密密钥保护文件或敏感分区。该能力只属于 PC 本地安全边界，不是云端账号密码，也不要求 Web 或手机安装 Rust 或接触旧账本密码材料。

`LocalLedgerSecretStateDto` 字段：

| 字段 | 说明 |
| --- | --- |
| `ledger_id` | 本地账本 |
| `secret_state` | none、password_required、unlocked、rotation_required、recovery_required |
| `kdf_profile_id` | KDF 配置标识；只保存算法族和参数摘要，不保存密码 |
| `retry_state` | 本机连续失败次数、冷却状态和可重试时间摘要 |
| `rotation_operation_id` | 换密钥或 KDF 升级操作 ID |
| `last_recovery_hint` | 脱敏恢复提示或恢复点引用 |

规则：

1. 旧 MoneyHome8 或旧本地账本密码验证、KDF 探测和兼容失败证据只保存在 PC 本地。
2. KDF 参数明文、派生密钥、中间材料、密码尝试值和失败样例不得上传云端，不得进入 Web、手机、普通日志、导出、支持包或错误响应。
3. 连续密码失败必须本机限速或冷却；冷却状态只能保存必要计数和时间摘要，不保存输入内容。
4. 换密钥、KDF 升级或账本加密状态变更必须先创建 PC 本地恢复点，并使用可恢复的分阶段操作状态。
5. 换密钥中断、磁盘不足、进程退出或校验失败时，账本必须回到旧密钥可打开状态或进入只读恢复状态，不能留下半加密账本。
6. 已开启同步的账本只同步新系统对象版本；本地密钥状态、KDF 探测证据、恢复点路径和旧密码诊断只保存在 PC 本地。
7. Web 和手机只能接收“需要在 PC 解锁后同步”的脱敏状态，不得请求用户输入 PC 本地账本密码。
8. 新账本创建成功后设置密码属于独立本地步骤；密码设置失败只影响加密状态，不回滚已创建账本、默认币种、首个账户或本地文件。
9. 首次设置、修改和清除账本密码都必须验证两次输入或旧密码要求，并通过临时副本、完整性检查和原子替换避免半加密状态。

错误码至少包括：

| 错误码 | 含义 |
| --- | --- |
| `ledger_password_required` | 打开本地账本需要密码 |
| `ledger_password_invalid` | 本机密码校验失败 |
| `ledger_password_confirm_mismatch` | 两次密码输入不一致 |
| `ledger_password_throttled` | 连续失败触发本机冷却 |
| `ledger_kdf_unsupported` | 本地账本 KDF 或旧格式暂不支持 |
| `ledger_key_rotation_interrupted` | 换密钥中断，需要恢复或重试 |
| `ledger_key_recovery_required` | 密钥操作失败后进入只读恢复流程 |

## 6. 登录和刷新流程

登录流程：

1. 用户提交邮箱、密码和客户端实例 ID。
2. .NET API 校验凭据。
3. 登录成功返回用户资料、访问令牌、刷新令牌和设备摘要。
4. 客户端保存令牌到安全边界。
5. 客户端读取当前用户、设备和账本列表。

刷新流程：

1. 访问令牌过期时，客户端使用刷新令牌请求新访问令牌。
2. 刷新成功后继续原请求或提示用户重试。
3. 刷新失败时进入 `refresh_failed`。
4. 刷新失败不得把待上传队列、PC 本地账本或本地草稿标记为已同步或已删除。

## 7. 退出登录

退出登录要求：

1. 当前设备令牌失效。
2. 清除客户端访问令牌和刷新令牌。
3. Web 返回登录页。
4. 手机保留本地草稿和缓存状态，但停止云端访问。
5. PC 保留本地账本、迁移证据、本地设置和未上传对象；已开启同步账本进入需要重新登录状态。
6. 退出登录不删除云端账本，也不删除 PC 本地文件。

## 8. 设备撤销

设备撤销要求：

1. 撤销后该设备刷新令牌失效。
2. 被撤销设备继续调用云端 API 时返回 `device_revoked`。
3. Web 被撤销后跳转登录。
4. 手机被撤销后待上传队列停止上传，保留草稿并提示重新登录或联系 Owner。
5. PC 被撤销后停止云端同步，保留本地账本文件和本地迁移证据。
6. 设备撤销必须审计操作者、目标设备、时间和结果。

设备撤销不得：

1. 删除 PC 本地账本文件。
2. 删除手机本地草稿。
3. 清理旧 MoneyHome8 迁移审计、迁移报告或脱敏摘要。
4. 静默上传被撤销设备上的待上传对象。

## 9. PC 未登录与同步开启

PC 未登录本地使用要求：

1. 可创建、打开、关闭、备份、恢复和维护本地账本。
2. 可本地记账、管理基础资料、附件和旧迁移。
3. 不调用云端账本、成员或同步 API。
4. 同步入口显示未登录或未开启同步状态。

PC 登录后：

1. 可查看当前账号和设备摘要。
2. 未显式开启同步前，本地账本仍然不上传。
3. 开启同步前必须展示同步范围和禁止上传范围。
4. 禁止上传范围包括旧 MoneyHome8 原始文件、旧路径、旧原始行、旧字段值、迁移审计、迁移报告、脱敏摘要和 PC 机器环境诊断。

## 10. 安全审计

必须审计：

1. 登录成功和失败。
2. 刷新失败。
3. 退出登录。
4. 设备登记、重命名和撤销。
5. PC 开启同步确认。
6. 令牌或设备相关异常。
7. PC 本地账本密码失败冷却、KDF 升级、换密钥开始、换密钥完成和恢复结果。

审计不得包含：

1. 密码。
2. 访问令牌和刷新令牌。
3. 账本密码材料和密钥材料。
4. PC 完整本地路径。
5. 旧 MoneyHome8 原始文件、旧原始行、旧字段值。
6. 迁移审计、迁移报告、脱敏摘要或 PC 机器环境诊断。
7. KDF 探测证据、派生密钥材料、密码失败样例或本地恢复点完整路径。

## 11. 错误模型

认证和会话错误码至少包括：

| 错误码 | 含义 | 三端处理 |
| --- | --- | --- |
| `unauthenticated` | 未登录或访问令牌无效 | 引导登录 |
| `token_expired` | 访问令牌过期 | 尝试刷新 |
| `refresh_failed` | 刷新失败 | 重新登录，保留本地数据 |
| `device_revoked` | 当前设备被撤销 | 停止同步，提示重新登录 |
| `account_disabled` | 账号不可用 | 停止云端访问 |
| `session_storage_unavailable` | 安全存储不可用 | 阻止保存令牌或提示受限使用 |
| `sync_requires_login` | 开启同步需要登录 | 展示登录入口 |
| `ledger_password_throttled` | 本地账本密码连续失败 | PC 本机冷却，Web/手机只显示脱敏状态 |
| `ledger_key_rotation_interrupted` | 本地换密钥中断 | PC 进入恢复或重试流程 |

错误响应不得包含密码、令牌、刷新凭据、KDF 探测证据、派生密钥材料、恢复点完整路径、PC 完整本地路径、旧 MoneyHome8 原始路径、旧原始行、旧字段值、迁移审计、迁移报告、脱敏摘要或 PC 机器环境诊断。

## 12. 验收要点

1. Web 和手机未登录不能访问账本数据。
2. PC 未登录可以创建和使用本地账本。
3. PC 登录后未显式开启同步时，不上传本地账本对象。
4. 登录响应不进入普通日志。
5. Rust 本地核心领域表不保存密码、访问令牌或刷新令牌。
6. 令牌过期可刷新；刷新失败保留本地草稿和 PC 本地账本。
7. 设备撤销后被撤销设备无法继续同步上传。
8. 设备撤销不删除 PC 本地账本文件和手机草稿。
9. 退出登录不删除云端账本或 PC 本地文件。
10. 错误和审计不泄露旧迁移证据或 PC 完整本地路径。
11. PC 本地账本密码连续失败会触发本机冷却，失败样例和 KDF 探测证据只保存在 PC 本地。
12. 换密钥或 KDF 升级中断后，账本能恢复到旧密钥可打开状态或明确进入只读恢复状态，不上传恢复点或密钥材料。

## 13. 当前无需人工确认

本计划没有引入新的产品取舍；它细化的是已确认的自有账号体系、PC 未登录本地使用、Web/手机必须登录、显式开启同步、设备撤销、令牌安全存储、日志脱敏和旧迁移证据只保存在 PC 本地的边界。
