# Flutter Web 在线端需求计划

本文档承接 `three-client-requirements-analysis.md`，定义 Flutter Web 第一版在线端需求。Web 端通过 .NET API 在线访问云端对象副本，不承担浏览器离线主账本写入。

## 1. 目标

Flutter Web 第一版必须支持：

- 登录后访问账本。
- 多账本切换。
- 在线新增、修改、删除常用财务记录。
- 查询账户、流水、预算、提醒和基础报表。
- 查看同步状态和设备来源。
- 完整冲突解决。
- 高风险删除二次确认。

Flutter Web 第一版不得：

- 离线写入主账本。
- 读取 PC 本地 SQLite。
- 调用 Rust 本地核心。
- 迁移旧 MoneyHome8 原始文件。
- 保存旧迁移审计、迁移报告或脱敏摘要。

## 2. 页面范围

| 页面 | 第一版能力 |
| --- | --- |
| 登录页 | 邮箱、密码登录，令牌过期提示 |
| 账本选择 | 账本列表、当前角色、最近同步摘要 |
| 账户中心 | 账户树、账户余额、隐藏/关闭状态 |
| 流水列表 | 日期、账户、分类、标签筛选，游标分页 |
| 记账表单 | 收入、支出、转账 |
| 预算/提醒摘要 | 预算列表、提醒列表和状态 |
| 基础报表 | 收支、资产和账户基础列表型报表 |
| 同步状态 | 设备来源、最近同步、冲突数量 |
| 冲突解决 | 冲突列表、字段差异、解决动作 |

## 3. 页面状态

Web 第一版页面必须把在线状态、权限状态和服务端错误分开表达。

| 页面状态 | 触发条件 | 页面行为 |
| --- | --- | --- |
| `unauthenticated` | 未登录或刷新令牌失效 | 跳转登录页，保留目标路由 |
| `loading` | 正在请求 .NET API | 展示加载状态，禁止重复提交 |
| `ready` | 数据加载完成 | 允许按角色操作 |
| `empty` | 查询成功但无数据 | 展示空状态和可用操作 |
| `readonly` | 当前用户为 Viewer | 隐藏或禁用写入按钮，保留查询 |
| `offline` | 浏览器无网络或 API 不可达 | 禁止主账本写入，允许保留当前只读页面 |
| `error` | API 返回业务错误或服务端错误 | 展示结构化错误和重试入口 |
| `conflict_pending` | 当前账本有未解决冲突 | 显示冲突入口，不阻止非冲突对象查询 |

## 4. 在线记账

Web 在线记账直接调用 .NET API 写入云端对象副本。

| 命令 | 需求 |
| --- | --- |
| 新增收入 | 金额大于零，账户和分类属于账本，分类方向允许收入 |
| 新增支出 | 金额大于零，账户和分类属于账本，分类方向允许支出 |
| 新增转账 | 必须有转出和转入账户，不能缺任一方向 |
| 修改常用记录 | 必须带当前对象版本 |
| 删除常用记录 | 二次确认，生成墓碑或作废版本 |

Web 表单失败必须显示字段错误，不得把服务端存储错误当成普通校验错误。

### 4.1 记账表单字段

收入、支出和转账表单共用字段：

| 字段 | 可为空 | 说明 |
| --- | --- | --- |
| `client_request_id` | 否 | Web 生成的幂等请求 ID |
| `ledger_id` | 否 | 当前账本 |
| `business_date` | 否 | 业务日期，格式 `YYYY-MM-DD` |
| `occurred_at` | 否 | 实际发生时间，ISO 8601 文本 |
| `amount_minor` | 否 | 主金额，最小单位整数且必须大于零 |
| `currency_code` | 否 | 主金额币种 |
| `party_id` | 是 | 人员或机构 |
| `description` | 是 | 交易说明 |
| `tag_ids` | 否 | 标签 ID 列表 |
| `attachment_ids` | 否 | 已上传的新系统附件 ID |
| `base_version` | 修改或删除时否 | 用户编辑时看到的对象版本 |

收入表单额外字段：

| 字段 | 可为空 | 说明 |
| --- | --- | --- |
| `account_id` | 否 | 收入流入账户 |
| `category_id` | 否 | 收入分类，必须允许收入方向 |

支出表单额外字段：

| 字段 | 可为空 | 说明 |
| --- | --- | --- |
| `account_id` | 否 | 支出流出账户 |
| `category_id` | 否 | 支出分类，必须允许支出方向 |

转账表单额外字段：

| 字段 | 可为空 | 说明 |
| --- | --- | --- |
| `from_account_id` | 否 | 转出账户 |
| `to_account_id` | 否 | 转入账户，不能与转出账户相同 |
| `fee_amount_minor` | 是 | 手续费金额；为空表示无手续费 |
| `fee_account_id` | 是 | 手续费承担账户；有手续费时必须明确 |
| `fee_category_id` | 是 | 手续费分类，第一版可为空 |

### 4.2 字段错误展示

`.NET API` 返回 `validation_failed` 时，Web 必须把字段错误映射到表单控件。

| 错误字段 | 页面行为 |
| --- | --- |
| `amount_minor` | 标记金额输入并保留用户输入 |
| `account_id` / `from_account_id` / `to_account_id` | 标记账户选择器并提示刷新账户资料 |
| `category_id` | 标记分类选择器并提示分类方向不匹配 |
| `business_date` | 标记日期输入 |
| `base_version` | 提示对象版本已变化并引导冲突处理或重新加载 |

## 5. 查询和分页

1. 所有列表查询必须限定 `ledger_id`。
2. 流水、冲突和附件列表使用 `limit + cursor`。
3. 默认不查询作废记录，除非用户进入历史/审计视图。
4. 报表使用云端对象副本计算或读取云端投影，不能要求浏览器拉全量对象自行计算。
5. 投资复杂报表第一版只展示已校准输入或基础列表，不固化未验证公式。

### 5.1 列表查询字段

流水列表请求必须支持：

| 字段 | 可为空 | 说明 |
| --- | --- | --- |
| `ledger_id` | 否 | 当前账本 |
| `date_from` | 是 | 业务日期起点 |
| `date_to` | 是 | 业务日期终点 |
| `account_id` | 是 | 账户筛选 |
| `category_id` | 是 | 分类筛选 |
| `tag_id` | 是 | 标签筛选 |
| `status` | 是 | 默认排除作废和墓碑 |
| `limit` | 否 | 单页数量 |
| `cursor` | 是 | 游标；第一页为空 |

流水列表响应必须包含：

| 字段 | 说明 |
| --- | --- |
| `items` | 流水摘要列表 |
| `next_cursor` | 下一页游标，没有更多时为空 |
| `has_more` | 是否还有更多 |
| `sync_watermark` | 响应对应的云端同步游标或版本水位 |

## 6. 冲突处理

Web 端支持完整冲突解决：

1. 冲突列表。
2. 冲突详情。
3. 字段级差异。
4. 保留本端、保留云端、字段级合并、另存副本和暂不处理。
5. 解决审计。

Web 端冲突解决使用云端当前对象副本，不访问 PC 本地文件、迁移审计、迁移报告或脱敏摘要。

## 7. 删除确认

Web 端删除交易、账户、账本或附件引用必须二次确认。

删除确认必须展示：

1. 对象名称或摘要。
2. 影响范围。
3. 是否同步到其它设备。
4. 是否影响余额、报表、预算或附件引用。
5. 删除后是否可以通过冲突解决或审计追溯。

账本删除属于高风险流程，第一版可先仅提供停用/归档入口；真正删除路径必须独立设计并带审计。

删除确认请求必须包含：

| 字段 | 可为空 | 说明 |
| --- | --- | --- |
| `object_type` | 否 | 删除对象类型 |
| `object_id` | 否 | 删除对象 ID |
| `base_version` | 否 | 用户看到的当前版本 |
| `confirm_token` | 否 | 服务端预检查返回的确认令牌，避免跳过影响范围确认 |
| `reason` | 是 | 用户填写的删除原因；高风险删除建议必填 |
| `client_request_id` | 否 | 幂等请求 ID |

删除确认响应必须包含：

| 字段 | 说明 |
| --- | --- |
| `result` | tombstoned、voided、archived、conflict_created、rejected |
| `object_version` | 删除、作废或归档后的新版本 |
| `conflict_id` | 并发冲突时返回 |
| `audit_event_id` | 云端审计标识 |

## 8. 权限和安全

1. Web 必须登录后使用。
2. 所有 API 请求必须带访问令牌。
3. 所有对象读写必须校验账本成员角色。
4. Viewer 只能查看，不能写入。
5. 令牌过期必须可刷新或引导重新登录。
6. 附件下载必须经过权限校验或短期授权。
7. Web 不展示旧 MoneyHome8 迁移审计、迁移报告、脱敏摘要、旧路径或旧原始行。

## 9. 验收口径

1. Web 端不能在离线状态提交主账本写入。
2. 在线新增收入、支出、转账会生成云端对象版本。
3. 删除有二次确认和审计。
4. 冲突不会静默覆盖。
5. 游标分页可处理大流水列表。
6. Web 不展示旧迁移审计、迁移报告或脱敏摘要。
7. Viewer 角色不能新增、修改、删除或解决冲突。
8. 版本过期的修改或删除必须进入刷新、拒绝或冲突处理路径。

## 10. 当前无需人工确认

本计划没有引入新的产品取舍；它细化的是已确认的 Web 在线为主、.NET API 主写入口和 PC/Web 完整冲突解决边界。
