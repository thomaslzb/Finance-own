# 存款与银行理财运行合同

本文把 B05 动态观察转换为 Rust 重构约束。旧 Delphi 窗体和帧名称只用于追溯证据，不作为 Rust 模块、表名或 API 边界。

## 领域模型

### DepositAccount

`DepositAccount` 保存账户身份、币种、所有者、开户机构、账户组、状态、备注、标签和附件关系。账户身份与单笔定期存单分离，避免修改账户资料时覆盖历史存款条款。

### FixedDepositCertificate

`FixedDepositCertificate` 表达一笔定期存单，至少包含：

- 稳定存单 ID、所属账户 ID 和可选存单号；
- 存款类型、币种、本金和当前余额；
- 起息日、期限数值、期限单位和到期日；
- 年利率、利率规则版本和舍入口径；
- 自动续存设置、到期状态、资金来源和审计信息。

到期本息是派生结果，不得成为唯一业务事实。原本金、原利率、原起息日和原期限必须保留。

### FixedDepositRenewal

续存是引用原存单的生命周期事件，保存续存日期、续存本金、可用资金、存款类型、期限、利率、来源存单和生成的新存单。手工续存与自动续存使用同一领域命令，但触发来源和幂等键不同。

续存不得原地覆盖旧存单。旧存单先完成到期结算，再生成新周期；任一步失败时不能留下已结清旧存单但没有新存单的中间状态。

### BankWealthProduct

`BankWealthProduct` 保存产品代码、名称、币种、发行机构、收益起始日、委托期、期限单位、收益终止日、预期年收益率、是否保本、注销状态和版本。

产品名称允许重复和变更。产品代码的唯一范围、注销后是否允许继续交易，以及收益日期规则必须由产品策略显式定义。

### BankWealthAccount

`BankWealthAccount` 保存账户名称、币种、所有者、创建日期、开户机构、默认资金账户模式、默认资金账户、状态、备注和附件。默认资金账户模式至少区分账户自身与其它账户，不能依赖界面单选框文本解析。

运行态已确认开户向导默认使用账户自身余额，提交 `250.00 CNY` 后只增加账户可用现金、无账户组小计、总资产和净资产，负债不变，冷启动保持。该期初事实没有自动创建产品或持仓。账户编辑器中币种只读，默认资金账户仍可在自身与其它之间配置；因此账户币种、开户期初来源和后续交易默认资金账户是相关但独立的事实。零金额其它账户模式即使未显示选中账户仍可完成属于旧版宽松边界，目标命令必须显式定义零金额是否允许空来源，并在非零真实来源时校验账户状态、币种和版本后生成双边平衡分录。

### BankWealthPosition

`BankWealthPosition` 以账户和产品为主键边界保存持仓本金、累计申购本金、累计赎回本金、购买日、到期日、条款快照、状态和版本。银行理财按本金管理，不使用基金份额与净值作为核心事实。

### FinancialProductEvent

银行理财事件至少区分申购、赎回、到期、分红、其它费用和利息收入。每个事件保存业务日期、账户、产品、资金账户、货币金额分解、标签、备注、幂等键和审计信息。

## 金额、利率与日期

金额使用整数最小货币单位。利率使用受控十进制定点值，并保存精度、计息基数、舍入模式和适用版本。

期限必须保存数值和单位，不能只保存换算后的天数。起息日、到期日和收益终止日应由明确日历规则计算，并保留原输入与派生结果。

在没有真实保存样本校准前，Rust 版不得宣称兼容旧软件的到期本息、预期收益、闰年、首尾日、提前支取或尾差算法。

## 定期存款命令

创建定期存单时，领域服务校验账户币种、存款类型、期限、利率、起息日、本金和资金来源，并在同一事务内写入存单、资金分录和审计事件。

到期支取应明确拆分本金、利息和可能的税费或调整。部分支取、提前支取和全部到期是不同命令，不能只通过金额是否等于余额推断。

续存命令必须引用已到期或允许续存的存单，校验续存金额不超过可用资金，并生成新的条款快照。自动续存任务使用稳定幂等键，应用重启不得重复生成新存单。

## 银行理财命令

申购命令保存产品条款快照、申购本金、资金账户、购买日和持仓版本。产品处于注销、日期无效或币种不匹配时拒绝申购。

赎回命令分别保存赎回本金与实际收回金额。赎回损益是两者结合费用和产品规则的派生结果；部分赎回必须减少对应本金并保留剩余持仓。

到期命令引用到期持仓，分别确认到期本金、收益、费用和资金到账。到期不是顶部普通记账菜单中的通用命令，Rust 版应由持仓状态或到期任务触发，并提供人工确认入口。

分红、其它费用和利息收入是独立事件。它们可以参与累计回报投影，但不得改变原申购本金，除非产品规则明确要求再投资并生成新的持仓事件。

## 产品目录与注销

产品目录的新增、修改、注销和删除需要乐观版本。存在持仓或历史交易时禁止物理删除；注销只阻止新的业务事件，不隐藏历史产品资料。

日期、期限、收益率和保本属性修改只影响新申购或明确生效日后的事件。已有持仓继续引用申购时的产品条款快照。

## 查询投影

定期存单列表、交易明细和账户概况使用统一 `DepositQueryContext`，至少包含账户范围、存款类型、到期状态、日期、币种、排序、数据版本和估值日期。

银行理财持仓统计、交易明细、市值构成、历史盈亏和产品资料使用统一 `BankWealthQueryContext`。所有投影返回查询条件、数据版本和估值日期，避免页签之间出现不同步的本金或收益。

“当前持仓产品”和“所有交易过的产品”只改变查询范围，不写业务事实。空产品目录、空持仓和空交易必须显示可区分的空状态。

## 审计、冲突与幂等

账户、存单、产品、持仓和事件写命令携带期望版本与幂等键。并发修改时拒绝旧版本提交，不能用最后写入者覆盖条款或余额。

创建、修改、注销、删除、申购、赎回、到期、续存和自动任务记录操作者、时间、输入摘要、目标版本、影响对象和结果。

跨账户资金流、存单余额、持仓本金、收益和审计必须在一个数据库事务中提交。失败时整体回滚，重试不得重复扣款、到账、续存或确认收益。

## 本地持久化建议

SQLite 至少需要：

- `deposit_accounts`、`fixed_deposit_certificates`、`fixed_deposit_renewals`；
- `bank_wealth_products`、`bank_wealth_product_versions`；
- `bank_wealth_accounts`、`bank_wealth_positions`、`bank_wealth_position_lots`；
- `financial_product_events`；
- 与总账共享的交易头、分录、标签、附件、审计和幂等表。

余额、到期本息、累计回报、市值构成和历史盈亏可以使用可重建投影或缓存，但不能成为唯一事实。

## 验证要求

Rust 实现进入兼容声明前，至少覆盖：

- 定期存单创建、修改、到期支取、提前支取、部分支取和续存；
- 自动续存的幂等、失败恢复和重复执行保护；
- 不同存款类型、期限单位、日期边界、闰年和舍入尾差；
- 产品新增、修改、注销、重复代码、日期冲突和引用保护；
- 银行理财申购、部分赎回、全部赎回、到期、分红、费用和利息；
- 银行理财账户非零期初、真实其它账户来源、币种不可变和默认资金账户切换；
- 本金、实际现金流、收益、费用和持仓余额的分录平衡；
- 空目录、空持仓、空交易和已注销产品的查询状态；
- 列表、交易明细、历史盈亏、产品资料和账户概况口径一致；
- 并发冲突、幂等重试、应用重启和事务回滚。
