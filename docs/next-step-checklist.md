# 下一步操作清单

本文档把当前最值得继续做的动作拆成简短顺序，方便后续无论是继续逆向还是开始编码，都可以直接照着走。

## A. 若继续逆向

### A1. 先试 GUI

1. 确认 `MoneyHome8.exe` 进程真实存在
2. 确认窗口标题是否为 `test - 财智8`
3. 优先补动态结果：
   - `记账` 真实保存和回滚
   - `财务诊断` 全部公式与边界值
   - `财务规划` 逐年现金流算法
   - `财务目标` 多账户估值和进度边界
   - `财务报表` 精确公式、筛选边界、导出和打印结果
   - `导入导出` 通用 XML 的完整导入语义、信用卡账单格式，以及交割单边界值与最终落库结果

### A2. 若 GUI 不稳定

改走数据线：

1. 继续研究 `mh.mdw`
2. 继续研究 `user.cfg` / `UseInformation.cfg`
3. 继续从 `test.mh8` 中抽：
   - 表簇
   - 字段语义
   - 链接表证据
