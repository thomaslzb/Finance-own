# MoneyHome8 共享 UI 与技术支撑合同

## 1. 边界

B20 的 19 个资源全部属于共享 UI、窗体基类或第三方技术支撑。它们提供筛选、日期、选择、模态窗口、页签、进度、统计导航和只读详情能力，但不拥有账户、交易、投资或报表领域真相。

Rust 重构不得按 Delphi 继承层次复制 19 个同名页面。共享组件只接收宿主提供的模型、草稿和命令回调，不直接访问 SQLite，不自行提交业务事务。

## 3. 技术排除

`TRzFrmCustomizeToolbar` 是第三方工具栏库内部定制器。当前未发现 MoneyHome8 用户入口、业务设置或必须迁移的持久化数据，因此不进入首版产品功能。若后续发现真实用户布局数据，应迁移为应用级工具栏配置，而不是复制第三方窗体。

`TfmCustomDialog` 同样不是独立页面。它只在具体数据网格启用高级自动筛选时作为可选能力存在。

## 4. 已验证行为

- 财务记录的日期范围菜单提供日、周、月、季、年、最近 7 天、最近 1/3/6 月、最近 1 年和自定义。
- 自定义日期窗体接收起止日期；本轮默认值为 `2026-06-30` 到 `2026-07-30`。
- 财务记录完整筛选窗体的金额区域默认“不筛选金额”，另外支持大于等于、小于等于和区间。
- 在线行情长任务提供可取消状态；B18 已验证股票更新中止后未观察到账簿业务写入。
- 报表中心真实使用统计树、统计表格和统计工作区组合；选择报表后在同一宿主加载结果。
- 目标进程存在 `TNodeForm/NODEWRAP` 和 `wkeWebWindow`，证明旧版有本地 Web 内容宿主，但它不是独立业务入口。

## 5. 数据和状态规则

1. 筛选、日期、选择和计算结果先进入宿主草稿；只有宿主应用命令可以改变查询或提交业务数据。
2. 日期范围统一转换为明确时区下的半开区间，UI 可以显示闭区间日期，查询层不得混用边界。
3. 统计树、表格、图表、导出和打印必须共享同一个不可变查询快照，避免跨视图金额不一致。
4. 进度取消是协作式取消；进入不可回滚提交阶段后必须明确显示不可取消，并等待事务结果。
5. Web 内容宿主默认禁止任意外部导航和任意脚本桥调用，只开放经过版本化声明的本地能力。
6. 共享组件状态可以保存为用户偏好，但不得混入账务领域表或改变历史业务口径。

## 6. 仍待校准

- 周起始日、季度边界、时区和夏令时处理。
- 金额区间边界是否包含、负数和超大金额校验。
- 各派生对话框的 Enter、Esc、帮助键、关闭和脏草稿提示。
- 统计表格排序、列定制、复制、大数据分页和导出格式。
- WebView 本地资源协议、脚本桥权限、崩溃恢复和离线降级。
