# 融资融券 Rust 开发合同

## 1. 证据边界

本合同覆盖 B12 的融资融券账户、担保物、融资买入、融券卖出、合同、权益、偿还、利息、费用、持仓统计和行情。开户、空账户工作区、代表性交易编辑器、批量偿还空状态、账户编辑和删除已有动态证据；后续又用真实临时融资与融券合同校准了单笔直接偿还、合同编辑和取消路径，并复测了批量直接还款的真实合同候选。实际偿还保存、精确公式与失败回滚仍待验证。

`TAlsoCouponsDirectlyDlgFm`、`TDirectPaymentsDlgFm` 和 `TEditMarginContractDlgFm` 已证实是依赖已有融资或融券合同的对象上下文入口。顶部记账菜单的同名位置实际打开批量窗体，因此 Rust 必须区分批量命令和单合同命令；当前只确认加载值与取消路径，不得声称已兼容保存行为。

## 2. 领域对象

- `MarginAccount`：稳定 ID、账簿、名称、人民币币种、现金余额、默认融资/融券年利率、状态和审计版本。
- `MarginContract`：类型、合同号、证券、原始本金或数量、剩余本金或数量、年利率、生效/到期日、状态和版本。
- `CollateralPosition`：证券、数量、成本、资格、折算率、划入来源和可用数量。
- `MarginTransaction`：融资买入、融券卖出、卖券还款、买券还券、直接还款、直接还券、利息偿还、权益、费用和更正。
- `MarginRepaymentAllocation`：偿还事件、合同、偿还本金或数量、利息、费用、分配顺序和幂等键。
- `MarginValuationSnapshot`：查询时点的持仓、市值、担保物市值、融资负债、融券负债、可用资金、资产总值和风险指标。

## 3. 合同规则

1. 融资买入和融券卖出完成时原子创建交易、合同和相应现金或证券分录。
2. 合同类型决定本金单位：融资合同使用货币金额，融券合同使用证券数量；不能用无单位数值统一处理。
3. 合同号在账簿和账户范围内的唯一规则必须由真实样例校准，Rust 至少要防止同一外部合同被重复导入。
4. 利率使用定点小数和明确日计数规则；默认账户利率只作为新合同默认值，不静默覆盖现有合同。
5. 修改合同采用版本化更正。利率变更默认只影响生效日后的计提，历史重算必须显式执行并保留审计。

## 4. 偿还规则

1. 单笔直接还款和还券必须从具体合同进入；旧版已观察到默认值分别等于融资合同未还金额和融券合同未还数量，Rust 仍需在保存时重新校验上限。
2. 本金/数量、利息和费用分别保存；显示净额不能替代分项事实。
3. 批量偿还逐合同保存分配明细，合计必须等于各行定点金额或数量之和。
4. 批量候选必须按稳定账户 ID、合同类型、未结状态和剩余量查询，不能依赖账户显示文本、工作区选中行或会话缓存。旧版在真实未结融资合同跨重启存在时仍返回空候选，Rust 不复制该行为。
5. 偿还值为空、为零、负数、超过未偿上限、合同已结清或资产不足时禁止提交；旧版空行提示“请选择合约并输入还款金额”，Rust 应提供合同与金额字段级错误并保留草稿。
6. 偿还使用幂等键；重试不得重复扣减现金、证券持仓或合同余额。
7. 偿还事件、现金或证券分录、利息、合同状态和风险投影在一个事务边界中提交。

## 5. 担保物与风险规则

1. 担保物买入、卖出、划入和划出是不同事件，必须保存来源和资格状态。
2. 担保物市值基于同一行情快照和折算规则；缺失行情不得静默按零值参与风险判断。
3. 融资负债、融券负债、可用资金和资产总值必须来自同一估值时点，避免跨页分币差异。
4. 持仓成本、市值、浮动盈亏、交易盈亏、均价和保本价使用可追溯批次及费用数据。
5. 风险指标和强平条件在真实合同与行情样例校准前保持明确的未实现状态，不编造阈值。

## 6. 查询与并发

- 合同列表、持仓统计、交易明细、历史盈亏和账户概况绑定同一账户和查询时点。
- 合同编辑与偿还使用乐观版本检查；发生并发偿还或编辑时禁止静默覆盖。
- 空账户返回空合同、空持仓、空交易和逐分为零的汇总，不创建占位合同。
- 行情更新、导出和打印不改变合同或交易事实；外部服务失败保留最近有效快照并显示时点。
- 删除账户前展示合同、交易、转账和计划影响；存在未结清合同时默认拒绝物理删除。

## 7. 验收缺口

- 融资和融券合同的完整形成字段、编号唯一范围、计息起点和到期规则；本轮只用最小值创建了代表性合同。
- 单笔直接还款/还券的校验、成功写入、保存并继续、撤销和幂等行为；动态默认值与取消已确认。
- 批量直接还款已确认真实合同、重启、空行编辑和提交阻断，但旧版无法把当前未结合同解析为候选；候选形成条件、成功保存和多合同事务仍待验证。
- 合同编辑的利率生效、代码更新、并发冲突和历史计息行为。
- 偿还分配、费用、权益、风险指标、强平和失败回滚公式。
