# Roadmap

## 第一阶段：摸清原软件与数据

1. 盘点 `MoneyHome8.exe` 的主要功能入口。
2. 确认 `test.mh8` 的文件格式、数据边界和备份策略。
3. 建立功能对照表，区分“必须兼容”“可延后实现”“暂不支持”。

## 第二阶段：建立 Rust 核心能力

1. 定义账本、账户、分类、交易、预算、报表等领域模型。
2. 建立 `mh8` 读写适配层，优先只读解析。
3. 增加最小可运行用例和回归样本。

## 第三阶段：重建 Flutter PC 应用与云同步

1. 建立 Flutter Desktop 壳层和 Rust PC 本地 API。
2. 补齐账本浏览、录入、编辑、删除、查询、统计等核心页面。
3. 建立 .NET API、PostgreSQL 云端对象副本和对象级同步骨架。
4. 使用测试库逐项对照原软件行为。

## 第四阶段：扩展手机端与 Web 端

1. 建立 Flutter Mobile 轻量记账、离线草稿和待同步队列。
2. 建立 Flutter Web 在线记账、查询和冲突解决。
3. 完成 PC、手机、Web 三端上传、下载和冲突处理闭环。
