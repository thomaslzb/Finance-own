# PC-Local Only Legacy Migration Audit

Finance Own will keep first-version legacy migration audit data and migration report files only on the PC client. The cloud will receive synchronized new-system financial objects after user confirmation, but it will not store legacy source files, legacy paths, original rows, field values, privacy-bearing diagnostics, migration summaries, report files, or redacted report summaries, preserving a stricter privacy boundary for MoneyHome8 migration evidence.
