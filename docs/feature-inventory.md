# Feature Inventory

本文档用于把 `MoneyHome8.exe` 的现有能力逐步沉淀为 Rust 重构范围。

## 当前已实测确认

### 账本生命周期

- 支持新建账簿。
- 支持打开账簿。
- 支持备份账簿。
- 支持还原账簿。
- 支持关闭当前打开的账簿。
- 程序启动后会自动打开默认账簿，默认路径来自 `Moneyhome.ini` 的 `DefaultBook`。

### 主导航与分析入口

- 存在 `财务数据` 主入口。
- 存在 `财务报表` 主入口。
- 存在 `财务分析` 主入口。
- 存在 `财务日历` 主入口。
- 存在 `计划与提醒` 主入口。
- 存在 `限额提醒` 主入口。
- 存在 `今日提醒` 主入口。
- 存在 `系统设置` 主入口。
- 当前实测截图可直接看到左侧一级导航：
  - 概况
  - 财务记录
  - 投资一览
  - 标签
  - 账户中心
- 当前实测截图可直接看到顶部一级入口：
  - 财务数据
  - 记账

### 数据同步与行情

- 支持 `同步数据`。
- 支持 `更新行情数据`。
- 存在云端登录、登出、注册、心跳和同步参数获取能力。
- 同步链路覆盖币种、人员、标签、收支项目、账户、交易、默认币种、账户余额。
- 通知链路覆盖提醒开关下载、提醒开关上传、提醒数据上传。
- 提醒数据上传至少包括：
  - 财务提醒
  - 预算情况
  - 证券持仓情况
  - 开放式基金持仓情况
  - 资产负债情况

### 账户与资产

- 主界面存在 `资产` 页签。
- 已打开测试账本后，主界面存在 `账户中心`。
- 已实测识别到以下账户类型：
  - 现金
  - 活期（卡折）
  - 定期
  - 第三方储值
  - 上市证券
  - 开放式基金
  - 外汇
  - 重大资产
  - 应付款
  - 预收款
  - 应收款
- 账户页存在 `新增账户组`。
- 账户页存在 `新增账户`。
- 账户页存在 `所有账户类型` 视图切换。
- 账户页存在 `按账户类型查看` 视图切换。
- 账户页当前可见的组织形态为“账户组 -> 账户”树状层级。
- 账户行当前可见字段至少包括：
  - 账户名称
  - 所属机构或账户组
  - 币种
  - 备注标识或用户标识
  - 部分账户的卡号/账号尾号
  - 部分账户的登录名或用户名
  - 当前余额
- 主界面底部当前可见汇总口径：
  - 资产
  - 负债
  - 净资产

### 投资与持仓线索

- 从配置项可确认存在证券交易页面。
- 从配置项可确认存在开放式基金交易页面。
- 从配置项可确认存在外汇交易页面。
- 从配置项可确认存在定期、债权债务相关页面。
- 从通知与同步配置可确认存在证券持仓、开放式基金持仓、账户统计上报能力。
- 从页面类名可确认存在 `投资一览` 总览页面。
