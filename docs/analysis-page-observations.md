- `财务分析` 不是单一报表页，而是一个独立的导航中心。
- 至少包含四个专题模块：
  - 预算
  - 诊断
  - 规划
  - 目标
- 这与资源窗体中已发现的：
  - `TBudget*`
  - `TFinancialDiagnosisFm`
  - `TFinancialPlanningCenterFm`
  - `TFP*`
  - `TGoal*`
  是一致的。

## 5. 对 Rust 重构的意义

- `财务分析` 应设计为单独的壳层导航模块，而不是挂在报表模块下面。
- `财务预算` 页面需要支持：
  - 空状态
  - 新增预算
  - 后续预算列表、编辑与统计
- `财务规划` 与 `财务目标` 需要单独的子模块，而不是只作为预算的附属页面处理。

## 8. 运行时 DFM 补证

同日从普通权限运行副本内存中解析真实 `TPF0` 资源后，页面内容结构已经得到直接证据。该证据不改变第 7 节对旧截图的判断，但补齐了截图没有显示的静态控件和字段。

### 财务诊断

- 新增账户
- 资产性质设置
- 开始诊断、调整财务数据
- 收支来源包含账簿统计和持久化手工输入；手工模式八项金额逐行确认并在冷启动后保持
- 十二项指标公式、样例结果和参考区间已由 `RT-15-010` 校准；诊断年总支出排除储蓄支出，资产性质只重分类流动/投资资产
- 定期、货币基金可分别归为流动资产或投资资产
- 输入数据与指标结果两个阶段

### 财务规划

- 未来重大事件、当前财务情况、家庭资料
- 工资、资产收入/支出、资产增长、资产购置
- 日常支出、教育、支出调整、其它收入/支出、通胀
- 退休、资产选择和年度预测
- 家庭资料支持无配偶和有配偶分支；`1990` 年出生、预计寿命 `85` 生成 `2026..2075` 年度范围
- 当前财务情况右侧固定为收入、支出、现金与投资、债权债务、商业保险、通胀六类，未来重大事件固定为养老、重大支出、资产购置三类
- 零增长受控样例中，年工资 `120000`、家庭年日常支出 `60000` 使年度余额按每年净增 `60000` 递增，并在冷启动后保持
- 起始余额、通胀/退休/资产增长复利、分期购置、跨币种/舍入/负值和清除确认仍待校准

### 财务目标

- 新增、修改、删除、显示已过期目标
- 目标名称、金额、开始/结束日期
- 全部账户或账户子集绑定
- 账户余额/市值与合计
