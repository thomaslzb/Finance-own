## 3. 控制台入口线索

- 来源窗体：`TSHORTCUTMANAGEDLGFM`（快捷键设置）
- 标签：`lblConsole` = `控制台`
- 热键控件：`edtConsole` / `TmwHotKey`
- 设计时启用：`false`
- 运行时键值：`Ctrl+F12` / `0x407B`
- 解释：方法级代码把 edtConsole 固定写为 Ctrl+F12；设计时禁用只表示用户不能在该页编辑

方法级证据证明具体键值；动态验证只需确认触发前置条件、窗口可达性和命令副作用。

## 4. 金额计算器支撑范围

- 金额输入控件：`TMHCalcuEdit`
- 实例数：`429`
- 覆盖窗体：`160` 个
- 弹出计算器：`TCALCUFM` / `TdxCalculator`

Rust 版应把它实现为金额输入控件的共享计算器弹层；结果、错误、Esc 和方向上键均关闭弹层，仍需动态验收回填、错误文案和焦点恢复。

## 5. 产品范围边界

- `AI`：记录为实验外部能力；默认关闭，不得复制旧明文 HTTP、内置秘密或无同意上传行为。
- `控制台`：记录为内部诊断能力；仅开发/诊断构建启用，不进入普通用户默认导航。
- `CalcuFm`：属于金额输入共享技术组件，进入实现范围，但不计为独立业务功能页。
